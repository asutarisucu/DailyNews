🛒 Shopify 開発者情報

【要対応】オンラインストアで動くアプリにネットワークアクセス宣言が必須に — 12月1日からデプロイと審査提出を拒否、2027年1月1日に非掲載

shopify
🔗 Shopify 開発者 changelog

Shopify は、オンラインストア上でコードを実行するアプリに対し、shopify.app.toml の [network_access] セクションで allowed_sources（接続先ホストや読み込み元サーバー）の宣言を必須にすると告知した。対象はスクリプトタグを使うアプリ、write_themes スコープを持つアプリ、write_open_pixels を使う Web ピクセルなどで、宣言がない場合は2026年12月1日からデプロイと App Store への提出が拒否され、2027年1月1日には非掲載・新規インストール停止となる。メタフィールドや商品などのデータ書き込みだけを行うアプリ、管理画面や Dev Dashboard で作成したカスタムアプリは対象外。前日に紹介した開発ストアでの事前テスト機能で設定を検証できる。

Anthropic の数学者がリーマン予想の証明を主張 — Claude と共同で作成、17万超の Lean ファイルで公開

ai
🔗 Scientific American

Anthropic の研究者 Levent Alpöge 氏は11月20日、Claude と共同でリーマン予想（および一般化リーマン予想）の証明を得たと主張し、4ページの解説ノートと約17万5,000ファイルからなる Lean 4 の形式証明を公開した。同氏は最も重要な局面を Claude が主導したと説明している。MIT の Andrew Sutherland 氏らが Lean 上でのコンパイルを確認し、定理の記述が Mathlib のリーマン予想の定義と一致するとの報告も出ているが、数学者による本格的な検証はこれからで、慎重な見方も多い。

ChatGPT の新機能「Space」が Plus ユーザーに順次提供 — 「ライブラリ」を置き換え、ページやスライドを自動更新

ai
🔗 OpenAI ChatGPT リリースノート

OpenAI は11月20日、ChatGPT の「Space」を18歳以上の Plus ユーザー向けに全世界で順次提供開始した。Space はサイドバーの「ライブラリ」を置き換え、ページ、スライド、画像、アップロードしたファイルをまとめて管理する場となる。接続したアプリやツールの情報をもとにページやスライドを自動更新する設定も可能。Free ユーザーは共有されたページを開けず、公開リンクも利用できない。なお常時稼働エージェント「dots」は引き続き一部ユーザーでのテストにとどまる。

Meta の AI エージェント「Muse」が他人のデータを表示か — 社員の内部報告を Reuters が報道、Meta は「ハルシネーション」と説明

ai
🔗 The Mac Observer

Reuters は、Meta が9月に公開した AI エージェント「Muse」について、社員から20件以上の異常動作の内部報告があったと報じた。釣りの話題の会話に見知らぬ銀行残高が表示されたり、Signal の私的な会話に言及したりといった事例が含まれる。Meta は、他人のメッセージに見える出力はモデルのハルシネーションであり、アカウント間で会話が混ざったわけではないと説明し、社員は一般公開版とは異なるバージョンを使っているとしている。一般向けの Muse で同じ問題が起きているかは確認されていない。

🔒 セキュリティ

【要更新】Cisco Expressway の CVE-2026-76466 が PoC 公開直後に悪用 — CVSS 9.8、クラスター構成で root 権限のコマンド実行

security
🔗 SecurityWeek

ロシアのセキュリティ企業 F6 は、Cisco Expressway の脆弱性 CVE-2026-76466（CVSS 9.8）が GitHub での PoC 公開直後に悪用され、ロシアの組織で4台の機器が侵害されたと報告した。クラスター構成のデバイスで、認証なしのリモート攻撃者が root としてコマンドを実行でき、攻撃者は内部ネットワークへの横展開も試みたという。修正版は X15.5.20 で回避策はなく、X14 以前は移行が必要。Erlang のシステムログ（erlang.log）の nodeup エントリが侵害の兆候とされる。CISA は11月20日に本脆弱性を KEV に追加した。

CISA が SAP NetWeaver の JNDI インジェクション CVE-2025-42884 を KEV に追加 — 連邦機関の対応期限は11月23日

security
🔗 CISA

CISA は11月20日、悪用が確認された脆弱性4件を KEV カタログに追加した。既報の VMware vCenter、Apache Roller、Cisco Expressway に加え、SAP NetWeaver Enterprise Portal の JNDI インジェクション脆弱性 CVE-2025-42884（CVSS 6.5）が含まれる。認証不要の攻撃者が JNDI ルックアップに使われる環境プロパティや URL を注入し、サーバー情報の取得や改ざんを行える可能性がある。修正は SAP Security Note 3660969 で、連邦機関は11月23日までの対応を求められている。

security
🔗 BleepingComputer

カナダの通信大手 Bell Canada は、「エージェント型」と表現する攻撃者が回線の受注・プロビジョニングに使う Maximo システムの本番前環境に侵入し、法人顧客データを盗んだと公表した。流出したのは担当者の氏名、役職、業務用メールアドレス、電話番号、住所のほか、チケット件名やネットワーク機器に関連する一部の IP アドレス。認証情報や機微な個人情報、添付ファイルへのアクセスはなく、サービスへの影響もないとしている。「エージェント型」の意味や攻撃者、影響件数は明らかにされていない。

AWS Lambda のタイムアウト上限が30分に倍増 — オンデマンドの Event Functions で全商用リージョン対応

cloud
🔗 AWS What's New

AWS は11月19日、Lambda のオンデマンド Event Functions の最大タイムアウトを従来の15分から30分に引き上げた。同期・非同期呼び出しとイベントソースマッピングのいずれにも適用され、全商用リージョンで利用できる。Lambda Managed Instances では同期呼び出しも30分に対応し、非同期と ESM は9月に導入された90分のまま。既存関数のタイムアウトは自動では延びないため設定変更が必要で、呼び出し元の API やキューのタイムアウトにも注意が必要。

【要確認】GitHub Actions の pull_request_target が12月2日から公開リポジトリで既定ブロックに — イベントポリシーでの明示許可が必要

dev
🔗 DevelopersIO（クラスメソッド）

GitHub は、公開リポジトリで pull_request_target イベントによるワークフロー実行を、Actions のイベントポリシーで明示的に許可しない限り既定でブロックする変更を12月2日に施行する。フォークからの PR で秘密情報が盗まれる「pwn request」攻撃への対策で、GitHub Free / Team / Enterprise Cloud の公開リポジトリが対象、プライベートリポジトリや GitHub Enterprise Server は対象外。秘密情報が不要なら pull_request への置き換え、必要なら特定ワークフローに限定したポリシー許可が推奨されている。

other
🔗 TweakTown

Apple は、11月17日に iCloud、App Store、Apple Music、Apple Pay、Apple アカウントのサインインなどで発生した大規模障害について、同日朝に実施した社内アップデートが原因で、サイバー攻撃ではないと説明した。iPhone や Mac で iCloud から突然サインアウトされたり、開発者が App Store Connect に接続できなかったりする事例が報告された。多くのサービスは同日午後に復旧した。Microsoft 365 や JPMorgan Chase などでも障害が相次いだ週となった。
