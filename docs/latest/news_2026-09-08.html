Hydrogen 開発者プレビュー更新（9月2日）: バリアントリンク・カートリフレッシュ・ローカル HTTPS 証明書の自動生成を追加

shopify
🔗 Shopify Developer Changelog

Hydrogen のヘッドレスコマースフレームワーク開発者プレビューに新機能が追加された。バリアントリンクが特定バリアントを指定してそのバリアントを開くように変更され、カートリフレッシュでコード変更後にカートを自動再読み込みできるようになった。また、Customer Account テスト用のローカル HTTPS 証明書が Hydrogen によって自動生成されるようになり、ローカルログインの初期設定がコマンド1つ（または設定不要）で完結する。いずれも Shopify CLI 最新版を使用する開発者が対象。

Shopify Admin GraphQL 2026-07: コンポーザブル Collections モデル正式リリース — サブコレクション・バリアントスコープ・アプリ所有ソースが利用可能に

shopify
🔗 Shopify Developer Changelog

GraphQL Admin API バージョン 2026-07 でコンポーザブルなコレクションモデルが正式リリースされた。コレクションは単一の手動またはスマート定義から、手動ピック・自動化条件・サブコレクション・アプリ所有ソースを組み合わせた「ソースのユニオン」へと刷新された。マルチバリュー条件・手動除外・バリアントスコープのソース・共有可能なアプリ所有ソースが利用可能。2026-07 以降の API バージョンで新モデルのコレクションが返されるため、コレクションを扱うアプリは早期にマイグレーションを実施することを推奨する。

Shopify Next Generation Events が開発者プレビュー公開 — Product・Customer トピックから提供開始、shopify.app.toml でフィールドレベルのイベント定義が可能に

shopify
🔗 Shopify Developer Changelog

Shopify の新しいイベントシステム「Next Generation Events」が unstable API バージョンで開発者プレビューとして公開された。Product および Customer トピックが先行提供され、2026年中に他のトピックも順次追加予定。従来のクラシック Webhook では配信後に自分で判断していたイベントの意味を、shopify.app.toml 内でトピック・アクション・フィールドレベルトリガー・ペイロード形状・配信条件として宣言的に定義できるようになった。試すには Shopify CLI バージョン 3.92 以上が必要。

🔒 セキュリティ

【緊急】Microsoft 9月 Patch Tuesday: 史上最多 973 件の CVE を修正、CVE-2026-85880（ALPC）・CVE-2026-81963（Windows Update Stack）の2ゼロデイを修正

security
🔗 BleepingComputer

Microsoft が9月8日（現地時間）の Patch Tuesday で史上最多となる 973 件の CVE を修正した。実際に悪用が確認されたゼロデイは2件で、CVE-2026-85880 は Windows ALPC のヒープバッファオーバーフローで低権限 AppContainer から SYSTEM 権限へのサンドボックス脱出が可能、CVE-2026-81963 は Windows Update Stack のリンクフォロー欠陥で既存アクセスを持つ攻撃者がローカルで権限昇格できる。対象は Windows・Office・SQL Server・Exchange・SharePoint・Azure・開発者ツールと広範にわたるため、早急に Windows Update の適用を強く推奨する。

CISA、KEV カタログに7件追加 — SonicWall SMA 1000 の SSRF 脆弱性 CVE-2026-83548（CVSS 10.0）や Kestra OS コマンドインジェクションなど

security
🔗 CISA

CISA が9月2日に Known Exploited Vulnerabilities（KEV）カタログへ7件の脆弱性を追加した。最も深刻なのは CVE-2026-83548（CVSS 10.0）で、SonicWall SMA 1000 アプライアンスのサーバーサイドリクエストフォージェリ（SSRF）脆弱性。未認証のリモート攻撃者が機密機能への不正アクセスを得られる。他にも Kestra OSS の OS コマンドインジェクション（CVE-2026-49869）、BerriAI LiteLLM の不正認証（CVE-2026-59822）などが含まれる。連邦政府機関は CVE-2026-48710・CVE-2026-59822 を除き9月5日までにパッチ適用が義務付けられた。

CISA、Google Chrome V8 型混乱の脆弱性 CVE-2026-85046 を KEV に追加 — ブラウザを通じた攻撃の典型的な侵入経路として注意喚起

security
🔗 CISA

CISA が9月4日、Google Chromium の JavaScript エンジン V8 で型混乱（Type Confusion）が発生する脆弱性 CVE-2026-85046 を KEV カタログに追加した。V8 の型混乱脆弱性は悪意あるサイバーアクターが好む典型的な攻撃ベクターで、標的ユーザーに悪意あるページを閲覧させることでリモートコード実行に繋がる可能性がある。Chrome は定期的に自動更新されるが、エンタープライズ環境で自動更新が無効になっているケースでは手動での確認・適用が必要。

AWS と Google Cloud がマルチクラウド相互運用の協業を発表 — Cross-Cloud Interconnect GA により企業の複数クラウド移行障壁が低下

cloud
🔗 CIO Dive

AWS と Google Cloud がマルチクラウド展開を容易にするための協業を強化すると発表。Cross-Cloud Interconnect は GA 時に最大 100 Gbps の帯域幅が利用可能で、AWS VPC とパートナークラウドの VPC ネットワーク間に専用・低レイテンシの接続を提供する。これにより企業はクラウド間のデータ転送コスト削減やワークロード分散が容易になり、ベンダーロックインのリスク軽減が期待される。エンタープライズアーキテクトは設計指針の見直しが必要になる局面もある。
