【明日が締め切り】Shopify、8月26日に非Plusストアの Additional Scripts・checkout.liquid を完全廃止 — トラッキング移行が未完の場合は計測データが即日消滅

shopify
🔗 Shopify Developer Docs

明日8月26日、Shopify はすべての非Plusストア（Basic・Shopify・Advanced・Pause and Build プラン）のサンキューページ・注文状況ページにおける checkout.liquid・Additional Scripts フィールド・スクリプトタグのサポートを終了する。Plusストアは2025年8月28日に同変更が適用済み。Additional Scripts フィールドで稼働中の Google Ads コンバージョンタグや Meta ピクセルなどのトラッキングコードは即日停止する。対処法は Web Pixels API への移行か、トラッキングアプリへの切り替え。移行が完了していない場合は今日中の対応が必須。

Hydrogen 開発プレビュー更新（8月18日）: カートセッション追跡・カート属性・標準ページビューイベント・Shop Pay スクリプト不要化

shopify
🔗 Shopify Developer Changelog

Hydrogen 開発プレビューが8月18日付で更新され、4つの重要機能が追加された。①カートセッション追跡（cart session attribution）: ログイン済みユーザーのカートとアカウントセッションが同期し、ゲストチェックアウトではなく保存済み情報でチェックアウトに到達できる。②カート属性: ギフトメッセージなど注文全体のデータをカートに、彫刻テキストなどライン単位のデータを各ラインアイテムに付与できるようになった。③標準ページビューイベント: Hydrogen ストアフロントがすべてのナビゲーションで標準 pageview イベントを発火し、Liquid テーマと同様の分析が可能に。④Shop Pay ボタンが Shopify の shop-js スクリプト読み込みなしに直接レンダリングできるようになりパフォーマンスが向上した。

Shopify Managed Markets、8月24日に Delivered Duty Unpaid（DDU）を終了 — 関税未徴収配送オプションが廃止・対象市場はチェックアウト時関税徴収に移行

shopify
🔗 Fudge.ai — Shopify Updates August 2026

Shopify Managed Markets は8月24日をもって Delivered Duty Unpaid（DDU: 輸入関税を購入者が現地で後払いする配送方式）のサポートを終了した。DDU が設定されていた対象マーケットは自動的に Delivered Duty Paid（DDP: チェックアウト時に関税を徴収する方式）に切り替えられる。越境販売を行うマーチャントは、顧客が配送時に予期せぬ関税請求を受けることがなくなる一方、チェックアウトフローでの関税表示・計算ロジックの確認が推奨される。

AWS が耐量子暗号（PQC）移行でクラウド3社の中で最先行 — GCP も ML-KEM・ML-DSA 対応を文書化、Azure はいまだ RSA/楕円曲線ベース留まり

dev
🔗 Refonte Learning

AWS・Azure・GCP の耐量子暗号（Post-Quantum Cryptography: PQC）対応状況を比較した最新レポートによると、AWS がNIST標準化した ML-KEM（格子暗号鍵カプセル化）・ML-DSA・SLH-DSA の実装で最も先行している。Google Cloud KMS も同3アルゴリズムを文書化し対応が進んでいる一方、Azure のマネージド HSM は依然 RSA・楕円曲線・AES ベースの鍵のみをサポートしており PQC への移行が遅れている。量子コンピュータによる現行暗号の解読が現実味を帯びるなか、クラウドプロバイダーの PQC 対応は企業の長期的なデータ保護戦略に直結する重要な選択基準となっている。
