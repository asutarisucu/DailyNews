組織外ストアにインストールされるカスタムアプリにも IP 許可リストを義務化 — 新規は11月20日、既存は2027年1月1日から

shopify
🔗 Shopify Developer Changelog

Shopify は11月11日、所有組織の外のストアにインストールされるカスタムアプリにも IP 許可リスト（IP allowlist）の設定を必須とすると発表した。新規インストールは2026年11月20日 23:59（米東部時間）から、既存のインストールは2027年1月1日から適用される。これまで義務化の対象は公開アプリのみで、カスタムアプリは推奨にとどまっていた。代理店などが構築したカスタムアプリを複数のマーチャントに配布しているパートナーは、Dev Dashboard で静的 IP または ASN による許可リストを早めに設定する必要がある。

🔗 Shopify Developer Changelog

dev
🔗 InfoQ

GitHub Actions のワークフロー依存関係ロックファイルが、10月14日のパブリックプレビューから約2週間で一般提供となった。gh actions-lock 拡張で生成した .github/workflows/actions.lock に記録されたコミットをランナーが実行するため、タグが後から書き換えられても影響を受けない。管理者向けにロックファイルを必須にするポリシーも用意され、Enterprise Cloud、Team、Free の各プランで利用できる。
