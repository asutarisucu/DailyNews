🛒 Shopify 開発者情報

【要確認】App Store の申請要件を厳格化 — 新規アプリは本人確認が必須、追加の掲載には既存アプリごとに10インストールが必要

shopify
🔗 Shopify Developer Changelog

Shopify は App Store の申請要件を「build, grow, then expand（作って、育てて、広げる）」方針で改めた。新しいアプリを申請する前に、パートナーアカウントで本人確認を済ませる必要がある。さらに、別のアプリを掲載するには、既存の各アプリがフルプライスのストアで10件以上インストールされていなければならない。却下後に指摘を直さず再申請すると、待機期間（クールダウン）が延びる仕組みも入った。すでにインストール数の条件を満たし、フルプライスのストアに1件以上残っているアプリは影響を受けない。

OpenAI が「Businesses in ChatGPT」をベータ公開 — 企業が認証済みプロフィールを取得し、自社の AI エージェントを ChatGPT 内で提供

ai
🔗 The Next Web

OpenAI は11月10日、企業向けの機能「Businesses in ChatGPT」をベータとして公開した。企業は新設の「Business Hub」で ChatGPT 上のプロフィールを申請でき、認証されると青いチェックが付く。基本情報の編集や、価格・在庫を含む商品フィードのアップロードも Business Hub から行う。米国の対象 EC・オンラインサービス事業者は、プロフィールから利用者が呼び出せる「Business Agents」も運用できる。エージェントは AI であることの明示や正確な価格表示が義務付けられ、ChatGPT 広告の遷移先にも設定できる。

ai
🔗 TechNode Global

🔒 セキュリティ

【要更新】Chrome のゼロデイ CVE-2026-125350 が悪用中 — XML コンポーネントの解放後使用、今年8件目

security
🔗 BleepingComputer

Google は11月9日、XML コンポーネントの解放後使用（use-after-free）の脆弱性 CVE-2026-125350 を修正する Chrome の緊急アップデートを公開した。Google は、この脆弱性を悪用するエクスプロイトが実際に出回っていることを認めている。2026年に悪用された Chrome のゼロデイはこれで8件目となる。修正版は Windows / Mac 向けが 157.0.8103.50/.51、Linux 向けが 157.0.8103.50 で、WebGL や V8 など高深刻度の脆弱性6件もあわせて修正された。全ユーザーへの配信には数日から数週間かかるため、手動での更新が推奨される。

【要更新】Git 2.56.1 などで脆弱性6件を修正 — 再帰クローン時に悪意あるリポジトリがコードを実行できる CVE-2026-111760 など

security
🔗 Help Net Security

Git プロジェクトは Git 2.56.1 とメンテナンス版を公開し、6件の脆弱性を修正した。最も深刻な CVE-2026-111760 はインデックス処理の整数切り捨てで、git clone --recurse-submodules の実行時に悪意あるリポジトリが任意のコードを実行できる。ほかに、悪意あるサーバーの HEAD 参照を使ったパストラバーサル（CVE-2026-113408）や、マージ処理のヒープオーバーフロー（CVE-2026-105437）なども修正された。ユーザーに代わってマージを実行するホスティングサービスも影響を受ける可能性があり、GitLab は Gitaly 経由で RCE に発展しうるとしている。

【要更新】Node.js 11月のセキュリティリリースが公開 — 26.13.1 / 24.22.3 / 22.23.5 で16件を修正、TLS 秘密鍵漏えいの恐れも

security
🔗 Node.js

予告どおり11月11日、Node.js の 26.x / 24.x / 22.x 向けにセキュリティリリースが公開された。修正版は 26.13.1 / 24.22.3 / 22.23.5 で、報道によると計16件の CVE を修正している。HTTPS の TLS 書き込みでの再入の問題（CVE-2026-123864、CVSS 8.1）は TLS 秘密鍵の漏えいにつながる可能性がある。HTTP/2 の解放後使用（CVE-2026-123866）では、他の接続の応答メモリが相手に送られる恐れがある。現時点で悪用は報告されていないが、Node.js 20 以前には修正が提供されないため注意が必要だ。

security
🔗 BleepingComputer

デンマークの海運大手 Maersk は、2022年の買収で引き継いだ旧システムが侵害されたことを認めた。ランサムウェアグループ WhiteArmor が犯行声明を出し、約100GB のデータを盗んだと主張して500万ドルを要求している。Maersk は、これまでの調査では機密データが流出していない可能性が高いとしている。ただし、影響を受けたシステムやデータの種類、侵入の時期は明らかにしていない。

AWS が「AWS Emulator」を一般提供 — AWS サービスをローカルで再現するオープンソースのエミュレーター、AI エージェントが全コードを記述

cloud
🔗 SiliconANGLE

Enterprise にインストールした GitHub App から、Enterprise レベルの Copilot シート管理 API を呼び出せるようになった。どのユーザーや Enterprise チームに Copilot シートを割り当てるかを、App から自動で制御できる。利用には、App に新しく追加された Enterprise 向けのきめ細かな（fine-grained）権限を付与する必要がある。個人のトークンに頼らずに、シート割り当てを自動化できる。

Copilot CLI 向け C++ 言語サーバーが MSBuild ビルドを自動設定 — エージェントの事前設定が不要に

dev
🔗 GitHub Changelog

GitHub Copilot CLI 向けの Microsoft C++ Language Server に、MSBuild のコンパイルコマンド抽出ツールが同梱された。プロジェクトを開くと抽出ツールが自動で実行される。これまでのように、エージェントが別の設定スキルを先に実行する必要はなくなった。MSBuild ベースの C++ プロジェクトでも、すぐにコード解析を使ってエージェントが作業できる。
