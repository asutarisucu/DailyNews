shopify
🔗 Shopify Developer Changelog

2026-07 APIバージョンより、GraphQL Admin APIがマーケット単位の配送設定に対応。マーケットごとに異なる配送戦略を別途配送プロファイルリソースを作成することなく設定可能になった。フィーチャープレビューは本日より利用可能で、開発ストアで既存インテグレーションと料金ロジックの検証が推奨される。マーチャントへのロールアウトは2026年10月1日から開始し、2027年7月1日に全マーチャントへ展開完了予定。

マーチャント所有の配送プロファイルAPI が Market-driven shipping 移行により非推奨に — 既存アプリは2026-07対応が必要

shopify
🔗 Shopify Developer Changelog

Market-driven shippingの導入に伴い、既存のマーチャント所有配送プロファイルAPIが非推奨となった。ショップがMarket-driven shippingを使用している場合、Admin GraphQL APIのレガシー配送プロファイルフィールドおよびミューテーションは「ライブ」な配送設定を反映しなくなる。書き込み操作はエラーなく成功するがマーチャントの実際の配送設定は更新されないという危険な挙動があるため、配送APIを利用するアプリはフィーチャープレビュー期間中に必ず更新が必要。
