npm サプライチェーン防衛を多重強化: publish 時マルウェア自動スキャン導入、v12 でインストールスクリプトをデフォルト無効化 — 2FA バイパストークンも段階廃止へ

🔗 GitHub Blog

GitHub/npm がサプライチェーン攻撃への対策を多層的に強化している。新たに導入されたパブリッシュ時マルウェアスキャンにより、npm へのパッケージ公開後 5 分程度の自動スキャンが行われ、疑わしいパッケージはインストール前に保留・ブロックされる。npm v12 では install-time スクリプトがデフォルト無効化され、依存関係インストール時の認証情報漏洩リスクが大幅に低減。また 2FA をバイパスできるアクセストークンの廃止も段階的に進められており、8月にアカウント設定変更、2027年1月には直接 publish にも制限が適用される予定。既存の CI/CD パイプラインは OIDC ベースの Trusted Publishing または Staged Publishing への移行が推奨される。
