🛒 Shopify 開発者情報

アプリの network_access 設定を開発ストアで事前テスト可能に — Dev Dashboard の機能プレビュー「network access testing」

shopify
🔗 Shopify 開発者 changelog

Shopify は、shopify.app.toml の [network_access] セクションで宣言したアプリの外部ホストやサーバーを、開発ストア上でリリース前に検証できる機能プレビュー「network access testing」を提供している。Dev Dashboard でストアを作成する際の任意ステップ「Test a feature preview」から有効化でき、宣言漏れのホストや誤った設定を見つけられる。IP 許可リストの必須化（11月20日期限）に続き、Shopify はアプリのネットワークアクセス宣言によるストアフロント保護を進めており、早めの検証が推奨される。

OpenAI が音声モデル「GPT-Live-1.1」を API で提供開始 — 待機時間を1分0.02ドルで課金する「Standby」も導入

ai
🔗 OpenAI Developer Community

OpenAI は、10月15日から ChatGPT Plus / Pro の音声機能で使われている全二重の音声モデル「GPT-Live-1.1」を API（モデル ID: gpt-live-1.1）で提供開始した。話しながら聞き続けることができ、前世代より文字起こし精度や多言語での声の一貫性が向上、推論やツール利用を任意のバックエンドモデルに委任することもできる。料金は利用中が1分0.05ドルで、新設の「Standby」では5〜60秒の無音後に一時停止し、待機時間を1分0.02ドルで課金する。

【要更新】Apache Roller の RCE 脆弱性 CVE-2026-129448 が悪用中 — CVSS 9.8、XML-RPC の逆シリアル化

security
🔗 BleepingComputer

Apache は、Java 製ブログサーバー Apache Roller の XML-RPC エンドポイントに存在する、認証不要の逆シリアル化によるリモートコード実行の脆弱性 CVE-2026-129448（CVSS 9.8）が実際の攻撃に悪用されていると警告した。認証チェックの前にオブジェクトを逆シリアル化してしまう不備で、6.1.5 より前のバージョンが影響を受ける。6.1.6 以降への更新が推奨され、すぐに更新できない場合は web.xml で XML-RPC のサーブレットマッピングを削除する回避策が示されている（管理画面での無効化だけでは不十分）。

security
🔗 BleepingComputer

Broadcom が緊急パッチを公開した VMware vCenter の認証回避脆弱性 CVE-2026-123890（CVSS 9.8）について、Mandiant と Google Threat Intelligence は、中国国家系とみられるグループが2026年9月上旬からゼロデイとして悪用していたと報告した。VMware Directory Service の欠陥で、ネットワークに到達できる未認証の攻撃者が認証を突破し、管理下の仮想マシン全体を掌握できる恐れがある。未適用の環境は直ちに更新し、侵害の痕跡を確認することが推奨される。

security
🔗 SecurityWeek

欧州委員会は、10月22日に検知したサイバー攻撃について「調査の結果、AI によって生成されたサイバー攻撃だった」と確認した。人事基盤 Sysper や医療費精算システム MyPMO、翻訳サービスなどが影響を受け、給与・休暇・医療費精算のシステムが約10日間停止した。Politico は使用ツールを公開の AI ペネトレーションテストフレームワーク「ARTEX」と報じており、現時点で職員データの漏えいの証拠は見つかっていないとしている。

【続報】ランサムウェア「n0n」が Visa・Mastercard・JPMorgan 関連の顧客データを公開 — 各社は委託先経由でカード決済情報は無事と説明

🔗 TechRadar

Visa と JPMorgan Chase を被害者として掲載していた新興ランサムウェア集団「n0n」が、リークサイトで実際にデータを公開した。JPMorgan は決済システムへの影響やカード決済情報の漏えいはないと説明し、Visa はアジア太平洋の外部サービス事業者でのインシデントと関連があるとした。Mastercard も特定の特典プログラム登録者の一部情報が流出したことを認めたが、分析では公開データは主に氏名やメールアドレスなどの連絡先情報で、件数も主張より少ないとみられている。

OpenSSL の Base64 処理にヒープオーバーフロー CVE-2026-121481 — CISA は CVSS 9.8、OpenSSL は「Low」と評価が割れる

security
🔗 Cyber Security News

OpenSSL の EVP_EncodeBlock() に、INT_MAX 付近の長さの入力を渡すとヒープバッファオーバーフローが起きる脆弱性 CVE-2026-121481 が11月18日に公開された。CISA の補足評価は CVSS 9.8（Critical）だが、OpenSSL は攻撃経路が特定されていないとして深刻度を「Low」としており、評価が分かれている。影響は 4.0.0〜4.0.3 と 4.1.0 で、修正は12月1日リリース予定の 4.0.4 / 4.1.1 に含まれる見込み。現時点で悪用は確認されていない。

Azure SRE Agent が AWS と Google Cloud にネイティブ対応 — アクセスキー不要の ID フェデレーションで接続（プレビュー）

cloud
🔗 Microsoft Tech Community

Microsoft は Ignite 2026 に合わせ、障害対応を自動化する Azure SRE Agent に AWS と Google Cloud の組み込みコネクターをパブリックプレビューで追加した。Azure のマネージド ID から AWS IAM ロールや Google Cloud の Workload Identity Federation へフェデレーションするため、AWS アクセスキーやサービスアカウントキーの管理は不要。各クラウドの IAM とエージェントの実行モード、ツール承認でアクセスを制御し、操作は CloudTrail や Cloud Audit Logs で監査できる。

Amazon MSK の Express ブローカーが Graviton4 ベースの M8g インスタンスに対応 — 計算コスト15%減、クロス AZ 料金も不要に

cloud
🔗 AWS

AWS は、Amazon MSK（マネージド Kafka）の Express ブローカーで Graviton4 ベースの M8g インスタンスをサポートした。M7g と比べてブローカー時間あたりの料金が15%安く、クライアント通信のブローカー側クロス AZ 料金がかからなくなるほか、P99 の書き込みレイテンシーは最大45%低下、遅延したコンシューマーの追い上げは2倍高速になるとしている。新たに 24xlarge サイズも追加され、既存の M7g クラスターからのインプレース移行にも対応する。

Amazon Aurora と RDS で Graviton5 ベースの R9g インスタンスが利用可能に — R8g 比で最大22%の価格性能向上

cloud
🔗 DevelopersIO（クラスメソッド）

AWS は、Amazon Aurora（PostgreSQL / MySQL 互換）と Amazon RDS for PostgreSQL / MySQL / MariaDB で、Graviton5 プロセッサーを搭載したメモリ最適化の R9g データベースインスタンスを一般提供した。AWS は前世代の R8g と比べて最大22%の価格性能向上をうたい、vCPU とメモリ構成は R8g と同一で料金差はわずかとされる。クラスメソッドの検証では us-east-1 で db.r9g.large の Aurora PostgreSQL クラスターを問題なく起動できたと報告している。

Signal が AI エージェント対策でスクリーンショットを既定でブロック — iOS 27 では「Block Siri AI」を既定オン

other
🔗 Engadget

Signal は11月20日、OS に組み込まれた AI アシスタントやサードパーティの AI エージェントがチャット内容を読み取るのを防ぐため、モバイルアプリでスクリーンショットを既定でブロックすると発表した。iPhone では新設定「Block Siri AI」が既定で有効になり、Android では既存の「画面セキュリティ」を利用する。ただし端末に保存済みのデータへのアクセスは防げず、macOS では確実にブロックする手段がないとしている。設定はオフにもできるが、自分と相手のメッセージが AI に読まれる恐れがある。
