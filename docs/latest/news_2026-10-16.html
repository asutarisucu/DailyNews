shopify
🔗 Shopify Developer Blog

shopify
🔗 Shopify Developer Changelog

Shopify が Shop MCP（Model Context Protocol サーバー）を公開し、任意の AI エージェントがカタログ検索・カート操作・Shop Pay チェックアウトを処理できるようになった。開発者は MCP 対応の任意のエージェントフレームワークから Shop MCP を呼び出すだけで Shopify のコマース機能を統合できる。ローンチ時点ではウェブフックが存在しないため、チェックアウト状態の取得は get_checkout のポーリングで行う必要がある点に注意。

🔗 Cybersecurity News

Palo Alto Networks の PAN-OS 管理インターフェースにコードインジェクション脆弱性 CVE-2026-0322（CVSS 8.6）が発見され、ネットワークアクセス権を持つ認証済み攻撃者が root 権限で任意コードを実行できることが判明した。CISA が KEV カタログに追加し、Palo Alto 自身も限定的な悪用事例を確認している。管理インターフェースへのアクセスを信頼済みIPに制限することが緊急緩和策として推奨されている。
