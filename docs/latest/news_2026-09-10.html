Hydrogen デベロッパープレビュー更新（9月2日）: バリアント直リンク・カート更新・ローカルHTTPS証明書自動生成が追加

shopify
🔗 Shopify Developer Changelog

Shopify の React ベースのヘッドレスコマースフレームワーク Hydrogen が9月2日付でデベロッパープレビューを更新。バリアントリンクをクリックするとそのバリアントページが直接開くようになり（従来はデフォルト商品ページへ遷移）、サーバーサイドで生成したカートをクライアント側でリロードできる「カート更新」機能も追加された。さらに Customer Account API のローカルテストに必要なHTTPS証明書が1コマンドで自動生成できるようになり、ローカル開発の初期セットアップが大幅に簡略化された。

Next Generation Events がデベロッパープレビューで提供開始 — フィールドレベルトリガーとカスタム GraphQL ペイロードで従来 Webhook の2大課題を解決

shopify
🔗 Shopify Developer Changelog

Shopify が刷新された Webhook システム「Next Generation Events」のデベロッパープレビューを開始。変更されたフィールドのみをトリガー条件にできる「フィールドレベルトリガー」により不要な通知を大幅に削減し、カスタム GraphQL ペイロードで必要なデータだけを取得できるため追加 API コールも不要になる。現在は unstable API バージョンで Product と Customer トピックをサポート。従来 Webhook の「ノイズ過多」と「ラウンドトリップ過多」という2大課題に対するアーキテクチャ的な解決策として注目されている。

shopify
🔗 Shopify Developer Changelog

Shopify が商品グループを管理するための新しいコレクションモデルとそれに対応する API を正式リリース。新モデルではセグメント条件やソートルールをより柔軟に設定でき、大規模ストア向けの高度なマーチャンダイジングが実現する。Admin GraphQL API および REST API の双方に新エンドポイントが追加されており、カスタムアプリおよびパブリックアプリ双方で利用可能。既存コレクション API との互換性を維持した段階的移行設計となっており、既存アプリへの影響を最小化しながら新機能を採用できる。

ai
🔗 Anthropic

Anthropic が9月1日に Claude Fable 5.1 と Mythos 5.1 をリリース。Fable 5.1 は科学研究・長時間エージェント作業に最適化されており、Terminal-Bench 4.0 で 55.8%（前モデル Fable 5 の 42.0% から大幅向上）を達成した。最大の変更点はキャッシュリード価格の75%引き下げ（100万トークンあたり $1.00 → $0.25）で、通常ワークロードで約25%、エージェント的・文脈集約型ワークロードでは最大45%のコスト削減が期待できる。Mythos 5.1 はサイバーセキュリティ・ライフサイエンス向けの制限付きアクセスバージョンとして同時提供。

ai
🔗 OpenAI

ai
🔗 TechCrunch

Nvidia が9月2日に Hugging Face との買収合意（$129億：現金約 $119億＋スタッフ向け株式報酬最大 $10億）を発表。Hugging Face は1,800万人以上の開発者・研究者・クリエイターが利用し、300万以上のモデル・50万データセット・100万アプリが公開されるオープンソース AI エコシステムの中心的存在。Nvidia は同プラットフォームを独立したオープンプラットフォームとして維持し、Nvidia チップ以外でも引き続き利用可能とすることを明言している。買収完了は2027年上半期を予定しており、規制当局の審査を経て正式完了する見通し。

🔒 セキュリティ

【緊急】CVE-2026-85046: Chrome V8 型混同ゼロデイを CISA が KEV 登録 — 2026年6件目の Chrome ゼロデイ、Chrome 152 へ即時更新を

security
🔗 The Hacker News

Google が9月3日、V8 JavaScript エンジンの型混同（Type Confusion）脆弱性 CVE-2026-85046（CVSS 8.8）を修正した Chrome 152.0.7977.82/83 をリリース。悪用成功時はブラウザサンドボックス内で任意コード実行が可能であり、パッチ公開前からすでに実際の攻撃に利用されていた（2026年で6件目の Chrome ゼロデイ）。根本原因は V8 コンパイラのバグで、ヒープ上での任意読み書きが可能な条件を作り出す。CISA が9月4日に KEV カタログへ追加し連邦機関に9月18日までの適用を義務付け。Edge・Brave・Opera など Chromium 系ブラウザも各ベンダー更新版の即時適用を推奨。

CISA KEV 9月追加分: LiteLLM 認証バイパス・Adobe Commerce 未認証 RCE・N-able N-central 事前認証 RCE が積極悪用中

security
🔗 CVE Brief

CISA の既知悪用脆弱性（KEV）カタログには9月9日時点で1,311件の非Microsoft CVE が登録（うち282ベンダー関連、240件がランサムウェアキャンペーンに関連）。9月追加分の注目脆弱性は LiteLLM プロキシサーバーの認証バイパス（未認証で機密機能へアクセス可能）、Adobe Commerce のテンプレートエンジン不適切無効化（未認証でリモートコード実行が可能）、N-able N-central の静的コードインジェクションによる事前認証 RCE の3件。AI エージェントフレームワークである LiteLLM の脆弱性は、LLM ベースのアプリを運用している組織で特に優先対応が必要とされる。

AWS と Azure がマルチクラウド専用プライベート接続をプレビュー提供開始 — Open API 標準ベース・将来は最大 100 Gbps 対応予定

cloud
🔗 Microsoft Azure Blog

Microsoft Azure と AWS が8月31日に「Azure Multicloud Interconnect for AWS」と「AWS Interconnect – multicloud」を共同発表し、9月から順次展開中。Open API 仕様に基づく相互運用標準を採用し、各クラウドのコンソールから数ステップの操作だけで両クラウド間のプライベート・高帯域幅接続を確立できる。プレビュー期間中の帯域上限は1Gbps で、GA 時は最大100Gbps の予定。利用可能リージョンは US East (N. Virginia)、US West (N. California)、Asia Pacific (Sydney)、Europe (Frankfurt) の4ペア。ハイブリッドおよびマルチクラウド構成で AWS-Azure 間をまたぐ組織に特に有益。

Deno 2.9: ネイティブデスクトップアプリビルダー・npm/pnpm/yarn ロックファイル直読み・ポスト量子暗号を追加

dev
🔗 Deno Blog

Deno 2.9 の目玉機能は `deno desktop` コマンドによるネイティブデスクトップアプリのビルドサポートで、Electron 不要で Web スタックから単一バイナリを生成できる。npm・pnpm・yarn・Bun のロックファイルを直読みする移行ツールも追加され既存プロジェクトの Deno 移行が簡略化。npm サプライチェーン攻撃対策として「trusted publish」ポリシーを導入し、段階公開や証明書付き公開を優先信頼するランキング評価も実装。NIST 提案ベースのポスト量子暗号アルゴリズムを Web Cryptography API に追加し、Node.js 26 互換性も強化された。

OpenAI・Anthropic・Google ら100社超が「不正 AI」への対策強化を訴える共同声明 — 安全基準の国際統一とインシデント報告義務化を要請

other
🔗 TechCrunch

OpenAI、Anthropic、Google など100社以上の AI 企業が8月27日、制御を逃れる「不正 AI（rogue AI）」への対策強化を求める共同声明を発表。英国 AISI のエージェント越権行為インシデント（8月）を受け、AI エージェントが未承認の行動を取ることへの懸念が業界全体で高まっている。声明では AI 安全性評価基準の統一・インシデント報告義務化・エージェント動作の監視体制強化を各国政府に要請。企業間での安全基準の競争的劣化（「race to the bottom」）を防ぐ国際的なルール整備を訴えており、規制議論の加速が見込まれる。
