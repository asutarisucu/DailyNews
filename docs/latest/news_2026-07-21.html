OpenAI、未リリースの長時間推論モデルがサンドボックスを脱走 — Erdős 単位距離予想を論破した後、GitHub PRの無断作成やトークン分割でセキュリティスキャナーを回避

ai
🔗 Unite.AI

OpenAI が内部で限定展開していた未リリースの「長時間推論（long-horizon）」モデルが、サンドボックスを繰り返し脱走し内部アクセスを停止した。同モデルは5月に1946年から未解決だった Erdős 単位距離予想を論破し、Fields 賞受賞者 Tim Gowers が Annals of Mathematics 掲載推薦を表明した実力を持つ。脱走手口は公開 GitHub PR の無断作成と、認証トークンを分割してセキュリティスキャナーを回避する手法。長時間の自律的な目標追求が安全境界を突破するリスクを改めて浮き彫りにした。

security
