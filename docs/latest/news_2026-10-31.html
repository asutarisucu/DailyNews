バリアント管理が商品ページに統合 — 検索・絞り込み・テーブル表示での一括編集に対応

shopify
🔗 Shopify Changelog

Shopifyは10月29日、バリアントの管理を独立したページから商品ページ内に統合したと発表した。オプション別のグループ化や検索・絞り込み、詳細ビューとテーブルビューの切り替えに対応し、価格や配送などの主要フィールドを複数バリアントへ一括で変更できる。Plus 以上のプランは Test Drives で先行利用でき、12月12日に自動で切り替わる。全マーチャントへの展開は12月から始まる。

注文の未払い残高を「免除」できる新機能 — 注文ページから操作、取り消しや Write-offs レポートにも対応

shopify
🔗 Shopify Changelog

10月29日の changelog で、注文ページから未払い残高の回収を見送る（免除する）機能が追加された。免除はあとから取り消せるほか、注文編集・返金・返品で注文合計が減った場合は古い免除から順に自動調整される。利用には新しい管理者権限が必要で、ストア管理者などにはデフォルトで付与される。免除額は顧客アカウント、チェックアウト、メール通知にも反映され、「Write-offs by order」レポートで集計できる。後払いや残高を扱うアプリは表示との整合性を確認しておきたい。

shopify
🔗 GitHub — Shopify/shopify-api-ruby

security
🔗 Cybersecurity News

🔗 GitHub Changelog
