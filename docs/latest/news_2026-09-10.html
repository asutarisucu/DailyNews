🔗 Shopify Developer Changelog

Shopify GraphQL Admin API 2026-07 で新しいコレクションモデルが正式提供開始となった。従来の「カスタムコレクション」「スマートコレクション」の二択から、複数のソース（自動ルール・手動リスト・除外・別コレクション・アプリ提供商品）を組み合わせて構成する「ソースベース」モデルへと刷新された。既存のコレクションはそのまま引き続き機能し、2026-07 では非推奨メンバーも引き続きクエリ可能なため段階的な移行が可能。複数ソースの混在・バリアント単位の対象指定・他コレクションの参照など柔軟なマーチャンダイジングが実現する。

Anthropic、Claude Fable 5.1 と Mythos 5.1 をリリース — キャッシュ読み取りコスト75%削減、Terminal-Bench-Science で 52.6% を達成

ai
🔗 Anthropic

Anthropic が9月1日に Claude Fable 5.1 と Claude Mythos 5.1 をリリースした。入出力トークン価格（$10/$50 per 100万トークン）は Fable 5 から変更なしだが、キャッシュ読み取り料金が $1 → $0.25 へ75%削減され、複雑なコーディングや高度なエージェントタスクでは最大45%のコスト削減が見込める。Terminal-Bench-Science 0.1 では 52.6% を記録し、Fable 5（24.7%）・Opus 5（29.0%）を大きく上回る。Claude API・AWS・Google Cloud・Microsoft Azure で利用可能で model ID は claude-fable-5-1。Mythos 5.1 は同じ基盤モデルをサイバーセキュリティや生命科学の審査済み組織向けに制限提供するバリアント。

OpenAI、GPT-6 Astra をリリース — コンピューター操作・自律的なエンタープライズワークフローを実現、Greg Brockman 氏が「AGI の始まり」と発言

ai
🔗 Axios

OpenAI が9月3日に GPT-6 Astra を一部組織向けにリリースし、翌4日に ChatGPT Plus・Pro・Business・Enterprise および API・AWS で一般提供を開始した。OpenAI 社長 Greg Brockman 氏は「世代的な飛躍」と表現し、AGI の始まりになり得るとのコメントを発表した。コンピューター操作機能を有し、反復深化推論（recurrent depth reasoning）によりエンタープライズワークフローを自律的にこなせると説明されている。API 価格は入力 $10・出力 $50 per 100万トークン（Fable 5.1 と同水準）。Preparedness Framework でのサイバーセキュリティ能力評価が初めて「Critical」レベルに達したため、リリース前に追加の安全対策が講じられた。

【緊急】CISA が Cisco・Citrix・Fortinet の悪用済み脆弱性3件を KEV 登録 — 連邦機関に9月12日までのパッチ適用を義務付け

security
🔗 The Hacker News

CISA が Cisco・Citrix・Fortinet に影響する実悪用中の脆弱性3件を Known Exploited Vulnerabilities（KEV）カタログへ追加し、連邦機関（FCEB）に9月12日までのパッチ適用を義務付けた。最も深刻なのは Cisco Secure Firewall Management Center の CVE-2026-20079（CVSS 10.0）で未認証リモートコード実行が可能。Citrix の CVE-2026-19490（CVSS 9.3）は NetScaler ADC/Gateway の認証バイパスで9月8日だけで36件のハニーポット侵害を確認。Fortinet の CVE-2025-25249（CVSS 7.3）はヒープバッファオーバーフローで、Node.js RAT「PivotC2」の展開に悪用され3,000以上の IP が標的となり178台が感染している。

npm 12 リリース — インストールスクリプトがデフォルト無効に、サプライチェーン攻撃リスクを大幅低減。2FA バイパストークンの廃止も段階的に開始

dev
🔗 InfoQ

npm 12 が正式リリースされ、preinstall・install・postinstall スクリプトがデフォルトで無効化された（allowScripts を明示的に許可しない限り実行されない）。サプライチェーン攻撃の主要な侵入経路だったインストールスクリプトを無効化することで、悪意あるパッケージによる被害を大幅に抑制できる。また2FA バイパスが可能だった Granular Access Tokens（GAT）の廃止も段階的に開始されており、2027年1月には直接パブリッシュも不可となる予定。あわせて pnpm 12.1（Rust CLI 採用）がワークスペースタスクスケジューラの新機能と macOS・Windows への共有ビルドアーティファクト対応を追加している。
