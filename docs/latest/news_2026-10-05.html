Next Gen Events が 2026-10 で正式 GA — 18 トピック対応、宣言的フィールド指定でフォローアップ API 呼び出し不要に

shopify
🔗 Shopify Developer Blog

Shopify は 2026-10 API バージョンとともに Next Gen Events を正式一般提供（GA）とした。Product・Customer・Order・Collection・Inventory・Content など 18 トピックにわたって、アプリが受け取りたい変更内容と必要なデータを GraphQL クエリで宣言し、単一ペイロードに収められるようになった。クラシック Webhook では必要だった後続の API 呼び出しが不要となり、開発・運用コストの大幅削減が期待される。Shopify CLI 4.83 以降でイベント API バージョンを 2026-10 に設定することで利用開始できる。
