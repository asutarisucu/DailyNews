🛒 Shopify 開発者情報

【要対応】Shopify がアプリセキュリティ強化の次の要件を告知 — 公開アプリの IP 許可リストは11月20日が期限、パートナーアカウントの MFA も必須に

shopify
🔗 Shopify 開発者ブログ

Shopify は11月14日付の開発者ブログで、一括処理（bulk operations）向け IP 許可リストへの対応に謝意を示しつつ、次に必要な対応をまとめた。すべての公開アプリは11月20日（米国東部時間 23:59）までに IP 許可リストを有効化する必要があり、未対応のアプリは App Store から非掲載となり新規インストールもできなくなる（既存のインストールは継続動作）。今後はすべてのパートナーアカウントで多要素認証（MFA）が必須になり、許可リストのないアプリは2027年4月1日以降 Admin API リクエストが失敗する段階的な強制スケジュールも示されている。

🔗 CNBC

OpenAI は、同社の AI エージェント「dots」がユーザーに代わって買い物の支払いまで行える「ChatGPT Wallet」を発表した。American Express・Mastercard・Visa のトークン化カードを使い、エージェントは実際のカード番号にアクセスせず、購入のたびに Face ID や指紋による生体認証が求められる。当初は米国の ChatGPT Pro 契約者（18歳以上・対象クレジットカード保有者）限定で、今後は支出上限やカテゴリ別の事前承認も追加予定。EC 事業者にとっては、エージェント経由の注文が不正判定でブロックされないかの確認が課題になる。

Compute Engine API に日付ベースの不変バージョンが GA — 四半期ごとのスナップショットで破壊的変更を回避

cloud
🔗 Google Cloud Blog

Google Cloud は Compute Engine API で「インターフェースベースのバージョニング（IBV）」を一般提供した。従来の単一で可変な /v1 に加え、2026-09-01 のような日付形式の不変な API スナップショットを指定でき、安定版はリリース後に破壊的変更を受けない。バージョンは X-Goog-Api-Version ヘッダーまたは $apiVersion クエリパラメーターで指定し、新バージョンは四半期ごとに公開される予定。移行は任意で、既存の /v1 利用はそのまま継続できる。
