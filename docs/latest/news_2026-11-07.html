🛒 Shopify 開発者情報

【要対応】公開アプリの Admin API 呼び出しに IP 許可リストが必須に — 一括操作は11月12日、その他は11月20日が期限

shopify
🔗 Shopify Developer Changelog

Shopify は11月5日、Admin API を呼び出すすべての公開アプリに IP 許可リスト（IP allowlist）の設定を義務付けると発表した。バルク操作を使うアプリは11月12日までに設定しないとバルクのクエリ・ミューテーションがブロックされ、それ以外の公開アプリも11月20日までに未設定だと App Store からの掲載停止と新規インストール停止の対象になる。既存インストールについては2027年1月15日からマーチャント向けの警告が始まり、4月1日以降は許可リスト外からの Admin API リクエストが 403 で失敗する。固定 IP のアプリはアドレスや CIDR を、サーバーレスなど動的なインフラでは ASN 単位で登録でき、Dev Dashboard で直近のトラフィックに対する事前テストも可能。カスタムアプリやマーチャント作成アプリは対象外。

OpenAI のエージェント群が Linux カーネルで948件の root 権限昇格バグを発見 — 未公開のサイバー特化モデルで検証、修正パッチも提案

ai
🔗 OpenAI

OpenAI は11月4日、開発中のサイバーセキュリティ向けモデルを使ったエージェントパイプラインが、Linux カーネルで一般ユーザーから root を奪える局所権限昇格（LPE）の脆弱性を948件見つけ、検証したと公表した。偵察役のエージェントが一般ユーザーから到達できるコードを洗い出し、分析役のエージェントが欠陥を探す構成で、対象はカーネル全体の約7%にあたる約280万行。10月中旬の実行で API コストは約120万ドル、少なくとも10種類の新しい攻撃手法も見つかったという。すでに数百件の報告と修正パッチ案をメンテナーに送っているが、Help Net Security はエージェントの自己申告結果が常に正しかったわけではない点も指摘している。

🔒 セキュリティ

OpenSSH の「SSHole」（CVE-2026-123158）が公開から9時間以内に攻撃に — ハニーポットで root 奪取を確認、10.6p2 で修正

security
🔗 Help Net Security

musl 系 Linux（PAM なし）の OpenSSH で、パスワード無効化済みアカウントにログインできる認証バイパス「SSHole」に、CVE 番号と悪用状況の続報が出た。脆弱性は CVE-2026-123158（CVSS 8.1）で、OpenSSH 10.6p2 で修正され、Alpine Linux は 3.16 から edge までの全ブランチに同日中に修正パッケージを配布した。Previdian は公開から9時間足らずで最初の攻撃を観測し、本物の Alpine Linux を使ったハニーポットで root 取得まで確認したという（日本に位置する単一 IP から8回の試行）。Alpine の既定構成が条件に当てはまるため、早急な更新と sshd の再起動が推奨される。

🔗 Bitdefender Labs

Bitdefender は、細工した APK を端末にインストールするだけで Android のシステムが繰り返しクラッシュし、再起動やセーフモードでも抜け出せなくなる不具合「GhostMap」を公表した。Android 内の2つのコンポーネントが同じ ZIP ファイルを異なる方法で解釈することが原因で、Android 10 以降が影響を受けるという。8月に報告したものの、Google はセキュリティ修正の対象外と判断し、将来のバージョンで検討するとした。復旧には初期化（データ消去）しかなく、現時点で実際の悪用は確認されていない。

🔗 SC Media

security
🔗 SentinelOne 脆弱性データベース

暗号資産決済用の WordPress プラグイン「CryptoPayment Gateway」（1.2.1〜1.2.2）に、AJAX 処理の認可漏れによる最大深刻度の脆弱性 CVE-2026-81648 が見つかった。未認証の攻撃者が管理者向け操作を呼び出せ、任意ファイルの削除や決済設定の上書き、保存されたウォレット認証情報の平文での取得が可能になる。修正版はなく、Defused Cyber が実際の悪用の試みを観測している。プラグインの削除、ウォレット鍵・シークレットのローテーション、決済設定とサーバーファイルの監査が推奨されている。

☁️ クラウド

Azure Front Door の耐量子 TLS 鍵交換ポリシーが GA — ML-KEM を組み合わせたハイブリッド TLS 1.3 に対応

cloud
🔗 Microsoft Tech Community

Microsoft は11月5日、Azure Front Door の TLS 鍵交換ポリシーで耐量子暗号（PQC）のサポートを一般提供（GA）とした。従来の楕円曲線と NIST 標準の ML-KEM を組み合わせたハイブリッド鍵交換を使え、カスタムドメインごとに Standard / Enhanced / Custom のポリシーを選べる。対象はクライアントとエッジ間の接続のみで、Front Door からオリジンへの接続は含まれない。ハイブリッド方式には TLS 1.3 と対応クライアントが必要で、TLS 1.2 を許可する場合は従来の鍵交換グループも含める必要がある。

Google の Agentic Data Cloud がクロスクラウド Lakehouse を強化 — AWS / Azure 上のデータを可変エグレス費なしでクエリ、相互接続とキャッシュが GA

cloud
🔗 Techzine

Google Cloud は、Agentic Data Cloud の拡張として、AWS や Azure に置いたデータを可変のエグレス費用なしでクエリできるクロスクラウド Lakehouse を打ち出した。AWS・Azure とのクロスクラウド相互接続とキャッシュが GA となり、取得したデータブロックは Google Cloud 側にキャッシュされる。基盤は Apache Iceberg で、AlloyDB からはクラウドストレージ上の Iceberg テーブルを稼働中の業務データと1本の PostgreSQL クエリで結合できる。自己学習型の Knowledge Catalog や AlloyDB Express も併せて発表された。

AWS 11月5日のアップデート — RDS のスナップショット単位課金、Lambda Managed Instances の SOCI 遅延読み込みなど

cloud
🔗 FinOps Weekly

AWS の11月5日前後の更新では、RDS のスナップショット料金が DB インスタンス単位の集計ではなくスナップショットごとに表示されるようになり、バックアップコストの配賦やタグ付けがしやすくなった。Lambda Managed Instances では SOCI による遅延読み込みが使えるようになり、起動時間を最大70%短縮できるという。ほかに ECS Managed Instances のインスタンス統合（Spot 含む）によるアイドル容量の回収、AWS Config の対応リソースタイプ10種追加、RDS for Oracle の M8i / R8i インスタンスの対応リージョン拡大が含まれる。
