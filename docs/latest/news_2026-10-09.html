🔒 セキュリティ

Citrix NetScaler ADC / Gateway にゼロデイ RCE（CVE-2026-88771/88772）— CISA が世界規模の悪用を確認、緊急パッチを要求

security
🔗 CISA

CISA が Citrix NetScaler ADC および Gateway を対象とした 8 件の CVE（CVE-2026-88771〜88778）に関する緊急アラートを発行した。うち CVE-2026-88771 と CVE-2026-88772 はいずれもクリティカルなゼロデイで、認証なしにリモートコード実行が可能。脅威アクターによるグローバルでの悪用が確認されており、影響を受けるすべての Citrix 環境への即時パッチ適用が求められている。

CISA KEV に Zammad の 2 CVE を追加（CVE-2026-102489/102490）— セッション固定・特権昇格、ローカルユーザーが root 取得可能

security
🔗 CISA

CISA が Known Exploited Vulnerabilities カタログに Zammad のセッション固定脆弱性（CVE-2026-102489）と不適切な特権管理脆弱性（CVE-2026-102490）を追加した。特権管理の欠陥はクリティカル評価で、ローカルユーザーが root 権限へ昇格できる。連邦機関は BOD に基づき優先的なパッチ適用が義務付けられており、Zammad を利用している組織は早急な対応が推奨される。

Cisco が 10月7日付でNX-OS / APIC の重大脆弱性を一斉パッチ — Nexus 3000/9000 MPLS OAM RCE など CVSS 9.8 複数件

security
🔗 Cisco Security Advisory

Cisco PSIRT が 10月7日付でセキュリティアドバイザリを一括公開した。Nexus 3000/9000 スイッチの MPLS OAM および NGOAM に関するリモートコード実行、NX-OS NX-API、Application Policy Infrastructure Controller（APIC）の API コマンドインジェクションを含む複数の重大脆弱性が対象で、いくつかは CVSS スコア 9.8 に評価されている。各アドバイザリに記載の修正バージョンへのアップグレードが推奨される。
