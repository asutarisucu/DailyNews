【API 2026-10 破壊的変更】Customer Account API から lastIncompleteCheckout と Checkout タイプが削除 — Storefront API カートフローへの移行が必要

shopify
🔗 Shopify Developer Changelog

API バージョン 2026-10 にて、Customer Account API の Customer.lastIncompleteCheckout フィールドおよび Checkout 型が完全に削除される。これらはすでに deprecated として null を返していた。バイヤーのカート・チェックアウト状態を取得している場合は Storefront API のカートフローへの移行が必須。また、Built for Shopify ステータスを維持するには 2026年12月1日までに Customer Account API での認証実装が要件となる。

Market-driven shipping Admin API が 2026-07 で提供開始 — マーチャント所有配送プロファイル API は非推奨へ

shopify
🔗 Shopify Developer Changelog

Shopify Admin GraphQL API 2026-07 より、マーケット単位で配送設定を行う Market-driven Shipping API が利用可能になった。複数の料金タイプ・条件・リアルタイムキャリア取得をサポートし、別途配送プロファイルリソースを作成せずに市場ごとの配送戦略を設定できる。既存のマーチャント所有配送プロファイル API (DeliveryProfile) は非推奨となるため、market-driven shipping を使用するショップはAPIの移行が必要。
