🛒 Shopify 開発者情報

【要確認】Dev Dashboard で Admin API トークンの有効期限強制をオプトイン可能に — 既存公開アプリの強制は2027年4月1日から

shopify
🔗 Shopify 開発者 changelog

Shopify は11月16日、Dev Dashboard から Admin API トークンの有効期限（expiry）強制を任意で有効化できる設定を追加した。有効にするとアプリがインストールされた全ストアに適用され、期限なしのオフライントークンや残り24時間超のデリゲートトークンを使った Admin API リクエストは失敗するようになる。既存の公開アプリに対する強制開始（2027年4月1日）より前に、期限付きトークンへの移行が正しく済んでいるかを本番相当で検証する手段として使える。設定は後からオフに戻すこともでき、全アプリ種別が対象。

【要確認】Optimizely 経由のサプライチェーン攻撃で CNN・BBC・Zoom など約180サイトにマルウェア — カード情報窃取と iPhone 狙いのエクスプロイト

security
🔗 BleepingComputer

Web 最適化プラットフォーム Optimizely の顧客が編集できる「Project JavaScript」欄に悪意あるコードが注入され、11月16日に CNN・Fox News・BBC・Salesforce・Zoom・HSBC など約178組織のサイト訪問者へ配信された。スクリプトは暗号資産の送金先アドレスのすり替え、カード情報のスキミング、Cookie 窃取を行い、旧版 iOS を狙うエクスプロイトキット「Coruna」「DarkSword」も読み込んでいたと報じられている。Optimizely は脆弱性を修正し注入コードを削除済みで、Apple は悪用された証明書をブロックした。Optimizely のドメインを CSP で許可していても防げない点が教訓で、EC サイトは外部スクリプトの監視を見直したい。

security
🔗 The Register

理化学研究所は、11月10〜13日に富岳の稼働状況を表示する Web ダッシュボードが攻撃を受け、侵入者が内部ネットワークを横移動して利用者データを保管するサーバーにマルウェアを設置したと発表した。13日に富岳へ直接ログインしようとする試みが確認されたため、システムを停止している。富岳の利用者4,222人と「Rikyu」の利用者375人の氏名・メールアドレスなどが漏えいした可能性があり、SSH 秘密鍵などの流出も調査中と報じられている。再稼働の時期は未定。

Tor が継続中の DDoS 攻撃を受けて緊急アップデート 0.4.9.17 を公開 — リレー運用者に即時更新を要請

security
🔗 BleepingComputer

Tor Project は、ネットワークのリレーに対する大規模な DDoS 攻撃が続くなか、防御を強化したリレーソフトウェア 0.4.9.17 を緊急リリースした。攻撃は大量の回線（サーキット）作成要求でリレーを飽和させるもので、新版では IPv6 クライアントを単一アドレスではなく /64 ブロック単位で数えるよう制限を改めた。同プロジェクトは追加のリリースも予告しており、リレー運用者に早急なアップデートを呼びかけている。

AWS IAM に「Access Troubleshooter」— AccessDenied エラーに認可 ID を付与し、評価されたポリシーを特定可能に

cloud
🔗 AWS What's New

AWS は、対応サービスの AccessDenied エラーメッセージに一意の認可 ID を含める「IAM Access Troubleshooter」を発表した。ID からコンソールまたは GetRequestAuthorizationDetails API で、アクションとリソースの組ごとの評価結果（許可・明示的拒否・暗黙的拒否）と考慮されたポリシーを確認できる。詳細は拒否から24時間保持され、利用には iam:TroubleshootAccess 権限が必要。どのポリシーが原因で拒否されたかを推測で探す手間が大きく減る。

【要確認】11月の月例更新で Windows のライセンス認証が失敗（0x80041008）— Microsoft が定例外の修正更新5件を公開

other
🔗 BleepingComputer

Microsoft は、11月の Patch Tuesday 更新を適用した Windows 10 / 11 / Server で、slmgr.vbs による KMS ドメイン指定やプロダクトキー投入時にライセンス認証がエラー 0x80041008 で失敗する問題を認め、定例外（OOB）の累積更新5件を公開した。KMS 認証済みの端末は最大180日間認証状態を保つため直ちに影響は出にくいが、新規セットアップやキー変更を行う環境は要注意。ビルドごとに KB 番号が異なるため（例：Windows Server 2025 は KB5136489）、管理者は対象の更新を確認したい。
