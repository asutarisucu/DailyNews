🛒 Shopify 開発者情報

パートナーが Shopify App Store からのアプリ取り下げを自分で実行可能に — サンセット日は30日以上先を指定

shopify
🔗 Shopify 開発者 changelog

Shopify は、Partner Dashboard の「アプリ ＞ 対象アプリ ＞ 配信」から「Remove from App Store」を選ぶだけで、開発者自身がアプリを App Store から取り下げ、サンセット（提供終了）日を設定できるようにした。サンセット日は30日以上先を指定する必要があり、これまでのように Shopify サポートへ連絡する必要はなくなった。掲載の取り下げは即時かつ取り消し不可で、インストール済みのマーチャントはサンセット日まで引き続き利用できる。マーチャントへの告知、課金の停止、アンインストールは Shopify が代行しないため、開発者側での対応が必要となる。

ai
🔗 Forbes

Anthropic は11月19日、ティッカー「ANT」で Nasdaq での取引を開始した。公開価格83ドルに対し初値は111.50ドルで、時価総額は寄り付き時に一時2兆ドルを超えたが、その後は上げ幅を縮め、終値は97.17ドル（公開価格比約17%高）だった。調達額は約813億ドルで、史上最大の IPO となった。

OpenAI が外部の安全性評価機関4社を社内に受け入れ — Apollo Research、METR、Transluce、Goodfire と契約

ai
🔗 OpenAI

OpenAI は、モデルの学習段階から外部組織が安全性を検証する「embedded assessments（組み込み型評価）」の第1弾として、Apollo Research、METR、Transluce、Goodfire の4団体と契約したと発表した。評価者にはモデルのチェックポイント、ソースコード、学習データ、監視システムなどへのアクセスが与えられ、機密性の高い情報を扱う場合は OpenAI のオフィスで同社の端末を使って作業する。報告書は取締役会の安全・セキュリティ委員会に未編集のまま提出される一方、OpenAI は公開前の編集や延期を求めることができ、研究者からはアクセスが約束より限定的だとの指摘も出ている。

🔒 セキュリティ

【要更新】PHP が11月のセキュリティリリースを公開 — PHP-FPM のリクエストスマグリング CVE-2026-129289 など重大な脆弱性を修正

security
🔗 Aikido Security

PHP プロジェクトは11月19日、サポート中の全ブランチ向けに 8.5.13 / 8.4.28 / 8.3.37 / 8.2.36 を公開し、計17件超の脆弱性を修正した。最も深刻な CVE-2026-129289（CVSS 4.0 で 9.2）は PHP-FPM のリクエストスマグリングで、FastCGI 接続を再利用するフロントエンド（nginx の fastcgi_keep_conn や Apache の enablereuse=on など）の構成では、認証なしで任意の PHP コードを実行される恐れがある。PHP 8.5 の解放後使用による RCE（CVE-2026-129474）や、10月の PHP2Shell 修正で残っていたセッションシリアライザの欠陥（CVE-2026-115560）も含まれる。現時点で実際の悪用は確認されていないが、早期に攻撃対象になるとの見方があり、更新できない場合は接続再利用の無効化が推奨されている。

【要更新】CISA が悪用中の脆弱性4件を KEV に追加 — Synology DSM、LiteLLM、Apache Axis、REDCap

security
🔗 CISA

CISA は11月18日、実際の悪用が確認された脆弱性4件を既知の悪用された脆弱性（KEV）カタログに追加した。対象は Synology DiskStation Manager の RCE（CVE-2024-10441）、BerriAI LiteLLM の保護されていない代替チャネル（CVE-2026-40217）、Apache Axis の安全でないリフレクション（CVE-2026-90436）、Vanderbilt REDCap のコードインジェクション（CVE-2026-90817）。Apache Axis 1.x はすでにサポートが終了している。報道によれば連邦機関の対応期限は LiteLLM 以外が11月21日、LiteLLM が12月2日と短く、LLM の API キーを狙う「LLMjacking」やクリプトマイニングへの悪用も指摘されている。

【要更新】VMware vCenter に CVSS 9.8 の認証回避脆弱性 CVE-2026-123890 — Broadcom が VMSA-2026-0009 を公開

security
🔗 The Hacker News

Broadcom は11月19日、vCenter、SDDC Manager、VMware Tools にまたがる5件の脆弱性を修正するセキュリティアドバイザリ VMSA-2026-0009 を公開した。最も深刻な CVE-2026-123890（CVSS 9.8）は VMware Directory Service の認証回避で、ネットワーク上の攻撃者が管理者として vCenter にログインできる恐れがある。一部報道は中国系グループによる9月以降の悪用を伝えているが、Broadcom のアドバイザリは悪用を確認していないとされ、情報が錯綜している。ESX 自体は影響を受けないが、vCenter 8.0 U3m / 9.0.2.0200 では VCF 9.1.1 へのアップグレード制限があるため、適用前に確認が必要。

cloud
🔗 AWS What's New

AWS は、AWS と他クラウド間をマネージドなプライベート接続で結ぶ「AWS Interconnect - multicloud」について、8月からプレビューだった Microsoft Azure との接続を一般提供した。提供リージョンは米国東部（バージニア北部）、アジアパシフィック（シドニー）、欧州（フランクフルト）の3つで、マネジメントコンソール、CLI、API から接続を作成できる。Azure 側でも ExpressRoute ベースの「Azure Multicloud Interconnect for AWS」が一般提供となり、両社が共同で運用する。これで Google Cloud、Oracle Cloud Infrastructure を含む主要クラウドとの接続が出そろった。

OpenID Connect による Amazon S3 への監査ログストリーミングが GHE.com でも利用可能に

dev
🔗 GitHub Changelog

GitHub は11月19日、OpenID Connect（OIDC）を使って Enterprise の監査ログを Amazon S3 にストリーミングする機能を、データレジデンシー対応の GHE.com でも提供開始した。OIDC を使うことで、長期間有効な AWS のアクセスキーを GitHub 側に保存する必要がなくなる。これまで github.com で提供されていた機能を GHE.com に拡大したもの。
