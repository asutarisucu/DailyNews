Liquid July '26 Developer Preview — {% block %} / {% partial %} タグ導入でテンプレートにページ構造を直接記述可能に

shopify
🔗 shopify.dev

2026年7月21日に公開されたデベロッパープレビューで、Liquidテンプレートに新しく {% block %} と {% partial %} タグが追加された。これにより、これまでの JSON テンプレート経由の間接的な構造記述から脱却し、テンプレートファイル一つにページ全体の構造とロジックをまとめて記述できるようになる。{% partial %} で定義した領域はページ全体を再読み込みせずJavaScriptで部分更新が可能。Theme Check の新ルールもあわせて追加され、ブロック引数とスキーマの不一致などをコンパイル時に検出できる。

shopify
🔗 shopify.dev

API バージョン 2026-07 以降、新しい Sources モデルを使用するコレクションが collections クエリおよびコレクションを返す全フィールドで返却されるようになった。新モデルへのアクセスにはバージョン 2026-07 への移行が必要だが、非破壊的変更のため廃止予定メンバーは 2026-07 でも引き続きクエリ可能であり段階的な移行が可能。Storefront API 2026-10 では @inContext ディレクティブに channelId 引数が追加され、販売チャネル固有の商品可用性・価格をクエリ全体に適用できるようになる。

ai

security

Microsoft の7月 Patch Tuesday では過去最多となる570件（一部集計では622件）の CVE が修正された。うち59件が Critical 評価。実際に悪用が確認されているゼロデイは CVE-2026-56155（Active Directory Federation Services）と CVE-2026-56164（SharePoint Server）の2件で、いずれも CISA の KEV カタログに追加されており、連邦機関に対してはそれぞれ7月28日・7月17日が修正期限とされた。Windows BitLocker の CVE-2026-50661 は公開済みだが実際の悪用は未確認。即時パッチ適用を強く推奨する。

Cursor IDE に「DuneSlide」ゼロクリック RCE — プロンプトインジェクションでサンドボックス脱出、Cursor 3.0 未満が全て対象（CVE-2026-50548 / 50549）

security
🔗 Cato Networks

Cato AI Labs が7月1日に開示した「DuneSlide」は、Fortune 500 の半数以上が利用する AI コードエディタ Cursor の2件の致命的なゼロクリック RCE 脆弱性（CVSS 9.8）。AI エージェントが MCP コネクタのレスポンスやウェブ検索結果を読み込むだけで、プロンプトインジェクションが発動しサンドボックス内の cursorsandbox バイナリを上書き、サンドボックスなしの任意コード実行が可能になる。ローカル環境と接続済み SaaS ワークスペースの両方が危険にさらされる。Cursor 3.0（4月2日リリース）で修正済みのため、未更新ユーザーは直ちにアップデートが必要。

Azure OpenAI に CVSS 9.9 の特権昇格脆弱性（CVE-2026-45499）— SSRF 経由でテナント間の権限昇格が可能

security
🔗 CrowdStrike

7月 Patch Tuesday で修正された CVE-2026-45499 は Azure OpenAI サービスに影響するサーバーサイドリクエストフォージェリ（SSRF）を利用した特権昇格脆弱性で、CVSS スコアは 9.9 と最高水準に近い深刻度。外部からネットワーク越しに認証なしで悪用可能とされており、テナント間での権限昇格のリスクがある。Microsoft Copilot にも別途コマンドインジェクション脆弱性が発見されており、Azure および Copilot を利用する組織は7月の累積更新を速やかに適用することが強く推奨される。
