🔗 The Next Web

Anthropic は10月27日、ライフサイエンス分野での Claude 活用の進捗を公表した。BigHat Biosciences、Bristol Myers Squibb、Generate Biomedicines など6組織と連携し、Divergence Labs では約1か月で約3万5,000件の抗体設計を生成したという。自社でも Mithril Medicine を買収して創薬プログラムを進めており、早ければ2028年後半の臨床試験開始を目指す。ただし成果はいずれも前臨床段階で、ヒトでの安全性・有効性は未検証だ。

Drupal Commerce Core のアクセスバイパス脆弱性が実際に悪用中 — 更新に加えて注文データの監査を呼びかけ

security
🔗 The Drop Times

Drupal セキュリティチームは、EC モジュール Commerce Core のアクセスバイパス脆弱性が実際に悪用されていると確認した。一部のルートやエンティティフィールドでアクセスチェックが不十分なことが原因で、ストア運営者に金銭的被害が出るおそれがある。8.x-2.41 または 3.3.13 への更新に加え、既存注文に不整合がないか監査するよう求めている。同時に公開された39件のアドバイザリのうち12件が Commerce 関連モジュールで、Commerce Stripe の CSRF なども含まれる。

JAL、Amadeus 経由の不正アクセスで約9万2,000人の予約情報が流出 — 約2,000人はパスポート番号も

security
🔗 The Record

日本航空（JAL）は10月28日、予約システムを提供する Amadeus での不正アクセスにより、JAL と日本トランスオーシャン航空の顧客約9万2,000人の氏名・予約番号・フライト情報が流出したと発表した。うち約2,000人はパスポート番号やマイレージ番号、メールアドレス、電話番号も含まれる。運航やクレジットカード情報への影響はないという。Amadeus は ANA、大韓航空、アシアナ航空にも同様の通知をしており、被害の全体像はまだ明らかになっていない。

加速器などの制御ソフト EPICS Base に4件の脆弱性 — 最重要は CVSS 9.8、7.0.11 で修正

security
🔗 SecurityWeek

CISA は10月27日、粒子加速器や研究施設の機器制御に広く使われるオープンソースの EPICS Base について ICS アドバイザリを公開した。7.0.10 以前に4件の脆弱性があり、最も深刻な整数オーバーフロー（CVE-2026-114595）は CVSS v3.1 で9.8とされ、リモートコード実行につながる可能性がある。AI エージェントによる調査で発見されたもので、修正版 7.0.11 が公開済み。現時点で悪用は確認されていないが、信頼できるクライアントのみに接続を制限することが推奨されている。

🔗 DEV Community（AWS Builders）

10月24〜30日の AWS サーバーレス関連アップデートでは、Step Functions のワークフローを Amazon Bedrock AgentCore Gateway 経由で AI エージェントのツールとして呼び出せるようになった。既存の業務ワークフローをそのままエージェントに組み込める。あわせて Bedrock AgentCore CLI が 1.0 に到達し、起動の高速化やコマンド体系の統一が図られたほか、DynamoDB Accelerator（DAX）がカナダ中部とケープタウンリージョンに拡大した。

Azure MCP Server 3.0 が一般提供に — 名前空間・設定セクション名などに破壊的変更

cloud
🔗 Azure SDK Blog

Microsoft は Azure MCP Server 3.0 の一般提供を Message Center（10月29日付）でも案内した。共有コードの名前空間が Azure.Mcp.Core.* から Microsoft.Mcp.Core.* に変わり、appsettings.json の設定セクションも MicrosoftMcp に変更。未知のパラメータを含むツール呼び出しは拒否されるようになり、azmcp resilience コマンドは resiliency に改名された。AI エージェントから Azure を操作している環境では、アップグレード前に移行ガイドを確認したい。

Azure Blob Storage のアカウント上限が1サブスクリプション・1リージョンあたり250から1,000へ（GA）

cloud
🔗 PUPUWEB（Azure Updates）

Azure は、標準エンドポイントのストレージアカウントを1サブスクリプション・1リージョンあたり最大1,000個まで作成できるよう上限を引き上げ、一般提供とした。従来の既定値は250個だった。テナントや顧客ごとにストレージアカウントを分けるマルチテナント SaaS や、大規模なデータ基盤で、サブスクリプション分割の手間を減らせる。

Node.js 26「Lithium」が Active LTS に — 2029年4月末までサポート

dev
🔗 GitHub（nodejs/node）

Node.js 26 は10月28日リリースの v26.13.0 で Active LTS に移行し、コードネーム「Lithium」が付いた。今回のリリースは LTS 指定のためのメタデータ変更のみで、2029年4月末まで更新が提供される。Node.js 26 は旧来の奇数・偶数リリースモデルによる最後のメジャーで、Node.js 27 以降は毎年4月にメジャーを出し10月に LTS 化する年1回体制に変わる。本番環境の移行計画を立てる良いタイミングだ。

【本日】GitHub Actions の macOS 14 ランナーイメージが11月2日で提供終了

dev
🔗 GitHub Changelog

GitHub Actions のホスト型 macOS 14 ランナーイメージは11月2日で廃止される。対象ラベルは macos-14、macos-14-large、macos-14-xlarge で、10月中に実施されたブラウンアウト（一時的な失敗期間）を経て、今後はこれらを指定したジョブが実行できなくなる。macos-latest（現在は macos-26）や macos-15 などへの移行が推奨されており、iOS / macOS アプリの CI を持つチームはワークフロー定義を確認したい。
