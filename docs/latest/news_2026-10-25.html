security
🔗 CISA

CISA は 10月21日、PHP の深刻な脆弱性 CVE-2026-109618 および CVE-2026-109619（通称 "php2shell"）に対し緊急アドバイザリを発出した。どちらも未認証のリモートコード実行を可能にするもので、修正バージョンは PHP 8.5.12・8.4.27・8.3.36・8.2.35。CISA は 10月22日のアップデートで SIGMA 検出ルールと追加の緩和策ガイダンスを追加した。公表時点では積極的な悪用は確認されていないが、早急なアップデートが推奨される。

BeyondTrust Remote Support の認証バイパス CVE-2026-102764 — 積極的悪用中、CISA KEV に追加

security
🔗 CISA

10月16日、CISA は BeyondTrust Remote Support バージョン 26.2.3 以前に存在する認証バイパス脆弱性 CVE-2026-102764 を KEV（既知悪用脆弱性）カタログに追加し、緊急パッチの適用を勧告した。既に積極的に悪用されており、セルフホスト環境は BT26-05-RS パッチを適用する必要がある。古いバージョンは先に 24.3.1 以降へアップグレードしてからパッチを当てること。

🔗 Rescana
