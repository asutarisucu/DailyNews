Google Cloud KMS がポスト量子暗号アルゴリズム（ML-KEM・ML-DSA・SLH-DSA）に対応 — AWS に続き GCP がポスト量子対応で先行

cloud
🔗 Refonte Learning

Google Cloud が8月、Cloud KMS のドキュメントを更新し NIST 標準の耐量子計算機暗号アルゴリズム（ML-KEM・ML-DSA・SLH-DSA）を正式にサポートリストへ追加した。これで AWS に続き GCP もポスト量子暗号対応のマネージドキーサービスを提供する体制が整った。一方、Azure の Managed HSM ドキュメントは依然として RSA・楕円曲線・AES の従来型アルゴリズムのみを記載しており、3大クラウド間でポスト量子対応の進捗に差が出始めている。長期データ保護を要する金融・政府系ワークロードでは早期評価が推奨される。

npm: bypass-2FA グラニュラートークンがアカウント管理操作を不可に — ミニ Shai-Hulud 攻撃を受けた供給チェーン強化策

dev
🔗 GitHub Changelog

npm のグラニュラーアクセストークン（GAT）で 2FA バイパス設定のものについて、8月1日よりトークン作成・削除・パスワード変更・メール変更・2FA 設定変更・パッケージアクセス変更・組織メンバー管理などのアカウント操作が不可となった。1つのトークン流出で22分以内に323パッケージの639バージョンに悪意あるコードを注入した「ミニ Shai-Hulud 攻撃」を受けた対策。直接パブリッシュは2027年1月まで引き続き可能だが、その後は OIDC トラステッドパブリッシングへの移行が必要。CI/CD パイプラインで npm トークンを使用している場合は早急な影響確認を推奨。
