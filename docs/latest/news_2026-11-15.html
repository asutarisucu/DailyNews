🛒 Shopify 開発者情報

アプリの IP 許可リストが IP アドレスと ASN の併用に対応 — 登録上限も最大250件に拡大

shopify
🔗 Shopify Developer Changelog

Shopify は11月11日、Dev Dashboard で設定するアプリの IP 許可リストについて、IP アドレス（範囲）と ASN（ネットワーク）を同じリスト内で組み合わせて登録できるようにしたと発表した。あわせて登録できる IP アドレス・範囲の上限も従来の100件から最大250件に引き上げられた。公開アプリへの許可リスト必須化（一般アプリは11月20日期限）を控え、固定 IP の一部とサーバーレス基盤を併用する構成のアプリでも設定しやすくなる。

🔒 セキュリティ

【要更新】UnrealIRCd のコマンドインジェクション脆弱性 CVE-2026-114713 が悪用中 — CISA が KEV に追加

security
🔗 The Hacker News

CISA は11月13日、オープンソースの IRC サーバー UnrealIRCd の脆弱性 CVE-2026-114713（CVSS 8.6）を既知の悪用された脆弱性（KEV）カタログに追加した。区切り文字の不適切な処理により、サーバー／IRCOp 権限で任意のコマンドを実行される恐れがある。11月7日の修正版公開の翌日から悪用が始まったとされ、6.2.7.1 以降への更新が推奨される。

Check Point Gaia OS の権限昇格脆弱性 CVE-2026-123039 も KEV 入り — PHP2Shell と連鎖して root を奪取

security
🔗 Security Affairs

CISA は Check Point の Security Gateway / Security Management に影響するローカル権限昇格の脆弱性 CVE-2026-123039（CVSS 7.8）も KEV に追加し、米連邦機関に11月16日までの対処を求めた。攻撃者は Mobile Access ポータルの PHP2Shell 脆弱性（CVE-2026-109618 / 109619）で侵入した後、この脆弱性で root 権限に昇格している。Check Point は数十社規模の顧客で悪用を確認しており、各リリースの最新 Jumbo Hotfix で修正済みだ。

乗っ取られた GitHub アカウント4,837件で CI シークレット窃取ツールを拡散 — 1,806以上のリポジトリで実行

security
🔗 The Hacker News

Aikido Security が「wfx-loot」と名付けた攻撃キャンペーンでは、11月10日以降、窃取された認証情報で乗っ取られた4,837件の GitHub アカウントが6万以上のリポジトリに探索用プルリクエストを送り、少なくとも1,806のリポジトリでシークレット窃取コードが実行された。リポジトリのシークレットや GitHub トークン、クラウド／API キー、パッケージレジストリの認証情報を盗んだ後、ワークフローの痕跡を削除する。コラボレーターや組織の権限経由で被害が及んだ例もあり、心当たりのあるプロジェクトは認証情報のローテーションが推奨される。

N-able N-central の「4EverAble2Shell」攻撃で21台のサーバーが感染 — うち19台は Hotfix 2 適用済み

security
🔗 The Hacker News

N-central のゼロデイ連鎖「4EverAble2Shell」の続報で、攻撃者が21台のサーバーに暗号資産マイナー XMRig を展開していたことが判明した。感染サーバーのうち19台は Hotfix 2 を適用済みだったという。攻撃は Apache Axis の脆弱性 CVE-2026-90436 と N-central の権限昇格バグを組み合わせたもので、N-able は Legacy API や Intune 連携など一部機能を制限している。

Cloud Run に「Ambient networking」と「express links」がプレビュー登場 — インスタンスごとのマネージド Envoy でトラフィックを制御

cloud
🔗 Google Cloud Release Notes

Google Cloud は11月13日、Cloud Run の新機能 Ambient networking をプレビュー公開した。インスタンスごとに Google が管理する Envoy サイドカーを経由してワークロードのトラフィックをルーティングし、トラフィック管理・セキュリティ・可観測性を強化する。関連機能の express links では、認証コードやサービスメッシュを用意しなくてもサービス同士を接続できる（プレビュー）。

cloud
🔗 Google Cloud Release Notes

11月13日のリリースノートによると、BigQuery で MySQL、Oracle、PostgreSQL への接続を作成し、それぞれのフェデレーションクエリに利用できるようになった（プレビュー）。Looker の BigQuery 接続では Google 公式の BigQuery JDBC ドライバーをオプトインで選べるようになった（プレビュー）。前日の11月12日には Knowledge Catalog のテーブル単位のリネージや、BigQuery の生成 AI 関数での gemini-4-hydrogen モデル対応も追加されている。

dev
🔗 Rust Blog
