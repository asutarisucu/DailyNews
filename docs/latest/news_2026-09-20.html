Customer Account API に countryCode サポート追加 — 2026-10 で territoryCode は非推奨、ISO 3166-1 alpha-2 形式に移行

shopify
🔗 Shopify Developer Changelog

Customer Account API バージョン 2026-10 から顧客住所の入力・参照で countryCode フィールドがサポートされ、US や CA などの ISO 3166-1 alpha-2 形式で国コードを指定できるようになった。既存の territoryCode フィールドは非推奨となるが後方互換性は維持されるため既存インテグレーションへの即時影響はない。2026-10 採用時には countryCode への移行が推奨されており、alpha-3 形式（USA など）は受け付けられなくなる点に注意が必要。

バリアント単位で最大 20 バーコードを保存可能に — GTIN / UPC / EAN など複数コードを種別付きで一元管理

shopify
🔗 Shopify Developer Changelog

Shopify がバリアント 1 つに対して最大 20 個のバーコードを保存できる新機能を追加した。GTIN・UPC・EAN などのタイプ情報とともに登録できるため、異なるサプライヤーやマーケットプレイスが個別のコードを使用する商品でも同一バリアントで一元管理が可能になる。複数バーコードへの対応は在庫管理の精度向上とマルチチャンネル販売の効率化に直結する。
