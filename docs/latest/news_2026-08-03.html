Next Generation Events が Developer Preview 公開 — フィールドレベルトリガー・カスタムGraphQLペイロード・クエリベースフィルターで Webhook を完全再設計

shopify
🔗 Shopify Developer Changelog

Shopifyが Webhook を根本から再設計した「Next Generation Events」を Developer Preview として公開（unstable API バージョンで利用可）。Product・Customer トピックが先行対応し、Order・Inventory は2026年中に順次追加予定。フィールドレベルトリガーにより price 変更のみを監視する購読が可能になり、カスタムGraphQLペイロードで自アプリに必要なフィールドだけを受け取れる。購読設定は shopify.app.toml に記述してコード管理できるため、レビューやデプロイフローに自然に組み込める。

App Home を UI Extension として構築可能に — admin.app.home.render ターゲットでバックエンド不要の管理画面ページを実現

shopify
🔗 Shopify Developer Changelog

カスタム配信Appを対象に、Shopify 管理画面の App Home ページを UI Extension（admin.app.home.render ターゲット）として構築できるようになった（API 2026-07 以降）。Preact + Polaris Web Components で開発し、コンパイル後のバンドルサイズ上限は圧縮後 64 KB。自前ホスティングが不要になり、CDN・SSL・可用性管理をShopifyに委任できる。ただしパブリックApp（App Store 掲載）は引き続き iframe 方式を使用すること。

SubscriptionBillingAttempt の廃止フィールド削除 — errorCode・errorMessage を利用中の App は今すぐ移行が必要

shopify
🔗 Shopify Developer Changelog

GraphQL Admin API の SubscriptionBillingAttempt タイプから廃止済みフィールド errorCode および errorMessage が削除された。代替として billingAttemptErrorCode フィールドへの移行が必要。購読課金ロジックでこれらフィールドを参照している App は、対象 API バージョンへのアップグレード前に必ず移行作業を完了すること。

shopify
🔗 Shopify Developer Changelog

2026年10月リリース予定の API バージョン 2026-10 に複数の破壊的変更が予告されている。Customer Account API では Customer.lastIncompleteCheckout および Checkout タイプが削除。GraphQL Admin API では無効なメタフィールドクエリが 2026-07 以前の「無視」から「エラー」に変更。Storefront API では @inContext ディレクティブに channelId 引数が追加。秋のバージョンアップ前に影響範囲の確認と対応を進めておくこと。

ai
🔗 OpenAI

OpenAI の次世代モデル「Astra」の内部バージョンが、群論・高次元幾何・符号理論・量子複雑性・格子暗号・組合せ数学にわたる10問の未解決数学問題を解決し、機械検証済み Lean 証明を公開した（8/1）。目玉はミハイル・グロモフが1999年に提唱したソフィシティ概念以来初の「非ソフィック群」の明示的構成。249ページの論文集に各問の Lean 証明書が添付されており、Fields 賞受賞者 Timothy Gowers が「査読誌に推薦できる」と評価。GPT-5.6 Sol APIの料金換算で全10問のコンピュート費用は約 $2,000。

security
🔗 CISA

CISA が7月29日、Cisco Secure Firewall Management Center（旧 Firepower Management Center）のハードコードパスワード脆弱性 CVE-2026-20316（CVSS 8.9 / High）を Known Exploited Vulnerabilities カタログに追加。未認証の遠隔攻撃者が低権限アカウントで FMC Web インターフェースに認証可能で、機密情報へのアクセスリスクがある。Cisco は7月に野生での実際の悪用を確認。連邦機関の対応期限は8月1日。FMC 環境はただちにパッチ適用状況を確認すること。

npm、bypass-2FA グラニュラーアクセストークンの機密操作を7/31より制限 — トークン作成・メンテナー変更・Org 管理が不可に

security
🔗 GitHub Changelog

npm が7月31日、2FA バイパス設定のグラニュラーアクセストークン（GAT）から機密操作の実行権限を剥奪。対象はトークンの作成・削除、リカバリーコード生成、アカウントパスワード/メール/プロフィール/2FA 設定変更、パッケージアクセス・メンテナー変更、Org・チームメンバーシップ管理など。漏洩した bypass-2FA トークンでアカウントを乗っ取り新規トークンを発行するサプライチェーン攻撃の根本的な攻撃面を排除。2027年1月頃には直接 publish 権限も制限される予定。

npm 12 リリース — インストールスクリプトをデフォルト無効化でサプライチェーンリスクを大幅低減、bypass-2FA トークンの段階的廃止も開始

🔗 The Hacker News

npm 12 が正式リリースされ、パッケージインストール時のスクリプト（preinstall / postinstall 等）がデフォルトで無効化された。悪意あるパッケージがインストール直後に任意コードを実行するサプライチェーン攻撃の主要な攻撃ベクターを封じる変更。必要な場合は --allow-scripts フラグまたは設定で明示的に許可する形になる。また bypass-2FA グラニュラーアクセストークンの廃止フローとも連動しており、レジストリ全体のセキュリティ基盤の刷新が着々と進んでいる。
