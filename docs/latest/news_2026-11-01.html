🛒 Shopify 開発者情報

Shopify 初の秋版「Fall '26 Edition（Exponential）」— AIエージェント対応を軸に150以上のアップデート

shopify
🔗 Shopifreaks

Shopifyは10月28日、Summer と Winter の間に出す初の秋版 Edition「Fall '26 Edition（Exponential）」を公開した。150件以上の更新の中心は AI エージェントで、Shop Pay の対応エージェント拡大や、複数のストア変更をまとめてステージングできる Sidekick の刷新などが含まれる。開発者向けには、ストアをエージェントから扱えるようにする WebMCP、アプリのアクティビティを Shopify Analytics や ShopifyQL で扱える App Events、埋め込みアプリからプロンプト付きで Sidekick を開ける Launch API などが紹介されている。詳細は公式の Editions ページと開発者 changelog で確認したい。

🤖 AI・機械学習

OpenAI・Google・Microsoft・Anthropic が共通の「AI学習オプトアウト」シグナルに対応へ — robots.txt の1行で一括拒否

ai
🔗 Thurrott.com

OpenAI、Google、Microsoft、Anthropic の4社は10月30日、Webサイトが robots.txt に記述する共通のポリシートークンを尊重し、AI モデルの学習用クローリングを一括で拒否できるようにすると表明した。IETF で策定された仕組みで、国際標準化を目指す。Anthropic はすでに対応を開始しており、OpenAI は今後数か月以内、Microsoft は2027年2月1日、Google は2027年中の対応を予定している。対象は学習用途のみで、検索インデックスやクローラーそのものを止めるものではない点に注意が必要だ。

Gemini API の Computer Use ツールが一般提供（GA）に — Interactions API と GenerateContent API の両方で利用可能

ai
🔗 Google Cloud Release Notes

Googleは10月30日付のリリースノートで、Gemini モデルが画面を見ながらブラウザやアプリを操作する Computer Use ツールを一般提供にしたと発表した。Gemini API の Interactions API と従来の GenerateContent API の両方で利用できる。先週の OpenAI GPT-6.1 Terra に続き、コンピュータ操作エージェントの本番利用に向けた競争が一段と激しくなっている。

🔒 セキュリティ

Android の「SMS of Death」エクスプロイトが公開 — 細工したSMS1通で未修正端末をクラッシュ、緊急通報も妨害

security
🔗 BleepingComputer

研究者が、最近修正された Android の脆弱性（CVE-2026-58882 と報じられている）の概念実証コードを公開した。細工したテキストメッセージを1通送るだけで端末をクラッシュさせたり、緊急通報を含む通話を妨害したりできるという。Google は10月の Android セキュリティアップデートで修正したとされるが、同月の公開ブレティンには記載がなく、Android 12 / 13 の端末は引き続き影響を受けると報じられている。業務用端末を管理している場合はパッチレベルを確認したい。

合計1,340万インストールの Chrome 拡張機能319個が検索を乗っ取り — 広告収益目的でリダイレクト

security
🔗 BleepingComputer

サプライチェーンセキュリティ企業 Socket の報告によると、合計で約1,340万回インストールされた319個の Chrome 拡張機能が、ユーザーの検索を別の検索経由へリダイレクトし、広告収益を得ていた。一見無害なユーティリティ系拡張に紛れ込んでいたとされる。企業では拡張機能の許可リスト運用や、インストール済み拡張の棚卸しを改めて検討したい。

WordPress コアの新たな脆弱性が攻撃の標的に — パッチ公開直後から悪用の試み

security
🔗 SecurityWeek

SecurityWeek によると、WordPress コアで修正されたばかりの高深刻度の脆弱性が攻撃者に狙われている。報道では、認証不要の競合状態（レースコンディション）を突いてリモートコード実行につながる可能性がある欠陥とされ、パッチ公開後まもなく悪用の試みが観測された。WordPress は直近のセキュリティリリース（7.1.4）でコア更新処理の競合状態を修正しており、自動更新を無効にしているサイトは早急に最新版へ更新すべきだ。

悪用中の Windows Shell 脆弱性 CVE-2026-96951 に Microsoft Edge も追加 — 154.0.4258.62 未満は要更新

security
🔗 The Back Room Tech

Microsoftは、10月の Patch Tuesday で修正し、実際の悪用が確認されている Windows Shell のセキュリティ機能バイパス脆弱性 CVE-2026-96951 のアドバイザリを改訂し、影響製品に Microsoft Edge を追加した。ダウンロードファイルに付く Mark of the Web の警告を回避される恐れがある。Edge 154.0.4258.62 より前のバージョンは更新が必要で、Windows 側のパッチだけでなくブラウザのバージョンも確認したい。
