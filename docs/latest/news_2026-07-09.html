Admin GraphQL API 2026-07: Market-driven Shipping が正式対応 — 市場ごとに配送戦略を直接設定可能に

shopify
🔗 Shopify Developer Changelog

Admin GraphQL API バージョン 2026-07 より、別途配送プロファイルリソースを作成することなく、市場（Market）に直接配送設定を行う「Market-driven Shipping」が利用可能になった。また、アプリ所有の配送プロファイルに新フィールド coversAllItems が追加され、認可されたアプリがすべての発送可能商品に配送レートを適用する際、商品ごとの個別割り当てが不要になった。国際展開を行うマーチャントにとって柔軟な配送ロジック構築が容易になる。

Shopify 新コレクションモデル (2026-07) GA — sources フィールドで複数ソース・バリアントレベルのメンバーシップに対応

shopify
🔗 Shopify Developer Changelog

数年ぶりの大規模刷新となる新コレクション API が 2026-07 で一般提供（GA）になった。新しい Collection.sources フィールドは、商品を型付きの包含条件とマニュアル選択で返す1つ以上のソースをサポートし、除外条件も指定可能。複数プロダクトグループソース・アプリ所有のシェア可能ソース・バリアントレベルのコレクションメンバーシップなど、これまで不可能だったコレクション構成が実現できるようになった。

【破壊的変更】POS UI Extensions 2026-07: 固定割引は per-unit（単価ベース）表記が必須化

shopify
🔗 Shopify Developer Changelog

POS UI Extensions API バージョン 2026-07 より、固定額のライン割引（fixed-amount line item discount）は per-unit（単価ベース）での表記が必須になった。以前のバージョンまで行われていた自動変換処理は廃止される。POS向けアプリで固定割引を扱っている開発者は、計算ロジックを単価ベースに更新する必要がある。同バージョンへのアップグレード前に動作確認を推奨。

🔗 The Hacker News

CISA が7月1日付で CVE-2026-45659（Microsoft SharePoint Server のデシリアライゼーション RCE、CVSS 8.8）を KEV カタログに追加。Siteメンバー権限以上の認証ユーザーがネットワーク経由で任意コードを実行できる。Microsoft は5月にパッチを公開済みだが、連邦機関の修復期限は7月4日に設定された。6週間の猶予で悪用に至る典型的な「n-day」攻撃パターンであり、SharePoint Server Subscription Edition・2019・2016 を保有する組織は即時パッチ適用が必須。

CISA BOD 26-04 発行: FCEB機関にリスクベースの脆弱性優先修復を義務化 — KEVカタログ遵守が法的要件に

security
🔗 CISA

CISA が Binding Operational Directive（BOD）26-04「リスクに基づくセキュリティアップデートの優先化」を発行した。連邦市民行政機関（FCEB）に対し、KEV カタログに掲載された CVE を優先的に迅速修復することを義務付けるもので、KEV カタログの法的拘束力が強化された。2026年のランサムウェア攻撃者は VPN アプライアンス・エッジセキュリティ機器・リモート管理ツール・ID プラットフォームに対する KEV を重点的に悪用しており、早期パッチ適用の重要性が改めて強調されている。
