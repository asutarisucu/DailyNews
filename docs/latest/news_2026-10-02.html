Shopify API バージョン 2026-10 が安定版に — SubscriptionContractCalculation 導入、税計算・メタフィールド・注文フルフィルメント仕様を更新

shopify
🔗 Shopify Developer Changelog

2026-10-01 に Shopify API バージョン 2026-10 が安定版としてリリースされた。最大の変更点は SubscriptionContractCalculation の導入で、サブスクリプション契約の作成・更新をステートレスな「calculate → poll → commit」ライフサイクルで行えるようになり、従来の SubscriptionDraft を置き換える。また Order.displayFulfillmentStatus が FULFILLMENT_NOT_REQUIRED を返せるようになり、draftOrderCalculate/Create/Update のフィールド変更、メタフィールドフィルタのエラー修正なども含まれる。アップグレード前に各自のアプリへの影響確認が推奨される。

マーケット別配送レート（Market-Driven Shipping）が 10 月 1 日よりマーチャントへの段階的ロールアウト開始 — 全マーチャントへの展開は 2027 年 7 月まで

shopify
🔗 Shopify Developer Changelog

Shopify の Market-Driven Shipping（マーケット別配送）が 2026-10-01 より一般マーチャントへの段階的ロールアウトを開始した。配送設定をデリバリープロファイルから Markets に移行し、マーチャントがマーケットごとに配送オプションを直接設定できるようになる。2027-07-01 までに全マーチャントへの展開が予定されており、Carrier Service API・Rate Calculation 拡張・デリバリープロファイル統合を持つアプリは既存インテグレーションの検証が必要。API 2026-07 以降で GraphQL Admin API 経由の設定が可能。

Next Generation Events が開発者プレビューに — フィールドレベルのトリガー制御・カスタム GraphQL ペイロード・クエリベース配信フィルタを Webhook に追加

shopify
🔗 Shopify Developer Changelog

Shopify の「Next Generation Events」が不安定版 API で開発者プレビューとして公開された。従来の Webhook が抱えていた過剰配信・固定ペイロード・変更フィールド特定不能の 3 つの課題を解決する設計で、フィールドレベルのトリガー制御・カスタム GraphQL クエリによるペイロード指定・配信フィルタ機能を備える。現在は Product と Customer トピックに対応しており、2026 年中に追加トピックが順次拡充される予定。unstable API バージョンで今すぐ試用可能。

Citrix NetScaler ADC/Gateway に RCE ゼロデイ 2 件（CVE-2026-88771・CVE-2026-88772）— 国家支援グループを含む攻撃者が世界規模で悪用、CISA が KEV 登録

security
🔗 BleepingComputer

Citrix が 9 月 27 日に NetScaler ADC および NetScaler Gateway の深刻な RCE ゼロデイ脆弱性 2 件を公開した。CVE-2026-88771（CVSS 9.5）は不正入力検証による未認証 RCE、CVE-2026-88772（同 9.5）は DTLS 有効時のメモリオーバーフロー RCE で、いずれもデフォルト設定環境に影響する。攻撃者は Web シェルを展開して侵入・永続化しており、パッチ適用後もバックドアが残存する可能性がある。CISA が即日 KEV カタログへ追加し、連邦機関に 3 日以内の対応を義務付けた。

CISA が週次脆弱性ブレティンを廃止 — FY26 末（9 月 28 日）で終了、重大度ベースから「リスクベース」の脆弱性管理へ移行

security
🔗 CISA

CISA は長年発行してきた週次 Vulnerability Bulletin を 2026 年 9 月 28 日（FY26 末）をもって廃止した。重大度スコア（CVSS）に基づく一律アラートから、実際の悪用状況を重視したリスクベースの優先順位付けへ方針を転換するための措置。今後のユーザーは KEV カタログ・CISA サイバーセキュリティアラート・ベンダーセキュリティ情報を参照することが推奨され、CVE.org では新規脆弱性の記録が継続される。セキュリティチームは情報収集フローの見直しが必要。

cloud
🔗 AWS News Blog

AWS の「What's Next with AWS 2026」イベントで、業務向け AI アシスタント「Amazon Quick」（デスクトップアプリ＋拡張統合）と、Amazon Connect の 4 つのエージェント型 AI ソリューション（サプライチェーン・採用・カスタマーエクスペリエンス・ヘルスケア）が発表された。また近日提供予定の「AWS Context」は既存データ間のリレーションを自動的にナレッジグラフへマッピングし、AI エージェントが実行時にガバナンスされたデータ関係・ビジネスルールへアクセスできるようにする。
