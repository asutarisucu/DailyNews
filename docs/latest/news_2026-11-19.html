🛒 Shopify 開発者情報

Shopify 管理画面で作成したカスタムアプリが Dev Dashboard に表示・管理可能に — ログ確認や IP 許可リスト設定にも対応

shopify
🔗 Shopify 開発者 changelog

Shopify は11月17日、ストアの管理画面（Shopify admin）で作成されたカスタムアプリ（マーチャントに移管されたアプリを含む）を Dev Dashboard で表示・管理できるようにした。既存のアクセススコープ、Webhook サブスクリプション、Admin API アクセストークンはそのまま有効で、既存の連携が止まることはない。Dev Dashboard 上では API・Webhook のログ確認や、認証情報を使える IP アドレスを制限する IP 許可リストの設定が可能になる。組織外ストア向けカスタムアプリへの IP 許可リスト義務化（新規インストールは11月20日から）への対応にも使える。

【要更新】Puppet Server / OpenVox の RCE 脆弱性 CVE-2026-115731 で PoC が公開 — CVSS 9.4、証明書の自動署名環境は特に危険

security
🔗 SecurityOnline

構成管理ツール Puppet Server と OpenVox に、デシリアライズの不備によるリモートコード実行の脆弱性 CVE-2026-115731（CVSS 4.0 で 9.4）が見つかり、動作する概念実証（PoC）コードが公開された。CA 署名済みのエージェント証明書を持つクライアントがサーバー上でコードを実行でき、証明書要求を十分な検証なしに自動署名する構成では未認証の攻撃者が証明書を取得できる恐れがある。Puppet Enterprise は 2023.8.13 / 2025.12.1 / 2026.0.1 より前が影響を受けるため、早急な更新と、パッチ適用までの自動署名の停止が推奨される。

Google が AI エージェント用サンドボックス基盤「Agent Substrate」と「gVisor」を CNCF に寄贈 — Sandbox プロジェクトとして受理

dev
🔗 Google Open Source Blog

Google は KubeCon North America で、Kubernetes 上で信頼できない AI エージェントを大規模に隔離実行する「Agent Substrate」と、コンテナ向けサンドボックス「gVisor」、強化学習基盤「OpenRL」を CNCF に寄贈し、いずれも Sandbox プロジェクトとして受理されたと発表した。Agent Substrate は Kubernetes 上に構築されたアクター型の制御・データプレーンで、OCI コンテナを gVisor や Cloud Hypervisor のマイクロ VM で隔離して動かす。Google は標準的なコンテナランタイムの10倍の密度と、500ミリ秒未満での中断セッション再開をうたっており、ベンダー中立な基盤として任意の Kubernetes クラスターで使えるようにする狙いだ。
