【要即時対応】CVE-2026-18577: N-able N-central に認証バイパスの脆弱性 — 野外で悪用、CISA KEV に追加・Cloudflare Tunnel で永続化被害も

security
🔗 The Hacker News

CISA が N-able N-central の認証バイパス脆弱性 CVE-2026-18577（CVSS: 8.2）を KEV カタログに追加した。未認証の遠隔攻撃者がサーバーの管理者権限を奪取できる本脆弱性は、既存パッチの不完全修正（CVE-2026-18556）を突いた形で8月1日から実際の攻撃に悪用されている。攻撃者は Take Control 機能で管理対象エンドポイントに侵入後、Cloudflare Tunnel（cloudflared）を設置して永続的なアクセスを確立している。N-central 2026.3.1.7 へのアップグレードを即時実施すること。

npm: 2FA バイパストークンが account/org 操作を完全喪失 — 2027年1月には直接 publish も不可になる予定

security
🔗 GitHub Changelog

7月31日より、2FA バイパス設定の npm 粒度アクセストークン（GAT）はアカウント・組織・パッケージ管理操作（トークン作成・削除、メンテナー変更、組織メンバー管理など）が使用不可になった。現時点では直接 publish は引き続き可能だが、2027年1月には publish も2FA 承認が必要な「ステージング公開」のみに制限される予定。CI/CD パイプラインで bypass-2FA トークンを使用している場合は今から Trusted Publishing への移行を推奨。

🛠️ 開発ツール・OSS

npm 12 リリース — インストールスクリプトがデフォルト無効化、サプライチェーン攻撃リスクを大幅に低減

dev
🔗 The Hacker News

npm のメジャーバージョン12がリリースされ、パッケージのインストールスクリプト（postinstall など）がデフォルトで無効化された。悪意あるパッケージがインストール時に任意コードを実行するサプライチェーン攻撃を大幅に抑制する変更で、明示的に許可したパッケージのみスクリプトが実行される。2FA バイパストークンの廃止と合わせて npm エコシステム全体のセキュリティ強化が加速している。
