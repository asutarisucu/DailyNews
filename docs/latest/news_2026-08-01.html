npm 2FA バイパス型 Granular Access Token の機能制限が7月31日施行 — CI/CD での直接 Publish は8月以降不可、2027年1月に完全廃止

security
🔗 GitHub Changelog

7月31日から、2FA バイパスを設定した npm Granular Access Token (GAT) ではトークンの作成・削除、パスワード/メール/2FA 設定変更、パッケージメンテナー管理など機密操作が不可になった。8月以降は直接 publish も制限（ステージング後に人間の2FA承認が必要）、2027年1月には直接 publish 権限が完全撤廃される。CI/CD パイプラインでこれらのトークンを使用している場合は OIDC Trusted Publishing への移行が必須。

npm 12 正式リリース — インストールスクリプトをデフォルト無効化、16年越しのサプライチェーン攻撃の温床を遮断

dev
🔗 The Hacker News

npm v12 が7月にリリース。`npm install` 実行時にすべての `preinstall`/`install`/`postinstall` スクリプトをデフォルトで無効化する最大のセキュリティ強化を実施。16年間サプライチェーン攻撃の温床となってきた依存ツリー内の任意スクリプト自動実行を遮断し、`npm approve-scripts` による明示承認制に移行。CI/CD で既存スクリプトを利用しているプロジェクトはサイレントな exit code 0 ビルド失敗が発生する可能性があり、npm 11.16.0 の警告を確認の上、早急な移行作業が必要。

🔗 Vercel Changelog

Vercel の Model Context Protocol (MCP) サポートが 2026-07-28 版仕様に対応完了。ステートレスプロトコルコアと強化された認証を実装し、既存クライアントの変更は不要。8月10日より CDN が該当ヘッダーの除去を停止し、DB クエリ時間などバックエンド指標がブラウザの `window.performance` API から直接取得可能になる。フロントエンドでのパフォーマンス診断とオブザーバビリティが大幅に向上する見込み。
