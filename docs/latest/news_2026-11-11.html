🛒 Shopify 開発者情報

Partner Directory を刷新 — プロフィールを Shopify の実績データで自動構成、公開レビューは廃止

shopify
🔗 Shopify Developer Changelog

11月9日、Shopify の Partner Directory が刷新され、パートナーのプロフィールが過去4年間のコラボレーションやストア移管の履歴など Shopify 側のデータから自動生成されるようになった。パートナー階層、在籍年数、推定企業規模、進行中の案件数、得意な業種・サービス・市場は Shopify が管理し、社名やロゴ、説明文、連絡先、注目クライアントはパートナー側が Organization Settings から編集する。公開レビューと評価はプロフィールから削除され、検索結果はアルファベット順に並ぶ。コミュニティでは並び順や規模表示の精度を疑問視する声も出ている。

Anthropic が「Claude Meetings」「Whiteboards」「Sheets」を発表 — 会議参加から表計算まで、オフィス領域に本格参入

ai
🔗 TechCrunch

Anthropic は、Claude がビデオ会議に参加して議論を計画やタスクに落とし込む「Claude Meetings」を Team / Enterprise プラン向けにベータ公開した。当初は Google Meet のみ対応。あわせて、議論をタイムラインや期限付きのボードに可視化する「Whiteboards」と、依頼から複数タブ・数式・書式・ドロップダウン付きの表を作る「Sheets」を有料プラン向けにベータ提供する。Team プランでは既定で有効、Enterprise プランでは既定で無効となっており、管理者は設定の確認が必要だ。

Google が「Gemini 4 Carbon」を一般提供 — 難度の高いタスク向け上位モデル、GitHub Copilot でも利用可能に

ai
🔗 Google Blog

Google は、サイバー防御者向けの限定提供を経て Gemini 4 Carbon を一般提供した。Google AI Studio の API と Gemini for business で全有料開発者・企業が利用でき、料金は Argon と同じ入力100万トークンあたり2ドル、出力10ドルの導入価格。日常的なコーディングや業務には引き続き Gemini 4 Argon を推奨し、Carbon はより多くのトークンを使って選択肢の探索や検証を行う難問向けと位置付ける。Google Antigravity の「/swarm」機能もプレビューされ、GitHub Changelog にも同日、Copilot での Carbon 提供開始が掲載された。

Google が第8世代 TPU に「TPU 8tx」「TPU 8i Max」を追加 — 機密推論と長文脈向け、ラインナップは計4種に

ai
🔗 Business Standard

Google は第8世代 TPU に2製品を追加した。TPU 8tx は TPU 8t のシリコンを流用し、機密情報を扱う規制業界や政府向けの機密推論を想定、高速ネットワークにより TPU 8t 比で最大2倍の低遅延をうたう。TPU 8i Max は TPU 8i を2基1パッケージに収め、演算性能・SRAM・HBM 帯域を2倍にした長文脈向けモデル。価格や提供時期は未定で、報道では2027年の提供とされる。

🔒 セキュリティ

【要更新】Microsoft 11月の月例パッチ — 1,000件超を修正、悪用中の Outlook なりすまし脆弱性 CVE-2026-124194 を含む

security
🔗 BleepingComputer

Microsoft の11月の月例セキュリティ更新は、集計方法により1,094〜1,235件の脆弱性を修正する過去最大級の規模となった。悪用が確認されたゼロデイは Outlook のなりすまし脆弱性 CVE-2026-124194（CVSS 6.5）で、細工したメッセージファイルを開くと NTLM 認証情報が漏えいし得る。CISA は KEV に追加し、連邦機関に11月24日までの対応を指示した。ほかに Windows Search（CVE-2026-116928）や LDAP（CVE-2026-119958）の CVSS 9.8 のリモートコード実行脆弱性も含まれ、早期の適用が推奨される。

SAP が CVSS 10.0 の脆弱性4件を修正 — NetWeaver / Web Dispatcher の「PROXYGATE」「ICM2SHELL」、未認証で OS コマンド実行

security
🔗 The Hacker News

SAP は11月の Security Patch Day で、NetWeaver と Web Dispatcher に存在する未認証で悪用可能な脆弱性4件（いずれも CVSS 10.0）を修正した。Onapsis Research Labs が報告した「PROXYGATE」「ICM2SHELL」と呼ばれる問題で、ネットワーク到達性があれば攻撃者が adm アカウント権限で OS コマンドを実行できる。パッチ適用までの回避策として WebSocket サポートの無効化が示されているが、ABAP Push Channels や一部の Fiori 機能に影響する。

米ヴァンダービルト大学がランサムウェア被害 — 「BYOD」グループが犯行声明、学内端末の停止を指示

security
🔗 The Register

米ヴァンダービルト大学は「進行中のサイバーセキュリティインシデント」に対応していると発表し、学生や職員に端末のシャットダウンと学内 Wi-Fi からの切断を指示した。ランサムウェアグループ「BYOD」が犯行を主張し、データベースの暗号化と学生・職員・研究データの窃取をうたって交渉を要求している。最初の兆候は Box 上のファイル削除通知だったとされる。大学側は被害範囲を確認しておらず、附属病院の診療施設には影響がないとしている。

Amazon DynamoDB が「Bulk Put Items」に対応 — S3 上のデータを既存テーブルへ非同期で一括投入

cloud
🔗 AWS What's New

DynamoDB に、Amazon S3 上の行区切り DynamoDB JSON または Amazon Ion ファイルを既存テーブルへ一括で書き込むマネージドジョブ「Bulk Put Items」が追加された。従来の S3 インポートは新規テーブルが対象だったが、稼働中のテーブルにも大量投入できるようになる。アイテムごとに条件式を指定でき、Standard と Accelerated の2つのティアを選べる。なお、グローバルテーブルへの投入は現時点で非対応。

【要確認】Dependabot アラートが12月8日から非アクティブなリポジトリで停止 — 1年間活動がないとアラートをアーカイブ

dev
🔗 GitHub Roadmap

GitHub は2026年12月8日から、過去1年間に活動のないリポジトリで Dependabot アラートを無効化し、既存のアラートを削除せずアーカイブすると告知した。リポジトリ作成、アラートの有効化、push が「活動」とみなされ、push すると自動的に再有効化されてアーカイブ済みアラートも復元される。アラートを有効にするセキュリティ構成を強制しているリポジトリや、管理者による切り替えを許可しない Enterprise ポリシー下のリポジトリは対象外。GitHub Enterprise Server は影響を受けない。
