Shopify Checkout UI Extensions 2026-04 移行リマインダー — metafield API が廃止、MetafieldUpdateCartChange への対応が必須に

shopify
🔗 Shopify Developer Docs

Shopify Checkout UI Extensions の API バージョン 2026-04 で、旧来の metafield API（applyMetafieldChange の updateMetafield・removeMetafield）が廃止された。今後は MetafieldUpdateCartChange および MetafieldRemoveCartChange を使用する必要があり、カートメタフィールドの読み取りには useAppMetafields を利用する。また、拡張機能のバンドルサイズ上限は 64 KB のまま変わらず、違反するとデプロイが拒否される。未移行のアプリは早急に対応が求められる。

🔗 The Hacker News

Google が Chrome の緊急セキュリティアップデートを配布し、野外での悪用が確認された V8 JavaScript エンジンの型混乱脆弱性（CVE-2026-85046）に対処した。悪意あるウェブページを閲覧するだけで任意コード実行が可能な深刻度の高い脆弱性で、CISA が先週 KEV カタログに登録していた。Chromium ベースのブラウザ（Chrome・Edge・Brave等）を利用しているユーザーはすべて速やかに最新バージョンへ更新するよう強く推奨される。エンタープライズ環境では強制更新ポリシーの確認と適用が急務。
