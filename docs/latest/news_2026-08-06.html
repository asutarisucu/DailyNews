shopify

Shopify: 注文配送先住所の更新で税金が自動再計算されるように — Order Update GraphQL ミューテーションの挙動変更

shopify
🔗 Shopify Developer Changelog

Shopify Order Update GraphQLミューテーションで未発送注文の配送先住所を変更した際、税金が新しい配送先に対して自動的に再計算されるようになった。従来は住所のみ更新され税額が変わらず、実際の配送先と税額が乖離する問題があった。この変更により注文データの一貫性が保たれるが、既存の税額保持ロジックに依存しているアプリは影響を受ける可能性があるため要確認。

【対応期限: 本日8/6】CVE-2026-18577: N-able N-central に認証バイパス — CISA KEV 追加、管理エンドポイント全滅の恐れ

security
🔗 The Hacker News

N-able N-centralの認証バイパス脆弱性CVE-2026-18577（CVSS 8.2）がCISAのKEVカタログに追加された。7月31日にN-ableが顧客環境で不審なアクティビティを検出し、8月1日から実際の悪用が確認された。攻撃者はN-centralのTake Control機能を悪用して管理下のエンドポイントへ水平展開し、Cloudflare Tunnel（cloudflared）で永続的なリモートアクセスを確立。修正バージョン2026.3.1.7（Hotfix 1）が8月2日にリリースされており、オンプレミス環境は即時適用が必要。連邦機関の対応期限は本日8月6日。

CISA KEV: Cisco UCM に SSRF（CVE-2026-20230）・PTC Windchill に不正入力検証（CVE-2026-12569）— 8月3日追加

security
🔗 CISA

CISAが8月3日付で既知の悪用脆弱性カタログに2件を追加した。CVE-2026-20230はCisco Unified Communications ManagerのSSRF（Server-Side Request Forgery）脆弱性で、内部ネットワーク情報の漏洩や内部サービスへの不正アクセスに悪用可能。CVE-2026-12569はPTC WindchillおよびFlexPLMの不正入力検証の脆弱性で、製造・PLM環境が標的になっている。どちらも悪意ある攻撃者の主要な攻撃経路として特定されており、連邦機関への迅速なパッチ適用が求められている。

Cloudflare Wallets 発表 — AIエージェント専用のステーブルコインウォレットとx402プロトコルで「エージェントがお金を使う」時代へ

cloud
🔗 Cloudflare Blog

Cloudflareが8月4日、AIエージェント向けのプログラマブルウォレット「Cloudflare Wallets」を発表した。アカウントオーナーが管理するAccount Walletと、個別エージェントに付与するVirtual Walletに分かれており、利用上限・承認マーチャントリスト・最大取引額を設定したスペンドコントロールが可能。open x402プロトコルを使用したステーブルコイン決済をエッジで処理し、API KeyやサインアップなしでAIエージェントがリクエスト単位で支払いを行える。企業は "research.example.cloudflare.pay" のような人間可読なウォレットIDをエージェントに割り当てることもできる。

npm: 2FA をバイパスするレガシートークンを段階的に廃止 — 8月からアカウント変更を制限、2027年1月から直接公開も不可に

dev
🔗 The Register

npmが2FAをバイパスできるレガシートークンのサポートを段階的に廃止する方針を発表した。2026年8月からはそのようなトークンでのアカウント設定変更が制限され、2027年1月以降はパッケージの直接公開も不可となる。サプライチェーン攻撃の主要な侵入経路であったレガシートークンの廃止により、OSSエコシステム全体のセキュリティが向上する見込み。CI/CDパイプラインでレガシートークンを使用しているプロジェクトは、今すぐ粒度の細かいアクセストークンまたはOIDCへの移行が必要。
