Hydrogen Developer Preview 8/18 更新: カートセッション同期・カート属性・標準ページビューイベント・Shop Pay 即時レンダリングを追加

shopify
🔗 Shopify Developer Changelog

8月18日の Hydrogen Developer Preview アップデートで4つの機能が追加された。①カートと Customer Account セッションを同期する「カートセッション帰属」によりログイン済み購入者がゲストフローを経ずにチェックアウトへ到達できる。②ギフトメッセージなど注文全体のデータをカートに、刻印テキストなど行ごとのデータを対応ラインに付加できる「カート属性」。③クライアントサイドナビゲーションを含む全ページ遷移を analytics に報告する「標準ページビューイベント」（Liquid テーマと同等の動作に）。④ JS ロード前から Shop Pay ボタンをスタイル付きで即時レンダリング。

SubscriptionContractCalculation API が 2026-10 RC でアーリーアクセス開始 — calculate→poll→commit のステートレス設計でサブスク契約更新を12 mutation から1つに削減

shopify
🔗 Shopify Developer Changelog

Shopify Admin GraphQL API の 2026-10 リリース候補バージョンで新しい SubscriptionContractCalculation API のアーリーアクセスが開始された。従来の Subscription Draft オブジェクトを置き換える後継 API で、stateless な「calculate → poll → commit」ライフサイクルを採用。12以上の draft mutation が1つの calculate mutation に集約され、Shopify 統合チェックアウトエンジンを通じて計算されるため計算結果の一貫性が向上する。2026-10 GA 後に Draft は非推奨となるが、既存アプリは段階的移行が可能。本番連携は 2026-10 が安定してから行うことを推奨。

Anthropic: Claude が自律的にタンパク質バインダーを設計、15ターゲット中14件で成功 — 業界標準の2倍以上の22〜35%成功率をウェットラボで検証

ai
🔗 Anthropic Research

Anthropic が8月20日に発表した研究で、Claude がタンパク質バインダー設計キャンペーンを人間の科学的指導なしに自律実行し、15ターゲット中14件に対する有効なバインダーを設計したことが外部ウェットラボ（Adaptyv Bio・Twist Bioscience）で独立検証された。1,320デザインから354件の確認済みバインダーを生成し、成功率は22.6〜35.1%（業界標準10〜15%の約2倍）。Claude は約3万トークンの初期プロンプトを受け取った後、ターゲット選定・構造生成・in silico 最適化・スクリーニングを自律的に実施。薬物設計の初期ステップへの寄与として評価される一方、デュアルユースリスクへの配慮から Claude Fable 5 ではこの能力は一般公開されていない。

【緊急】CISA が TrueConf Server の RCE 脆弱性 CVE-2026-72529/72530 を KEV カタログ追加 — Head Mare が悪用、修正期限8月23日

security
🔗 BleepingComputer

CISA が8月20日に TrueConf Server の2件の脆弱性を既知悪用脆弱性（KEV）カタログへ追加し、連邦機関に3日以内のパッチ適用を命令。CVE-2026-72529（CVSS 9.3）は未認証リモート攻撃者が TCP 4307番ポート経由で任意コードを実行できる認証不備の RCE。CVE-2026-72530 と合わせてハクティビストグループ「Head Mare」が少なくとも2026年7月から悪用しており、クライアントインストーラーを悪意あるバージョンに差し替えてバックドアマルウェアを展開する攻撃が確認されている。影響バージョン 5.3.x〜5.3.9・5.4.x〜5.4.9・5.5.x〜5.5.5 を使用中の組織は TrueConf Server 5.3.9・5.4.9・5.5.5 へ直ちにアップグレードすること。

Cisco が Crosswork・Secure Workload の深刻な脆弱性9件を修正 — うち5件が CVSS 10.0、SQLインジェクション・認証バイパス・外部ファイル制御を含む

security
🔗 The Hacker News

Cisco が8月19日のセキュリティアドバイザリで Crosswork Data Gateway・Crosswork Network Controller・Crosswork Planning・Secure Workload に影響する脆弱性9件を修正。CVE-2026-20030（SQLインジェクション）・CVE-2026-20357（認証不備）・CVE-2026-20358（外部ファイルシステム制御）など5件が CVSS スコア10.0の最高深刻度。今回の脆弱性はすべて Cisco 内部のセキュリティレビューで発見されており、現時点で野外悪用は確認されていない。Crosswork 7.2.1 以前を使用中の場合は 7.2.1-SP へのアップグレードで対処可能。回避策はないため早急なパッチ適用を推奨。

Black Hat 2026: Check Point がMicrosoft Defender の正規ドライバー BTR.sys を悪用し EDR/AV を無効化する手法を公開 — Windows 7〜11 25H2 全対象

security
🔗 The Hacker News

Check Point Research が8月20日の Black Hat USA 2026・DEF CON 34 で、Microsoft Defender の正規ブートタイム修復ドライバー（BTR.sys）を悪用して任意のカーネルレベルのファイル・レジストリ操作を実行できる手法を公開。ソフトウェアの脆弱性を悪用するのではなく、正規署名済みのドライバーを武器化するため標準的なセキュリティ検知を回避できる。Windows 7 から Windows 11 25H2 まで全バージョンが影響対象で、EDR や他のセキュリティソフトウェアを起動前に削除・無効化するために使用可能。Microsoft への報告を経て協調開示されており、Defender の更新での対処が見込まれる。
