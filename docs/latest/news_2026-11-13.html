顧客データ消去リクエストの保留期間を10日から5日に短縮 — アプリの GDPR 対応処理のタイミングに影響

shopify
🔗 Shopify Developer Changelog

Shopify は顧客データの消去リクエストについて、受付から実際の処理までの保留期間を従来の10日から5日に短縮した。消去を受けて送られる webhook（customers/redact）を前提にデータ削除を行っているアプリは、処理タイミングが早まる点に注意が必要だ。なお、送付予約されたギフトカードの受取人については、配信が完了するまで保留状態が続く。

非営利団体の連合が OpenAI・Google・Anthropic・Meta・SpaceX の AI 部門を提訴 — 最先端モデルの開発差し止めを要求

ai
🔗 Maryland Daily Record（Reuters 配信）

Public Citizen や Heat Initiative、The Alliance for Secure AI などの非営利団体は11月12日、サンフランシスコの裁判所に、より高性能なフロンティア AI モデルの開発停止を求める訴えを起こした。カリフォルニア州法上の「公的不法妨害（public nuisance）」を根拠に、損害賠償ではなく差し止め命令を求めている。訴状は、各社の経営陣自身が生物兵器やサイバー攻撃などの破局的リスクを警告してきた点を挙げている。Meta はコメントを控えた。9月に利用者が起こした「開発減速の合意」をめぐる反トラスト訴訟とは別の訴訟となる。

Anthropic の改定「Supported Regions Policy」が11月12日に発効 — 中国本土・香港・マカオに所在する個人の利用も禁止

ai
🔗 TokenPost

Anthropic が改定した対応地域ポリシーが11月12日に発効したと報じられている。従来の「中国資本が過半を握る企業」への制限に加え、中国本土・香港・マカオなど非対応地域に物理的に所在する個人の利用も対象とし、対応地域の企業の従業員であっても例外にならない。対象は Claude.ai、Claude Code、API に加え、クラウド事業者や正規販売代理店経由で提供されるモデルにも及ぶとされる。一部では本人確認（KYC）の要求やアカウント停止の報告も出ているが、個別の事例は未確認だ。

Meta が最小・最安の「Muse Ember」を公開 — エージェントの大量実行向け、入力100万トークンあたり0.10ドル

ai
🔗 The New Stack

Meta Superintelligence Labs は Muse シリーズで最も小さく安価なモデル「Muse Ember」を公開した。上位モデルの Muse Wonder が計画を担い、Ember が反復的な作業を大量にこなす分業を想定している。Muse Code と Meta Model API から muse-ember-1.0 として利用でき、料金は入力100万トークンあたり0.10ドル、出力0.50ドル、コンテキストは100万トークン。テキスト・画像・音声・動画を入力できる。ベンチマークは Meta 自身によるもので、Claude Haiku との比較では項目によって勝敗が分かれた。重みは非公開。

🔒 セキュリティ

【要対応】N-able N-central の新たなゼロデイ「4EverAble2Shell」が PoC 公開から数時間で悪用 — 11月10日の緊急修正版も影響

security
🔗 BleepingComputer

先週の大量ゼロデイ公開を受けて N-able が11月10日に出した N-central 2026.4 HF2（build 2026.4.1.26）に対し、修正を回避する新たなエクスプロイト「4EverAble2Shell」が公開された。未認証で root 権限のリモートコード実行が可能とされ、11月12日時点で暗号資産マイナー XMRig が仕込まれた本番サーバー21台が確認され、うち19台が最新の修正版だった。Legacy API を有効にしている環境が影響を受けるため、watchTowr などは Legacy API の無効化と侵害痕跡の確認を呼びかけている。Huntress は「パッチ適用済みでも脆弱とみなすべき」としている。

【要更新】Xen Orchestra に悪用中の認証回避脆弱性 — 細工した Cookie で管理者権限を奪取し XCP-ng ホストを乗っ取り

security
🔗 BleepingComputer

Vates は仮想化管理ツール Xen Orchestra と XOA に、管理画面へ到達できる攻撃者が認証を回避できる深刻な脆弱性（VSA-2026-062）があり、実際に悪用されていると公表した。REST の Cookie 解析で認証トークンに空の JSON オブジェクトを渡すと管理者として操作でき、管理下のプールで任意コードを実行し XCP-ng ノードを root で掌握できる。修正版は 6.9.1 と 6.10.0。攻撃は通常のログに残らないため、HTTP 通信で authenticationToken=j:{} を含むリクエストを監視するよう推奨されている。CVE は未採番。

改ざんされた ScreenConnect クライアントで48組織・288台以上が被害 — マルウェア「SCKit」を展開

security
🔗 The Hacker News

攻撃者がリモート支援ツール ScreenConnect の不正なクライアントを使い、少なくとも48組織の288台以上のエンドポイントにマルウェア「SCKit」を展開していたことが明らかになった。ConnectWise は、自社インフラの侵害や ScreenConnect ソフトウェア自体の脆弱性が関与した証拠はないとしている。ソーシャルエンジニアリングで不正クライアントを導入させる手口が続いており、許可していない ScreenConnect インスタンスの棚卸しが推奨される。

Qlik Sense サーバーを狙う攻撃 — リバースシェル投入を試み、ActiveMQ や Veeam のエクスプロイトも準備

security
🔗 The Hacker News

10月以降、BI 製品 Qlik Sense のサーバーを標的に PowerShell のリバースシェルを送り込もうとする攻撃が複数の環境で観測された。今回の試みは失敗に終わったが、攻撃者は Apache ActiveMQ や Veeam を狙うエクスプロイトも用意していたという。Qlik Sense への侵入に使われた脆弱性はまだ特定されていない。過去にもランサムウェア集団 Cactus が Qlik Sense の脆弱性を悪用しており、インターネットに公開したサーバーは最新版への更新と露出の見直しが求められる。

BigQuery でプロジェクト単位の上限（Project caps）が GA — 予約内のスロット数と同時実行数をプロジェクトごとに制限

cloud
🔗 BigQuery release notes

Google Cloud は11月11日、BigQuery の「Project caps（スケジューリングポリシー）」を Enterprise / Enterprise Plus エディションで一般提供した。1つの予約（reservation）を共有する複数プロジェクトについて、プロジェクトごとに最大スロット数と同時実行数を制限でき、特定プロジェクトによるリソースの独占を防げる。同日、JSON を平坦化する JSON_FLATTEN 関数も GA となった。

Gemini / Veo API にエンドユーザー識別用の safety_identifier ラベルが GA — CodeMender v0.21.0 はサンドボックス内でビルド実行

cloud
🔗 Gemini Enterprise Agent Platform release notes

Gemini Enterprise Agent Platform で、Gemini と Veo の API 呼び出しにエンドユーザーを識別する safety_identifier リクエストラベルを付けられる機能が一般提供になった。不正利用が起きた際に、どの利用者によるものかを特定しやすくする仕組みだ。同日公開の CodeMender v0.21.0 では、サンドボックスが有効な場合に build.command をサンドボックス内で実行するよう変更された。

🛠️ 開発ツール・OSS

GitHub Copilot で「Claude Fable 5.2」が一般提供 — Business / Enterprise は管理者によるポリシー有効化が必要

🔗 Let's Data Science

GitHub は Anthropic の新モデル Claude Fable 5.2 を Copilot で一般提供し、Pro+、Max、Business、Enterprise プランで段階的に展開している。モデルピッカーから選択でき、Business / Enterprise では既定で無効のポリシーを管理者が有効にする必要がある。Fable 5 系はAnthropic の安全分類器を動かすためプロンプトと出力の保持が必要で、ゼロデータ保持の他の Claude モデルとは扱いが異なる。料金は従量課金でプロバイダーの定価に準じる。

🔗 GitHub Changelog
