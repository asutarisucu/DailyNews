【要対応】Shopify アプリセキュリティ更新（2026年10月）— オフライントークン期限と新セキュリティ機能・アプリセキュリティハブを公開

shopify
🔗 Shopify Developer Blog

Shopifyは10月27日、アクション必須の「Security update: Offline token dates, new security features」を公開した。オフライントークンの強制適用日程に加え、client credentials アクセス、IP制限、ネットワークアクセス宣言、本人確認（identity verification）などの新機能と、新たなアプリセキュリティハブ（shopify.dev/docs/apps/build/security）が案内された。各アプリに適用されるプラクティスをハブで確認し、リリースごとに shopify app security check を実行することが推奨されている。

【期限間近】Global Catalog REST API が11月2日に停止 — Global Catalog MCP（UCP）への移行が必須

shopify
🔗 Shopify Developer Changelog

2026年4月に非推奨化された Global Catalog REST API（discover.shopifyapps.com/global）が11月2日でトラフィックの受付を停止し、保存済みカタログへのリクエストも失敗するようになる。移行先は Universal Commerce Protocol を実装した Global Catalog MCP で、検索は search_catalog、単体・バリアント取得は get_product、一括取得は lookup_catalog に対応する。リクエストは catalog.shopify.com/api/ucp/mcp に送り、meta.ucp-agent.profile にエージェントプロファイルURLを含める必要がある。

AI Toolkit と Shopify CLI に「shopify app security check」が登場 — 審査提出前に脆弱性を自動スキャン

shopify
🔗 Shopify Developer Changelog

Shopify AI Toolkit と Shopify CLI に、アプリの一般的な脆弱性をスキャンする新コマンド shopify app security check が追加された。各指摘には問題箇所・想定される影響・修正手順が含まれ、エージェントがコードを読み取る方式のため特定フレームワークに依存しない。ツールはオープンソースで、App Store 提出前および毎リリース時の実行が推奨されている。

Admin API 2027-01 RC に appDowngradeAccessScopes ミューテーション — write スコープを read に格下げ可能に

shopify
🔗 Shopify Developer Changelog

GraphQL Admin API 2027-01 リリース候補に、付与済みのオプショナルな write スコープを対応する read スコープへ格下げする appDowngradeAccessScopes が追加された。例えば write_products を格下げすると read_products は維持されるため、マーチャントに再承認を求めずに権限を最小化できる。appRevokeAccessScopes で write を取り消すと read も失われる場合があるため、読み取りを継続したいアプリはこちらを使う。Shopify管理インストールを利用するアプリが対象。
