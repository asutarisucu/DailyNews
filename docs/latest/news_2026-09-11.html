Customer Address APIs が countryCode フィールドをサポート — ISO 3166-1 alpha-2 コードで住所管理が簡素化

shopify
🔗 Shopify Developer Changelog

Shopify の Customer Address API が countryCode フィールドをサポートするようになった。これまで country フィールドには国名の文字列が入り、言語設定によって表記が異なる問題があったが、countryCode による ISO 3166-1 alpha-2 コード（例: JP, US, GB）での指定が可能になったことで、住所データの一貫性と多言語対応が向上する。Admin API・Storefront API・Customer Account API のいずれでも利用でき、新規住所作成・既存住所の更新どちらにも対応している。

SubscriptionBillingAttempt の非推奨フィールド（errorCode / errorMessage）が GraphQL Admin API 2026-07 で削除 — 移行が必要

shopify
🔗 Shopify Developer Changelog

Shopify GraphQL Admin API 2026-07 において、SubscriptionBillingAttempt オブジェクトの非推奨フィールドである errorCode と errorMessage が削除された。代替として errorDetails フィールドが提供されており、複数のエラー詳細を構造化した形式で受け取ることができる。サブスクリプション管理アプリを開発・運用しているパートナーは、2026-07 以降の API バージョンへ移行する前に errorDetails フィールドへの切り替えが必要。既存アプリの動作確認を早期に行うことが推奨される。

Hydrogen の shopify_y・shopify_s トラッキングクッキーが廃止予定 — Storefront API セッション管理への移行を推奨

shopify
🔗 Shopify Developer Changelog

Hydrogen ストアフロントで使用されてきた shopify_y（ユーザー識別）と shopify_s（セッション管理）の2つのトラッキングクッキーが廃止されることになった。ブラウザのサードパーティクッキー制限強化に対応するための変更で、代替として Storefront API が提供するセッション管理機能への移行が推奨される。廃止後は shopify_y・shopify_s クッキーに依存したカスタムアナリティクスや A/B テストのセグメンテーションが動作しなくなるため、Hydrogen を利用するストアは実装の見直しが必要になる。

ai
