Hydrogen Developer Preview 最新アップデート: カートセッション属性・Shop Pay 直接レンダリング・標準ページビューイベントを追加

shopify
🔗 Shopify Developer Changelog

Hydrogen Developer Preview の最新アップデートでは、ログイン済みショッパーがカートを引き継いで決済に進める「カートセッション属性」と、ギフトメッセージなどのオーダー全体データや刻印テキストなどの行単位データを添付できる「カート属性」が追加された。また Shop Pay ボタンが Shopify ホストスクリプトなしで直接レンダリング可能となり、すべてのナビゲーション（初回ページ読み込みだけでなく）で標準ページビューイベントが報告されるようになった。フレームワーク非依存・ランタイム非依存設計が強調されており、エージェント対応の Hydrogen を既存のホスティングプラットフォームに導入しやすくなっている。

Shopify 2026-10 API リリース候補公開: Cart API がサブスクリプションをファーストクラスでサポート・DraftOrder破壊的変更あり

shopify
🔗 Shopify Developer Changelog

Shopify API バージョン 2026-10 のリリース候補が公開された。Cart API でサブスクリプション販売プランや一度限りの購入とサブスクリプションのハイブリッドカートがサポートされ、定期購入はファーストクラスの機能となった。破壊的変更として DraftOrderDiscountNotAppliedWarning.priceRule が削除され、2026-10 以降の未フルフィルメント注文の配送先変更では税金が自動再計算される仕様に変更。対象フィールドを利用しているアプリは 2026-10 への移行前に動作確認と修正が必要。

Shopify API 新レート制限モデル詳解: APIキー単位で毎秒40リクエスト・バースト50、IPベース除外は廃止

shopify
🔗 Tenten.co / Shopify Developer Changelog

2026年の重要な Shopify API 変更として、新しいレート制限モデルが導入されている。APIキーごとに毎秒40リクエスト（バースト50、持続時間20ms毎1リクエスト）が上限となり、従来のIPベースの除外は廃止された。APIキーが個別にスロットリングされるため、複数テナントで同一キーを共有しているアプリは特に影響を受ける可能性がある。各アプリの API 呼び出しパターンを見直し、指数バックオフの実装やリクエストのバッチ化が推奨される。

ai

OpenAI は9月3日に GPT-6 Astra をリリースし、同社社長の Greg Brockman は「AGI 時代の幕開け」と宣言した。最大の特徴はユーザーの代わりにコンピューターを操作する「computer use」機能で、スプレッドシート入力やゼロからのウェブサイト作成など高度なタスクを自律実行する。本モデルは OpenAI の Preparedness Framework においてサイバーセキュリティの「クリティカル」閾値に達した初のモデルとして位置づけられており、セキュリティガードレールが強化されている。まず Daybreak プログラムの法人向けに先行提供し、数日以内に Plus・Pro・Business・Enterprise ユーザーへも順次展開予定。

🔒 セキュリティ

【緊急】CISA、7件の既知悪用脆弱性を KEV カタログに追加 — SonicWall (CVSS 10.0)・JFrog Artifactory・Kestra OSS など、9月5日が対応期限

security
🔗 CISA

CISA が9月2日、7件の新規悪用済み脆弱性を Known Exploited Vulnerabilities (KEV) カタログへ追加した。最高危険度は CVE-2026-83548（SonicWall SMA1000 SSRF、CVSS 10.0）で未認証リモート攻撃者が機密機能へアクセス可能。CVE-2026-82329（JFrog Artifactory 認証不備）と CVE-2026-9586（Sangoma Switchvox SQL インジェクション）は既にリバースシェル展開と管理トークン奪取に悪用されている。Kestra・Artifactory・Switchvox・SonicWall は9月5日、LiteLLM・Starlette は9月16日が連邦機関の修正期限。AI インフラ関連製品の脆弱性が含まれるため、社内でこれらを利用している組織は早急なパッチ適用を推奨。

JetStream、AIエージェント向けゼロトラスト推論エンジン「Clearance」を発表 — 実行前にエージェントの各アクションを承認・危険なシーケンスをブロック

security
🔗 Yahoo Finance / JetStream

JetStream Security が9月2日、AIエージェントの各アクションを実行前に評価・認可するゼロトラスト推論エンジン「Clearance」を発表した。Clearance は AI ゲートウェイ上でリクエストを検査し、承認済み設計・ツール・実行内容にマッピングして危険なシーケンス（データ流出パターンなど）を事後ログではなく事前ブロックで封じる。規制業界で大量のエージェントを運用する組織に向け、ライブデータ流出や内部コンプライアンスリスクを大幅に低減することを目指す。CrowdStrike Fal.Con 2026 で実演予定で、CrowdStrike の新 AI パートナー特化プログラムにも参加している。
