shopify
🔗 Shopify Developer Changelog

Shopify Flow: アクション実行ごとに runtime_URL を自動解決 — 既存ワークフローの再アクティベートが不要に

shopify
🔗 Shopify Developer Changelog

2026年7月7日より、Shopify Flowがアクションの実行ごとに runtime_url を動的に解決するよう変更。アプリのデプロイでURLが変更されても、マーチャントがワークフローを再保存・再アクティベートする必要がなくなった。shopify app dev による開発環境でも自動反映される。従来の「URLはワークフロー作成時に固定」という挙動に依存している場合は注意が必要。

Shopify Flow: Action extensions のフィールドミスマッチをサーバー側で制御可能に — ブレイキングチェンジが大幅減少

shopify
🔗 Shopify Developer Changelog

Shopify Flowのアクション設定フィールドを変更した際のブレイキングチェンジを、サーバー側コードで制御できるようになった。フィールドのミスマッチが発生しても、以前はワークフローが検証失敗で停止していたが、新仕様ではアプリ側でフォールバックを定義すればワークフローは実行継続される。大規模なFlow連携アプリのスキーマ変更がより安全に行えるようになる。
