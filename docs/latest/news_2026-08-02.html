orderUpdate GraphQL mutation が配送先住所変更時に税金を自動再計算 — 2026年8月31日より全 API バージョンで適用

shopify
🔗 Shopify Developer Changelog

2026年8月31日以降、未フルフィルメントの注文の配送先住所を orderUpdate GraphQL mutation で変更すると、税金が新しい配送先に対して自動的に再計算される。これまでは住所変更後も元の税行が残り、注文の合計と配送先が不一致になる問題があった。変更の採用に向けてコード修正は不要で、全 Admin GraphQL API バージョンに適用される。

npm 2FA バイパス Granular Access Token、7月31日よりアカウント管理操作を制限 — スケルトンキー攻撃面を解消

dev
🔗 GitHub Changelog

2FA をバイパスするよう設定された npm Granular Access Token（GAT）が、7月31日よりトークン作成・削除、パッケージのメンテナー変更、組織/チームメンバーシップ管理などのアカウント管理操作を実行できなくなった。これらの操作にはインタラクティブな 2FA チャレンジが必要になる。流出したバイパストークンでアカウントを乗っ取り新トークンを発行する攻撃パターンを根本的に遮断する変更。

GitHub Stacked PRs がパブリックプレビュー開始 (7月30日) — ウェイトリスト廃止、全リポジトリへ展開、マージキュー対応も近日追加

dev
🔗 GitHub / El Solitario

GitHub の Stacked PRs 機能が 7月30日にパブリックプレビューとして全リポジトリへ順次展開を開始した。スタックされた複数の PR をスタックマップで追跡し、並行レビューを経て一括でマージキューへ投入できる。Vercel・jQuery・TED などが早期テスターとして参加し、jQuery 作者の John Resig は「5つのスタック PR を一度にマージキューへ投入できるのは素晴らしい」とコメント。CLI・モバイル・GitHub Copilot のコーディングエージェントからも利用可能。

npm 12: インストールスクリプトをデフォルト無効化 — サプライチェーン攻撃リスクを大幅削減、手動許可が必要に

dev
🔗 The Hacker News

npm 12 がインストールスクリプト（preinstall / postinstall）をデフォルトで無効化した。パッケージインストール時に任意のコードを実行するサプライチェーン攻撃の主要な侵入経路を閉じる変更で、スクリプトの実行が必要な場合はプロジェクト単位の許可設定が必要になる。2FA バイパストークン制限と合わせ、npm エコシステムのセキュリティ強化が急速に進んでいる。
