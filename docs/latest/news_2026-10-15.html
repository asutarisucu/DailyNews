shopify
🔗 Shopify API Release Notes

API バージョン 2025-10 が 2026 年 10 月 16 日に退役する。退役後はこのバージョンへのリクエストがエラーを返すため、2025-10 を使用しているアプリは速やかに 2026-04 以降のバージョンへ移行する必要がある。あわせて 2026-10 が安定版として確定し、新機能の利用が可能になった。

shopify
🔗 The Paypers

Microsoft October 2026 Patch Tuesday — 1,413 CVE・Windows Shell ゼロデイ CVE-2026-96951 が実攻撃悪用

security
🔗 BleepingComputer

Microsoft が 10 月 13 日に過去最大規模の月例セキュリティ更新を公開し、1,413 件の CVE に対処した。うち実攻撃が確認されているゼロデイは Windows Shell の Mark of the Web バイパス CVE-2026-96951（CVSS 8.8）で、CISA も KEV カタログに追加して 10 月 16 日までの修正を義務付けた。EoP が 677 件と最多で、RCE 317 件・情報漏洩 254 件が続く。優先対応として Windows Shell ゼロデイと CVE-2026-97814（Windows Text Shaping、CVSS 9.8）へのパッチ適用が推奨される。

Ivanti CVE-2026-104935 続報 — Volexity が UTA0576 による3脆弱性チェーン攻撃を特定

security
🔗 BleepingComputer

セキュリティベンダーの Volexity が、Ivanti Connect Secure の CVE-2026-104935 を含む 3 つの脆弱性をチェーンして悪用する脅威アクター UTA0576 を特定した。少なくとも 10 月 3 日から攻撃が確認されており、コマンドをメモリ上で実行するため Ivanti の Integrity Checker Tool では侵害の検出が困難。未パッチの権限昇格脆弱性も悪用されており、KEV 未登録で修正なしの状態が続いている。インシデントレスポンスには Checker Tool だけでなくフォレンジック調査が必要とされる。
