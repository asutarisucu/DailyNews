🛒 Shopify 開発者情報

Shopify Engineering がモバイルアプリ設計「Reflex」を公開 — エージェントが大半のコードを書く前提で React Native からネイティブへ

shopify
🔗 Shopify Engineering

Shopify Engineering ブログが、AI エージェントがコードの大半を書くことを前提にしたモバイルアプリのアーキテクチャ「Reflex」を解説した。プラットフォームに依存しない共有モジュール「Core」が必要な機能をプロトコルとして宣言し、モバイルアプリと CLI がそれぞれ実装を注入するホストとなるため、CLI から画面なしでアプリを操作して素早く検証できる。最大のボトルネックはフィードバックループだったとしており、300画面超の Shop アプリを React Native からネイティブ（Swift / Kotlin）へ移行する取り組みの中核になっている。

UI 拡張機能のロケールファイル合計 256KB 上限を撤廃 — 多言語対応アプリのデプロイ失敗を解消

shopify
🔗 Shopify Developer Changelog

UI 拡張機能に含めるロケールファイルの合計サイズに課されていた 256KB の上限が撤廃された。全 API バージョンの UI 拡張機能が対象で、言語数の多いアプリがデプロイに失敗する問題が解消される。ただし個々のロケールファイルに対する 30KB の上限は引き続き適用される。上限に合わせて翻訳を削っていた開発者は、翻訳を戻して shopify app deploy で再デプロイできる。

ai
🔗 Anthropic

Anthropic は11月9日、同じ基盤モデルから成る Claude Fable 5.2 と Claude Mythos 5.2 を公開した。一般向けの Fable 5.2 はサイバー・生物分野の安全策を強化したうえで、料金を入力100万トークンあたり8ドル、出力40ドル（5.1 は10ドル／50ドル）に引き下げ、出力速度は前世代比で約30%高速化したとしている。安全策を緩めた Mythos 5.2 は Cyber / Life Sciences の認証プログラム参加組織に限定され、社内の CVE 再発見テストで 89.6% を記録したという。Amazon Bedrock でも提供が始まった。同社は11月16日の週の IPO を目指していると報じられている。

D-Link が DGS-3130 シリーズのスイッチに未修正のゼロデイ複数件と警告 — ファームウェア修正はなく暫定緩和策のみ

security
🔗 BleepingComputer

D-Link は、DGS-3130 シリーズのマネージドスタッカブルスイッチに未修正の脆弱性が複数あるとして、暫定的な緩和策を公開した。報道によると問題は D-Link Discovery Protocol（DDP）周辺の認証・アクセス制御・入力処理にあり、DGS-3130-30TS の複数のファームウェアバージョンが影響を受ける。他の機種への影響は調査中で、修正版ファームウェアはまだない。機器の棚卸しとバージョン確認、管理サービスをインターネットに公開しないことが推奨されている。

Anthropic が法人顧客に通知 — 外部セキュリティ企業が社内システムに侵入し、アカウント ID や利用額データを閲覧した可能性

security
🔗 MLQ.ai

Anthropic は11月7日、外部のセキュリティ企業による不正アクセスでエンタープライズ顧客のアカウント情報が閲覧された可能性があるとメールで通知した。対象はアカウント ID、組織 ID、プラン種別、利用量・支出額などで、会話内容やパスワード、決済情報は含まれないという。相手企業はデータの削除を書面で証明したとされ、一部報道は第三者製オフィスソフトの脆弱性を突いたセキュリティ新興企業 Cathedral だと伝えている。韓国では100社超の情報が対象とされ、個人情報保護委員会が予備調査を始めた。

FBI と CISA が冷蔵・コールドチェーン設備への攻撃に警告 — インターネットに露出した制御装置が標的

security
🔗 BleepingComputer

FBI と CISA は、インターネットからアクセスできる冷蔵設備やコールドチェーンの制御装置を狙ったサイバー攻撃が起きているとして注意を呼びかけた。温度設定の改ざんは医薬品や食品、血液製剤などの品質に直結するため、制御装置をインターネットに直接公開しないこと、既定の認証情報を変更すること、リモートアクセス経路を見直すことなどが推奨されている。保守を担うサプライヤー経由の侵入にも注意が必要だ。

Google Cloud が AI エージェント向けセキュリティ機能を拡充 — Auth Manager の GA、Agent Identity の JWT 発行はプレビュー

cloud
🔗 SecurityBrief Asia

Google Cloud は自律型 AI エージェントを運用する組織向けのセキュリティ機能を発表した。エージェントが使う認証情報を Google 管理の保管庫で IAM ポリシーにより一元管理する Auth Manager が一般提供となり、Agent Identity から標準的な OIDC トークン（JWT）を発行して AWS や Azure、オンプレミスのバックエンド、MCP サーバーへ長期 API キーなしで認証できる機能がプレビューで始まった。Wiz Defend と Google Security Operations の連携強化も含まれる。

🔗 Node.js

Node.js プロジェクトは、26.x・24.x・22.x の各リリースラインに対するセキュリティアップデートを11月11日（米国時間）以降に公開すると予告した。修正される問題の最高深刻度は High。詳細やバージョン番号はリリース時に公開される。サポート終了済みのバージョンはセキュリティリリースのたびに影響を受けるものとして扱われるため、EOL 版を使っている環境はサポート中のラインへの移行が推奨される。

GitHub シークレットスキャンが Actions のワークフローログを検査可能に — パブリックプレビュー、既定は無効

dev
🔗 GitHub Docs

GitHub のシークレットスキャンが、GitHub Actions のワークフローログに出力されたシークレットを検出できるようになった（パブリックプレビュー）。有効化すると、シークレットスキャンが有効なリポジトリで新しいワークフロー実行の完了後にログを検査する。過去の実行は対象外で、検出はプロバイダーパターンのみ（汎用・カスタムパターンや AI 検出、Actions がマスクした値は対象外）。プレビュー中はアラート通知が送られないため、リポジトリのアラート一覧を確認する必要がある。

other
🔗 CNBC
