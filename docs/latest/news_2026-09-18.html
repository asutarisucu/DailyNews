Shopify POS UI Extensions、API 2026-10 で staffMemberId フィールドを削除 — session.staffMember シグナルへ移行が必要

shopify
🔗 Shopify Developer Changelog

API バージョン 2026-10 より、POS UI Extensions の Session API から静的フィールド `session.currentSession.staffMemberId` が削除された。代替として 2026-07 から提供されているリアクティブシグナル `session.staffMember` を使用する必要があり、スタッフ切り替え時の動的更新にも対応できる。2026-10 をターゲットにするアプリは `session.staffMember.value?.id` で ID を取得するよう更新が必要。なお、レシートターゲット向け `BaseData.session.staffMemberId` は別 API であり今回の変更の影響を受けない。

Shopify Customer Account API: lastIncompleteCheckout と Checkout タイプが 2026-10 で削除 — カート API への移行を推奨

shopify
🔗 Shopify Developer Changelog

API バージョン 2026-10 において、Customer Account API の `Customer.lastIncompleteCheckout` フィールドおよび `Checkout` タイプが削除される。バイヤーのストアフロント体験でアクティブなカートやチェックアウト状態を取得する必要がある場合は、Storefront API のカートフローへの移行が推奨される。あわせて GraphQL Admin API 2026-10 では `DraftOrderDiscountNotAppliedWarning.priceRule` も削除されるため、これらのフィールドを使用しているアプリは早急に対応が必要。

CISA、CVE-2025-39682（Linux カーネル kTLS 脆弱性、CVSS 9.8）を KEV カタログに追加 — 修正期限は 9/21

security
🔗 CISA

9 月 18 日、CISA が Linux カーネルの kTLS（Kernel TLS）受信処理に存在する脆弱性 CVE-2025-39682（CVSS 9.8 CRITICAL）を Known Exploited Vulnerabilities カタログに追加した。`net/tls/tls_sw.c` において長さゼロのレコード処理が不適切で、リモートピアが特殊なパケットを送信するだけでカーネルクラッシュを引き起こす DoS 攻撃が可能。Linux 6.1.149・6.6.103・6.12.44・6.16.4・6.17 で修正済みであり、Debian・Amazon Linux 2023 向けディストリビューション修正も提供されている。連邦機関の対応期限は 9 月 21 日。
