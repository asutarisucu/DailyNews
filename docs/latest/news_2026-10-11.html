Script Tags が正式廃止フェーズへ — 10月1日より scriptTagCreate・scriptTagUpdate がエラー、2027年3月1日に注入停止

shopify
🔗 Shopify Developer Changelog

2026年10月1日から scriptTagCreate および scriptTagUpdate ミューテーションはユーザーエラーを返すようになり、REST リソースの POST・PUT も拒否される。既存のスクリプトタグは引き続き動作するが、2027年3月1日にストアフロントへの注入が完全停止する。移行先はテーマアプリエクステンションの app embed block、または計測用途には Web Pixel の利用が推奨されている。影響を受けるアプリは早急に代替実装のリリースが必要だ。

Next Gen Events が 2026-10 API で GA — 従来 Webhook の宣言的後継、18 トピックに対応し段階的移行が可能

shopify
🔗 Shopify Developer Blog

Shopify の Events（旧来 Webhook の次世代後継）が 2026-10 API バージョンで一般提供（GA）となった。18 トピックをカバーし、受け取る変更の種類やペイロードに含めるデータをきめ細かく選択できる宣言的なモデルを採用している。既存の Webhook と同一アプリ内で共存でき、ワークフローを一件ずつ移行できるため段階的な対応が可能。利用には Shopify CLI 4.83 以上が必要だ。

shopify
🔗 Shopify Developer Changelog

Catalog API において、商品バリアントごとのマーチャント設定比較価格が list_price フィールドとして返されるようになった。price フィールドの値に変更はなく後方互換性は維持される。また Global Catalog REST API は 2026 年 11 月 2 日にトラフィック提供を停止するため、同 API を利用しているインテグレーションは GraphQL Catalog API への移行が必要となる。
