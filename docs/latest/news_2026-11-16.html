Shopify の2026年ホリデー商戦レポート — 買い物客の65%が少なくとも1つの購買タスクで AI を利用予定

shopify
🔗 KTVZ（Shopify Global Holiday Retail Report）

Shopify が公開した「2026 Global Holiday Retail Report」によると、今年のホリデーシーズンに買い物客の65%が少なくとも1つのショッピングタスクで AI を使う予定だという。ただし用途は商品リサーチが中心で、エージェントに購入の完了まで任せる段階には至っていない。Shopify は第3四半期決算で AI 経由のトラフィックが前年比2.6倍になったとしており、ストアの商品データや UCP 対応など、AI エージェントから参照されやすい状態に整えておくことが重要になる。

OpenAI が研究インフラ向け安全機構「Control Room」を公開 — 介入決定から35秒以内にモデルの出力を停止

ai
🔗 Interesting Engineering

OpenAI は、研究用インフラ上のモデル推論ワークロードを一元的に追跡・停止する社内システム「Control Room」の詳細を明らかにした。学習・評価用のエージェント的サンプリングやデータ処理を含む研究推論を接続し、不整合（ミスアライメント）監視システムと連携して、介入の決定から35秒以内に出力を止められるという。システムが停止・改ざんされた場合は推論要求を拒否する「フェイルクローズ」設計で、Control Room を経由しない未承認のエンジンも定期的に探索する。一般向け API 製品ではない点に注意。

FBI が AI 攻撃フレームワーク「ARTEX」の悪用に警告 — 初期侵入から特権取得まで3時間未満の事例も

security
🔗 BleepingComputer

FBI はフラッシュアラートで、オープンソースの AI ペネトレーションテスト基盤「ARTEX」が少なくとも8月以降、金融・政府・防衛・エネルギー・医療など幅広い組織への攻撃自動化に使われていると警告した。LLM エージェントが偵察・脆弱性悪用・権限昇格・データ窃取を連携して実行し、標的選定から特権アクセス取得まで3時間かからなかった侵入もあるという。10月の ConnectWise Cloud Backup サプライチェーン攻撃にも使われたとされ、元リポジトリ削除後もフォークや商用版が出回っている。FBI はインターネット公開システムの棚卸し、Kudu/SCM やクラウド管理エンドポイントの制限、アプリ同意付与の最小権限化を推奨している。

FBI、北朝鮮系ハッカーがディープフェイクのビデオ通話で4億ドル超の暗号資産を窃取と発表 — 手口は「FaceStealer」

security
🔗 The Hacker News

FBI は、北朝鮮系の攻撃者が「FaceStealer」と呼ばれる手口で過去18カ月に4億ドル超の暗号資産を盗んだと明らかにした。被害者の知人になりすましてビデオ会議に誘い込み、AI によるディープフェイク映像で信用させてマルウェアを実行させるもので、標的の多くは創業者や経営幹部だった。米司法省は11月12日に攻撃基盤のクラウドインフラを差し押さえたと発表し、FBI は活動を BlueNoroff（APT38 / Sapphire Sleet）と結び付けている。ビデオ会議中に追加ソフトのインストールを求められた場合は別経路で本人確認することが重要だ。

【要更新】OpenSSH の認証回避「sshole」（CVE-2026-123158）が悪用中 — musl libc かつ PAM 無効の環境、Alpine Linux などが対象

security
🔗 SecurityWeek

musl libc にリンクされ PAM を無効にした sshd（Alpine Linux ベースのコンテナやサーバーなど）で、パスワードが設定されていないアカウントに十分長い任意の文字列でログインできてしまう脆弱性 CVE-2026-123158「sshole」が報告され、すでに悪用が確認されている。修正は11月5日公開の OpenSSH 10.6p2 で、GreyNoise は複数の送信元からの攻撃成功チェーンを観測した。glibc＋PAM 構成の Debian / Ubuntu は該当しない。すぐに更新できない場合は sshd_config で PasswordAuthentication no を設定して再起動すれば攻撃経路を塞げる。

Android の未修正の欠陥「GhostMap」— 権限不要の悪意あるアプリで端末を再起動ループに陥らせる

security
🔗 BleepingComputer

Bitdefender は、権限を一切要求しない細工したアプリをインストールするだけで、Android 端末を永続的なブートループに陥らせられる欠陥「GhostMap」を公表した。2つのシステムライブラリが ZIP の圧縮方式を異なる形で解釈することが原因で、セーフモードでも中核サービスがクラッシュし、復旧に初期化が必要になる場合がある。Android 10 以降で再現し、8月パッチ適用済みの Pixel 10（Android 17）でも確認されたが、11月のセキュリティ更新でも修正されていないとみられる。現時点で悪用は確認されていないが、提供元不明の APK のサイドロードを避け、バックアップを取っておくことが推奨される。

Cloudflare が利用額の上限設定とアラート機能「Spend Management」をベータ提供 — まず Workers と Durable Objects に対応

cloud
🔗 Cloudflare Blog

Cloudflare は、従量課金（Pay-as-you-go）の顧客向けに、オプトイン方式で利用額の上限とアラートを設定できる「Spend Management」をベータとして提供開始した。対象はまず Workers と Durable Objects で、設定した上限に達するとブロックポリシーが適用され、該当プロダクトが自動的に一時停止される。想定外のトラフィックや暴走したエージェントによる高額請求を防ぐ手段になる一方、上限到達時にサービスが止まる点は運用設計で考慮が必要だ。
