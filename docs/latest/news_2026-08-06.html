🔒 セキュリティ

CISA KEV に CVE-2026-18577 追加 — N-able N-central の認証バイパス脆弱性が野外で積極的に悪用、8月6日までに修正必須

security
🔗 The Hacker News

CISAが8月3日、N-able N-centralの認証バイパス脆弱性 CVE-2026-18577（CVSSスコア: 8.2）をKnown Exploited Vulnerabilities（KEV）カタログに追加した。本脆弱性は以前に修正されたCVE-2026-18556の不完全なパッチが原因であり、認証バイパスとアカウント乗っ取りが可能。攻撃者はN-centralサーバの管理者権限を奪取後、内蔵の「Take Control」機能を悪用して管理下のエンドポイントへ横断侵入し永続的なバックドアを仕込める。修正版はバージョン2026.3 HF1。連邦機関（FCEB）は本日（8月6日）までの適用が義務付けられており、N-central Take Controlのアクティビティ監査も推奨されている。

npm — 2FA バイパス設定のグラニュラーアクセストークンがアカウント管理操作を実行不可に（7月31日〜）

security
🔗 GitHub Changelog

7月31日より、2FAバイパス設定のnpmグラニュラーアクセストークン（GAT）がトークン管理・組織/チーム管理・パッケージアクセス変更などの高権限操作を実行できなくなった。これらの操作には今後インタラクティブな2FAチャレンジが必要になる。本変更は「Mini Shai-Hulud攻撃」（単一の漏洩トークンで22分以内に323パッケージ・639バージョンに悪意あるコードが注入された事件）を受けた対策。2027年1月にはパブリッシング操作もOIDCトラステッドパブリッシングへ移行し、常設トークン方式が廃止される予定。

npm 12 リリース — インストールスクリプトをデフォルト無効化、16年の歴史で最大規模のサプライチェーン対策

dev
🔗 The Hacker News

npm v12が7月にリリースされ、preinstall/install/postinstall スクリプトがデフォルトで自動実行されなくなった。実行するには npm approve-scripts による明示的な承認が必要。平均的なnpmプロジェクトは79の推移的依存関係を抱えており、その任意の1パッケージに悪意あるスクリプトが仕込まれていた場合、npm install 一発でコードが実行されていた。本変更はAxisoとMastra AIを標的とした北朝鮮のサプライチェーン攻撃、および「Miasmaワーム」（2時間以内に57パッケージを感染させた攻撃）への直接対応となる。既存のCI/CDパイプラインへの影響確認が必要。
