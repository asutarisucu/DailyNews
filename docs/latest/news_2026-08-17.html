Shopify Oxygen: 開発ストアからの Hydrogen デプロイが解禁 — 有料プランなしで Oxygen ホスティングをテスト可能に

shopify
🔗 Shopify Developer Changelog

2026年8月3日より、開発ストア（dev store）から Hydrogen ストアフロントを Oxygen にデプロイできるようになった。これまで Oxygen ホスティングには有料プランが必要だったが、今回の変更で開発・検証フェーズでも Oxygen のエッジデプロイを試験できる。ただし開発ストアにはパブリック環境が含まれないため、デプロイ URL は常にストアログインが必要になる点に注意。ヘッドレスストアフロントを開発中のチームにとって開発サイクルが大幅に短縮される改善となる。

shopify
🔗 Revize Blog

2026年8月26日は Basic・Shopify・Advanced プランのすべての非 Plus ストアにとって Checkout Extensibility への移行最終期限となる。この日を過ぎると Shopify はすべての Additional Scripts・トラッキングピクセル・GTM コンテナを自動削除する。Google Ads・Meta ピクセル・GTM・アフィリエイトスクリプト・購入後アプリがすべて機能停止するにもかかわらず、ストアフロントに目視エラーは表示されないため見落としに注意が必要。未移行ストアは今すぐ Checkout UI Extensions と Shopify Pixels への置き換えを急ぐことを推奨する。

【CVSS 10.0】CVE-2026-72898: Metabase に認証不要の SQL インジェクション — 野放し攻撃中・CISA KEV 登録済み・即時パッチ適用を

security
🔗 Bishop Fox

オープンソースの BI ツール Metabase にCVSS 10.0（最高スコア）の SQL インジェクション脆弱性（CVE-2026-72898）が確認された。パスワードリセットエンドポイント /api/session/reset_password を経由して認証なしで任意の SQL を注入でき、管理者権限の奪取・接続データベースの認証情報窃取・データ流出が可能。セルフホスト版の 0.58〜0.63.4 が影響を受ける。Metabase は8月6日にパッチ済みリリース（0.58.28〜0.63.10）を提供済みで、CISA が8月11日に KEV カタログへ追加した。自社環境に Metabase を導入している場合は直ちに更新が必要。

CISA KEV 更新（8/11）: Cisco ASA/FTD ヒープ検査・Metabase SQLi など3件を追加 — BOD 26-04 に基づき優先対応を

security
🔗 CISA

CISA が2026年8月11日に Known Exploited Vulnerabilities (KEV) カタログへ3件の脆弱性を追加した。CVE-2026-20349（Cisco Secure Firewall ASA および FTD のヒープ検査の脆弱性）、CVE-2026-68820（Microsoft Windows WinSock カーネルドライバの解放後使用、Lazarus グループが悪用）、CVE-2026-72898（Metabase の SQL インジェクション）が対象。BOD 26-04 に基づき連邦政府機関は指定期限までのパッチ適用が義務付けられており、民間組織も KEV に基づくリスク優先対処を強く推奨する。
