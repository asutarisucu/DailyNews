🛒 Shopify 開発者情報

Shopify Oxygen が開発ストアでも利用可能に — 有料プランなしで Hydrogen ストアフロントをデプロイ・検証できるように

shopify
🔗 Shopify Developer Changelog

2026年8月3日より、開発用ストア（dev store）から Hydrogen ストアフロントを Oxygen にデプロイできるようになった。これまで Oxygen ホスティングは有料プランが前提だったが、この変更により費用をかけずに本番相当の環境でストアフロントをテスト・評価できる。ただし dev store は公開環境（public environment）を持てないため、デプロイ URL には常にストアへのログインが必要となる点に注意。

shopify
🔗 Shopify Developer Changelog

GraphQL Admin API の Cash Drawer オブジェクトにドロワー現在残高を返す balance フィールドが追加された。また Cash Count Activity には担当者コメント（note）とカスタム理由コード（reasonCode）が追加され、開店・閉店時のキャッシュカウント詳細をアプリからより細かく参照できるようになる。カスタムキャッシュ管理ワークフローを構築する POS 向けアプリ開発者は API バージョン 2026-10 への移行時に活用できる。

🔒 セキュリティ

【緊急】CISA KEV に4件追加（8/18）: VMware vCenter CVSS 9.8 パストラバーサル・MS SharePoint 弱認証・Apple macOS 不正認証など全脆弱性に対応必須

security
🔗 CISA

CISA が8月18日に既知悪用脆弱性（KEV）カタログへ4件を追加した。CVE-2026-59310（Broadcom VMware vCenter、パストラバーサル、CVSS 9.8）はネットワーク接続のみで任意コード実行が可能。CVE-2026-55040（Microsoft SharePoint、弱認証バイパス、CVSS 9.1）は認証回避による不正アクセスを許す。CVE-2026-33824（Microsoft IKE サービス拡張、ダブルフリー）と CVE-2026-65400（Apple macOS、不正認証）も追加されており、連邦機関は期限内の修正パッチ適用が義務付けられた。

VMware vCenter CVE-2026-59310 が実際の攻撃で活発に悪用 — パストラバーサルでリモートコード実行、恒久的バックドア設置まで確認

security
🔗 The Hacker News

Broadcom VMware vCenter のパストラバーサル脆弱性 CVE-2026-59310（CVSS 9.8）が実際の攻撃者によって積極的に悪用されていることが確認された。ネットワーク経由でのアクセスにより任意コード実行が可能で、侵害後に持続的なバックドアが設置されたケースも報告されている。Broadcom はパッチをリリース済みで CISA も KEV カタログへの追加と対処期限を設定している。vCenter を利用している組織はただちに Broadcom の公式パッチを適用することを強く推奨する。

dev
🔗 GitHub Changelog

2026年7月31日より、npm のグラニュラーアクセストークン（GAT）で 2FA バイパスが設定されたトークンは、アカウント設定変更・トークン作成・組織チーム管理・パッケージアクセス変更などの管理操作を実行できなくなった。これらの操作には対話型 2FA チャレンジが必要となる。さらに 2027 年1月頃には直接パブリッシュも制限され、パブリッシュには人間による 2FA 承認が必要になる予定。レジストリ最大の認証情報ベース攻撃面が縮小される。
