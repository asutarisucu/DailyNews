Customer Account API: lastIncompleteCheckout と Checkout 型が 2026-10 で完全削除 — Storefront API Cart フローへの移行が必須に

shopify
🔗 Shopify Developer Changelog

Shopify の Customer Account API バージョン 2026-10 では、非推奨の Customer.lastIncompleteCheckout フィールドと Checkout 型サブツリーが完全に削除される。これらフィールドはすでに null を返しているため動作への影響はないが、2026-10 にアップグレードする前にクエリの更新が必要だ。アクティブなカート・チェックアウト状態が必要な場合は Storefront API のカートフロー、購入履歴には Customer.orders への移行が推奨される。

shopify
🔗 Shopify Developer Changelog

【過去最大規模】Microsoft 9月 Patch Tuesday — 973件修正・ゼロデイ2件（CVE-2026-85880 / CVE-2026-81963）、CISA が9/22 期限で即時パッチ適用を要求

security
🔗 BleepingComputer

9月9日の Patch Tuesday では記録を更新する 973件の脆弱性を修正。CVE-2026-85880（Windows ALPC ヒープバッファオーバーフロー：SYSTEM権限昇格）と CVE-2026-81963（Windows Update Stack EoP：SYSTEM権限昇格）の2件がゼロデイとして実悪用中。CISA は両 CVE を KEV カタログに追加し、連邦機関に9月22日までのパッチ適用を義務付けた。Critical 分類は 105件で、そのうち81件が RCE。

CISA KEV に5件を新規追加 — JFrog Artifactory・ConnectWise ScreenConnect（CVSS 9.9）・MikroTik RouterOS の実悪用を確認、即時対応必須

security
🔗 The Hacker News

CISA が JFrog Artifactory（CVE-2026-42016：認可バイパスによる権限昇格、CVE-2026-42018：匿名トークン漏洩）、ConnectWise ScreenConnect（CVE-2026-84869, CVSS 9.9：未認証でのリモートファイル転送・コード実行）、MikroTik RouterOS（CVE-2026-67277：カーネルメモリ漏洩・DoS、CVE-2026-86060：ポリシーマスク改竄による権限昇格）の5件を KEV カタログに追加した。RouterOS は9月13日、ScreenConnect は9月14日が連邦機関の対応期限。

Check Point VPN に CVSS 9.8 の重大 RCE 脆弱性2件（CVE-2026-85102/85103）— 未認証リモートコード実行が可能、9/9 に緊急パッチを配布済み

security
🔗 SecurityWeek

Check Point が Security Gateway および Spark Firewall の VPN 機能に影響する CVE-2026-85102（VPN ネゴシエーション時の不正証明書検証）と CVE-2026-85103 の2件を公開した。いずれも CVSS 9.8 で、未認証の攻撃者がリモートから任意のコードを実行できる深刻度の高い脆弱性だ。9月9日に緊急パッチを配布済みで、Jumbo Hotfix Accumulator（R82.10 Take 44 以降等）の即時適用が推奨される。

Cisco FMC/SCC CVE-2026-20079 — ランサムウェア・国家支援グループ含む3組織が積極悪用、OT/ICS環境にも波及リスク

dev
🔗 DEV Community
