dev
🔗 GitHub Changelog

2026年7月31日より、2FAバイパス設定のnpmグラニュラーアクセストークン（GAT）がセンシティブな操作（トークン作成・削除、パスワード/メール変更、パッケージアクセス変更、Org/チーム管理）を実行できなくなった。直接公開もステージング後の人的2FA承認が必要に変更。流出したトークン1つでアカウント乗っ取りが可能だった最大のクレデンシャル攻撃面を閉鎖する変更で、CI/CDパイプラインの見直しが必要な場合あり。
