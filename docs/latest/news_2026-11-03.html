Ivanti Connect Secure の追加脆弱性2件が KEV 入り — 既報ゼロデイと連鎖して root 権限奪取

security
🔗 SecurityOnline

CISA は10月30日、Ivanti Connect Secure の CVE-2026-111357（重要機能の認証欠如、権限昇格）と CVE-2026-118527（ファイル処理時の予測可能なファイル名）を既知の悪用済み脆弱性カタログ（KEV）に追加した。先に報じたゼロデイ CVE-2026-104935 と組み合わせ、ファイルを仕込んだうえで root 権限を得る攻撃チェーンとして悪用されている。影響は 25.1.1.2 以前および 22.8R2.5 以前で、Ivanti は10月29日に緊急アップデートを公開している。

Synology NAS を狙うランサムウェア「C3RB3R」が拡大 — ファイルを .L0CK3D に暗号化

security
🔗 IT-Connect

Cerber 系の亜種とされる C3RB3R ランサムウェアが Synology NAS を狙った攻撃を続けており、被害ファイルは拡張子 .L0CK3D に変更され各フォルダに身代金要求文が置かれる。侵入経路について、Qihoo 360 は9月に修正された DSM の重大な脆弱性2件の悪用と分析する一方、Synology は古い DSM を狙った攻撃として更新を呼びかけている。無料の復号ツールは確認されておらず、DSM の最新化と、NAS とは切り離したバックアップの確保が重要だ。

dev
🔗 MarkTechPost
