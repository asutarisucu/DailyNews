Anthropic、Messages API を Claude エージェントの手で Python から Rust に移行 — リクエストあたり CPU 約70%減・メモリ80%超減

ai
🔗 Unite.AI

Anthropic は11月25日、Claude API の中核である Messages API を Python から Rust へ書き換えた経緯を公開した。コードの大半は Claude エージェントが書き、既存の Python 実装を基準に挙動の差分を突き合わせながら移行を進めたという。リクエストあたりの CPU 使用量は約70%、メモリは80%以上削減され、最初のトークンまでの時間の中央値も約20%短縮された。テストに通るだけでは不十分で、本番トラフィックとの一致を検証する仕組みづくりが作業の要だったとしている。

Claude が「Skills over MCP」をパブリックベータで提供 — MCP の Tasks と Elicitation は一般提供に

ai
🔗 Claude

Anthropic は11月24日、MCP サーバーがスキルを配布できる「Skills over MCP」を Claude と Claude Code でパブリックベータとして公開した。Pro・Max・Ultra では既定で有効、Team は管理者による有効化が必要で、Enterprise は今後対応する。あわせて、長時間処理を MCP サーバーに任せて後から結果を受け取る「Tasks」と、処理の途中でフォームやリンクを通じてユーザーに入力を求める「Elicitation」が一般提供になった。いずれもオープンな MCP 仕様の一部で、ファイルアップロードへの対応も近く始まる予定。

OpenAI と Cisco がオープンソースの「Shirudo」を公開 — パッチ適用前の Linux を eBPF の「シールド」で一時防御

ai
🔗 OpenAI

OpenAI と Cisco は、稼働中の Linux システムに一時的な防御を適用するランタイム「Shirudo」をオープンソースで公開した。eBPF を使い、再起動なしで脆弱性の悪用をブロックする「シールド」を読み込み、管理者が正式なパッチを準備・展開するまでの時間を稼ぐ。Codex にシールドを生成させる使い方を想定し、シールドは暗号署名され、読み込み前の検証と運用者の承認が必要。Isovalent の Tetragon を書き直したもので、現時点では実験的なプレリリースとされている。

🔒 セキュリティ

【要更新】Drupal コアのインストーラーの RCE 脆弱性 CVE-2026-132165 が悪用中 — 未認証でサイト乗っ取りが可能

security
🔗 BleepingComputer

Drupal コアのインストーラーに、匿名ユーザーが Drupal の再インストールを試みてサイトを乗っ取ったりリモートコード実行したりできる重大な脆弱性 CVE-2026-132165 が見つかった。Anthropic の OSS スキャナーが発見したもので、Drupal は修正版公開の翌日にあたる11月19日から実際に悪用されていると勧告を更新した。修正版は 10.6.22、11.3.22、11.4.13 で、サポートが終了した 11.2.x、10.5.x 以前には修正が提供されない。CISA は KEV に追加し、連邦機関に11月27日までの対応を求めている。更新に加えて /core/install.php へのアクセス遮断とログの確認が推奨されている。

Check Point のセキュリティ管理サーバー24台が侵害 — 17カ国22組織を狙ったスパイ活動と GreyNoise が報告

security
🔗 CSO Online

GreyNoise は、17カ国22組織の Check Point セキュリティ管理サーバー計24台が侵害された攻撃キャンペーン「GT13」を報告した。攻撃者は10月17日から11月2日にかけて活動し、100件を超える管理タスクを実行してファイアウォールのデータベースや内部 CA を持ち出し、セキュリティポリシーのアンロードも試みたという。初期侵入の手口は不明だが、侵入後の段階で CVE-2026-16232 の悪用が確認された。GreyNoise は AI エージェントの関与を疑っている。Check Point は管理サーバーへのアクセスを信頼できるネットワークと IP に限定するよう呼びかけている。

CISA が KEV に10件を一括追加 — Danfoss AK-SM 800A、HPE Juniper Session Smart Router、Mitel MiCollab など

security
🔗 CISA

CISA は11月25日、悪用が確認された脆弱性10件を KEV カタログに追加した。Danfoss の冷凍設備向けコントローラー AK-SM 800A シリーズの3件（CVE-2023-25914、CVE-2023-25915、CVE-2025-41450）、HPE Juniper Session Smart Conductor / Router の OS コマンドインジェクション（CVE-2026-103406）、Mitel MiCollab のファイルアップロードの欠陥（CVE-2026-133275）などが含まれる。該当製品を使っている組織は、更新の適用や露出状況の確認を急ぎたい。

BigQuery で時系列分析の ML 関数4種が一般提供に — 埋め込みモデル embeddinggemma-300m も GA

cloud
🔗 Google Cloud

Google Cloud は11月24日付の BigQuery リリースノートで、テーブル値の ML 関数 ML.TREND、ML.SEASONALITY、ML.DETECT_CHANGE_POINTS、ML.CORRELATION の一般提供（GA）を案内した。クエリエディタのほか、会話型分析でも利用できる。また AI.EMBED と AI.SIMILARITY 関数で使える組み込み埋め込みモデル embeddinggemma-300m も GA になった。Databricks の SQL を GoogleSQL に変換する機能はプレビューで提供される。

Azure と Google Cloud を直結する「Azure Multicloud Interconnect」がパブリックプレビューに — 両社が共同サポート

cloud
🔗 Microsoft Tech Community

Microsoft と Google は、Azure と Google Cloud の間をプライベートで高帯域に数分で接続できる相互接続サービスをプレビューで提供開始した。Microsoft 側は「Azure Multicloud Interconnect with Google Cloud」、Google 側は「Partner Cross-Cloud Interconnect for Azure」と呼び、両社が共同でサポートする。初期のプレビュー提供は Google Cloud の us-east4（北バージニア）などから始まる。AWS も Interconnect - multicloud を一般提供しており、大手クラウド間の直接接続が相次いで整いつつある。

Vercel が人とコーディングエージェントのための掲示板「Vercel Board」を実験提供 — Claude Code や Codex がタスクを分担

dev
🔗 InfoQ

Vercel は、人とコーディングエージェントがタスクを調整するためのヘッドレスな掲示板「Vercel Board」を実験的機能として全プランで公開した。エージェントは CLI や SDK からリース付きでタスクを確保し、進捗や結果を書き込める。タスク間の依存関係や、返信・ラベル変更時にエージェントを起こすウォッチャー、予約フォローアップにも対応する。Claude Code、Codex、OpenCode、Mastra、LangChain などが同じボードで協働でき、Slack・GitHub・Linear と双方向で同期する。データの保存先は米国のみで、リージョンは選べない。

Vercel のオープンソース・エージェントフレームワーク「eve」が1.0で一般提供に

dev
🔗 Vercel

Vercel は、本番運用向けの AI エージェントを構築するオープンソースフレームワーク「eve」のバージョン1.0を一般提供した。セッションをまたいだ組み込みメモリや、リポジトリの AGENTS.md に従って動くコーディング拡張などを備える。@eve/board パッケージを使えば、eve で作ったエージェントを Vercel Board の参加者としてタスク処理やフォローアップの予約に使える。
