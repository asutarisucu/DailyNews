OpenAI、データセンターの電力コスト全額負担と自治体関係者との NDA 廃止を表明 — 中間選挙での住民投票の逆風を受けて

ai
🔗 Android Headlines

OpenAI は11月5日、データセンター立地に関する新方針を公表した。自社が所有・運営するデータセンターについて電力と送電網インフラの費用を負担し、計画の遅延・縮小・中止時にも地域の電気料金利用者を保護するとしている。立地交渉で公職者と秘密保持契約（NDA）を結ぶ慣行もやめ、建設・水・エネルギー使用に関するサイト単位の情報を公開する方針だ。中間選挙で10州・41件のデータセンター関連の住民投票のうち40件で規制側が支持されたことを受けた動きとされる。

ai
🔗 Google Blog

Google は11月5日、動画の生成・編集モデル「Gemini Omni 1.2 Flash」を一般提供（GA）した。クリップ長は従来の10秒から最長15秒になり、3〜15秒の任意の秒数を指定できる。720p の料金は1秒あたり0.07ドルと Omni 1.1 比で約30%安くなり、対話形式で複数回の編集を重ねることもできる。Gemini API、Google AI Studio、Google Cloud、Flow、Google Vids などで利用でき、生成動画には SynthID の電子透かしが入る。

musl 系 Linux の OpenSSH で、パスワード無効化済みアカウントにログインできる問題「*sshole」が公開

security
🔗 BleepingComputer

研究者の Ozgun Kultekin 氏が、Alpine Linux など musl C ライブラリを使うディストリビューション上の OpenSSH サーバーで、パスワード認証を無効化したアカウントに極端に長いパスワードを入力するだけでログインできてしまう問題を公開した。原因は musl の crypt() がハッシュ化に失敗したときの戻り値の扱いにある。影響は musl ベースの環境に限られるが、コンテナのベースイメージとして Alpine は広く使われているため、公開 SSH を持つ環境では各ディストリビューションの修正情報を確認したい。

Zyxel GS1900 スイッチ約1,000台への攻撃は別のゼロデイ CVE-2026-107441 だった — 6月の修正では防げず

🔗 BleepingComputer

9月に CVE-2026-7273 の悪用とされた Zyxel GS1900 スイッチへの攻撃について、Binarly は実際には CGI プログラムの別の境界外書き込み脆弱性 CVE-2026-107441 が使われていたと報告した。6月に公開された CVE-2026-7273 の修正（Patch 2）では今回の攻撃を防げず、KEV の期限どおりに対応した組織も依然として影響を受けていた。Zyxel は10月23日に修正ファームウェア 2.90 Patch 3 を公開しており、全台への適用と設定変更の確認、特権資格情報のローテーションが推奨されている。

Debian / Ubuntu の APT に脆弱性 CVE-2026-109518 — 中間者が検証済みパッケージを差し替え root でコード実行

security
🔗 The Hacker News

Debian は11月4日、パッケージマネージャー APT の脆弱性 CVE-2026-109518 を公表した。HTTP リダイレクトで2つのダウンロードが同じ URI に解決される場合や、HTTP ダウンロード再開時のファイル処理の不備を突くと、悪意あるミラーやプロキシなど通信経路上の攻撃者が署名検証後のパッケージを差し替えられる。リトライが既定で有効な Debian 12 / Ubuntu 22.04 以降が主な影響対象で、Ubuntu は CVSS v4.0 で7.7と評価している。修正版 APT への更新に加え、HTTPS のリポジトリを使えば攻撃を防げる。

🔗 CISA

AWS DataSync の Enhanced モードが Google Cloud Storage / Azure Blob Storage 向けに OIDC 認証をサポート

cloud
🔗 AWS What's New

AWS DataSync の Enhanced モードで、Google Cloud Storage と Azure Blob Storage のロケーションに OpenID Connect（OIDC）による認証を使えるようになった。これにより、他クラウドから Amazon S3 へのデータ転送で長期間有効なアクセスキーを発行・保管する必要がなくなる。マルチクラウド間のデータ移行や定期転送を行っている場合、静的な認証情報を減らしてセキュリティを高められる。

【要確認】Azure が2027年2月1日から欧州などで値上げ — ダブリン（North Europe）は最大17%、旧世代 VM は全リージョンで約25%

cloud
🔗 Techzine

Microsoft は2027年2月1日から、一部の Azure 仮想マシンとストレージの料金を地域別に引き上げる。報道によると North Europe（ダブリン）が17%と最も大きく、West Europe（アムステルダム）は9%で、フランス・ノルウェー・シンガポールなども対象となる。これとは別に v1 / v2 系の旧世代 VM シリーズは全リージョンで約25%値上がりし、2月1日以降に購入した予約インスタンスは交換できなくなるとされる。正式な条件は Azure Service Health の通知で確認したい。

Vercel がログインセッションを端末に紐付ける DBSC を導入、AI によるセキュリティレビューもパブリックベータに

dev
🔗 Help Net Security

Vercel は、セッション Cookie の窃取によるなりすましを防ぐ Device Bound Session Credentials（DBSC）の段階的な展開を始めた。TPM に保存した秘密鍵でセッションを端末に紐付けるため、インフォスティーラーに Cookie を盗まれても別の端末では再利用できない。あわせて、GitHub へのプッシュごとにコードの脆弱性をチェックする Vercel Agent の「Security Review」がパブリックベータとなり、11月10日まで無料で使える（エージェントによる修正は別途課金）。
