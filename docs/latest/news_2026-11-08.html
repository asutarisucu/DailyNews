🛒 Shopify 開発者情報

【要確認】パートナーアプリは一括操作（バルクオペレーション）の利用前に有効化が必須に — 31日間未使用だとアクセス失効

shopify
🔗 Shopify Developer Changelog

Shopify は11月6日、公開アプリおよびパートナーとして構築したカスタムアプリが GraphQL Admin API のバルクオペレーションを実行するには、事前にアクセスの有効化が必要になったと告知した。Partner Dashboard の「Run bulk operations」で、バルククエリとバルクミューテーションを個別に許可する。すでにバルク操作を実行しているアプリは有効化済みだが、直近31日間に実行していない操作種別はアクセスが失われ、未許可のまま実行すると access denied エラーになる。全 API バージョンが対象で、管理画面や Dev Dashboard でマーチャントが作成したアプリは今のところ対象外。

🔗 Shopify Developer Changelog

🔒 セキュリティ

SonicWall が SonicOS の脆弱性7件を修正 — SAML 認証の SSL-VPN で MFA を回避できる CVE-2026-19868 は悪用中、CISA も KEV に追加

security
🔗 BleepingComputer

SonicWall は11月6日、SonicOS の脆弱性7件を修正し、そのうち CVE-2026-19868（CVSS 7.1）が実際の攻撃に悪用されていると警告した。SAML 認証を使う SSL-VPN が対象で、別の認証方式の有効な資格情報を持つ攻撃者が SAML による制御（SAML で強制した MFA を含む）をすり抜けられる。修正版は Gen7 が 7.3.4-7013、Gen8 が 8.2.3-8015 で、回避策はない。CISA は同日 KEV カタログに追加し、連邦機関に11月20日までの対応を求めている。

Barracuda Email Security Gateway の脆弱性2件を連鎖させ未認証で root 権限 — パッチ公開済み、現時点で悪用は未確認

security
🔗 SecurityWeek

Barracuda は11月2日、Email Security Gateway（ESG）などに影響する脆弱性2件の修正を公開した。CVE-2026-116606（CVSS 9.3）は ESG の設定インポート API を未認証で呼び出せる認可バイパスで、CVE-2026-111560（CVSS 8.6）は管理者権限で root としてコマンドを実行できる OS コマンドインジェクション。後者は Web Security Gateway、WAF、Load Balancer ADC にも影響する。両者を組み合わせると未認証で root を奪えるため、古いファームウェアでは段階的なアップグレードが必要な点に注意して早めに適用したい。
