Script Tags 廃止タイムライン確定 — 2026年10月よりミューテーションがエラーを返し、2027年3月1日にストアフロント注入を完全停止

shopify
🔗 Shopify Developer Changelog

Shopify が8月24日に Script Tag の廃止スケジュールを正式発表。2026年10月1日より scriptTagCreate・scriptTagUpdate ミューテーションがユーザーエラーを返すようになり、REST Admin API の POST/PUT も拒否される。全 API バージョンに横断的に適用されるため古いバージョンへのピン留めで回避することはできない。ストアフロントへの注入は 2027年3月1日に完全停止。アプリはアプリ埋め込みブロックまたはウェブピクセルへの移行が必要で、早期対応が推奨される。

Additional Scripts 廃止完了（8月26日）— Basic・Shopify・Advanced プランの Thank you / Order status ページ スクリプトボックスが削除

shopify
🔗 Makseong

2026年8月26日、Shopify の Basic・Shopify・Advanced プラン（非 Plus）で Additional Scripts フィールドと Thank you / Order status ページのスクリプトボックスが削除された。これらのフィールドに入れていたカスタム追跡コードや GTM スニペットはすでに動作を停止している。移行先は Shopify Web Pixels または Checkout UI Extensions で、デフォルトのチェックアウトとサンクスページへの直接スクリプト埋め込みは今後利用不可。Shopify Plus は引き続き Additional Scripts を一定期間利用可能だが段階廃止の方針は変わらない。

shopify
🔗 Shopify Developer Changelog

Shopify が8月27日のチェンジログで、Theme CLI v3.83.x 以前のバージョンで使用できるパスワード保護ストア用の開発フロー（Password Protected Shop Dev flows）を廃止すると告知した。現在このフローを利用して theme dev を実行している開発者は、最新の CLI バージョンへのアップグレードと新しい認証フローへの移行が必要。移行しない場合、旧バージョン CLI ではパスワード保護ストアへの接続ができなくなる。Theme CLI の継続的なセキュリティ強化の一環として実施される変更。

shopify
🔗 Shopify Developer Changelog

Shopify Hydrogen の8月18日付 developer preview で複数の重要機能が追加された。カートと Customer Account セッションを同期させる「カートセッション属性」により、ログイン済み購入者がゲストフローを経由せず保存済み情報で直接チェックアウトできるようになった。クライアントサイドナビゲーションでも標準ページビューイベントを発火するよう修正され、分析ツールへの計測漏れを解消。さらに Shop Pay ボタンが外部スクリプト読み込み完了を待たずに即時レンダリングされるようになり、表示速度が改善。新スキルとして hydrogen-customer-account と hydrogen-local-https も追加されている。

🔗 Anthropic Developer Platform Changelog

security
🔗 The Hacker News

CISA が8月24日に CVE-2026-21962 を既知悪用脆弱性（KEV）カタログへ追加し、連邦機関に対して本日（8月27日）までの対処を義務付けた。Oracle HTTP Server および Oracle WebLogic Server Proxy Plug-in for Apache/IIS に存在する不正アクセス制御の欠陥で、CVSS スコアは最大値の 10.0。認証なしにネットワーク越しの HTTP リクエストだけで機密データへの不正アクセス・改ざん・削除が可能。中国政府に紐付く脅威アクターが世界100カ国以上の政府機関・商業ネットワークに対して実際の攻撃で悪用が確認されており、Oracle 1月パッチで修正済みのため即座に適用すること。

security
🔗 CISA

CISA が8月11日に追加した KEV3件のうち、Metabase の SQL インジェクション脆弱性（CVE-2026-72898）が特に自社 BI 環境を運用するエンジニアへの影響が大きい。攻撃者がクエリを細工することで Metabase が接続するバックエンドデータベースに対して任意の SQL を実行でき、機密データの流出や改ざんが可能。Metabase を社内ツールとして利用している企業では最新版へのアップグレードとアクセス制御の見直しを優先的に実施すること。同時追加の Cisco Secure Firewall ASA/FTD ヒープインスペクション（CVE-2026-20349）も合わせて対応が必要。
