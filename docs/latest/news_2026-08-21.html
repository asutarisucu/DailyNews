security
🔗 The Hacker News

Rust サプライチェーン攻撃 — arrayref / internment / append-only-vec 3クレートが侵害、累計2.45億ダウンロードに影響・DPRK 関与の疑い

security
🔗 The Hacker News

8月20日、ripgrep 作者として知られる BurntSushi のアカウントが侵害され、arrayref 0.3.10 / internment 0.8.7 / append-only-vec 0.1.9 の3クレートに悪意ある build.rs スクリプトが混入された。コンパイル時に外部ペイロードをダウンロードして実行するビルドタイムドロッパーを通じ、累計2.45億ダウンロードのエコシステムが影響を受けた。Wiz の分析では北朝鮮 DPRK のサプライチェーン攻撃キャンペーンとの重複が確認されている。Nextron Systems のレポートを受けた Rust セキュリティ対応チームが約86〜107分以内に侵害バージョンを Yank して対応。該当クレートを利用しているプロジェクトはビルドキャッシュの検証と最新バージョンへの更新を推奨。

CISA KEV 更新（8/20）: TrueConf Server CVE-2026-72529/72530 を追加 — Head Mare グループが PhantomCore マルウェア展開に積極悪用中

security
🔗 CISA

CISA が8月20日、TrueConf Server の2件の脆弱性を Known Exploited Vulnerabilities（KEV）カタログに追加した。CVE-2026-72529 は TCP ポート 4307 への認証不要のリモートコード実行（未文書化関数の呼び出し）、CVE-2026-72530 はコードインジェクション。ハクティビストグループ Head Mare がこれらの欠陥を悪用して PhantomCore マルウェアを展開していることが確認されている。パッチは6月に TrueConf Server 5.3.9 / 5.4.9 / 5.5.5 で提供済みで、連邦機関は CVE-2026-72529 を3日以内、CVE-2026-72530 を2週間以内にパッチ適用することが義務付けられた。

npm bypass-2FA トークン制限が8月から本格適用 — granular access token のアカウント操作権限が剥奪、2027年1月には直接 publish も不可に

security
🔗 GitHub Changelog

8月から、bypass2fa=true で設定された npm の granular access token（GAT）がアカウントガバナンス操作（トークン作成・削除、パスワード変更、2FA 設定変更、組織メンバーシップ管理など）に利用できなくなった。これらのアクションには常にインタラクティブな 2FA チャレンジが必要になる。さらに2027年1月には、bypass-2FA トークンによる直接 npm publish も制限され、ステージング後にメンテナーが 2FA で承認する OIDC Trusted Publishing が事実上の標準となる。CI/CD で長期的な npm トークンを使用してパブリッシュしているプロジェクトは早急に移行計画を立てること。
