Hydrogen 2026-10 正式リリース — Next.js・SvelteKit・Astro など主要 JS フレームワーク対応のツールキットへ刷新

shopify
🔗 Shopify Developer Blog

Shopify の Hydrogen フレームワークがバージョン 2026-10 として正式リリースされた。従来の単独フレームワークから脱却し、Next.js・React Router・SvelteKit・Astro・SolidStart・Nuxt など主要 JavaScript フレームワーク上で動作するツールキットとして再設計されている。型安全な GraphQL クエリや Vue バインディングも含まれており、開発者はフレームワークを自由に選択しながら Shopify のコマース機能を統合できるようになった。

Shop MCP が公開 — 1 接続でカタログ検索・カート構築・Shop Pay チェックアウトをエージェントに統合

shopify
🔗 Shopify Developer Changelog

Shopify が Shop MCP（Model Context Protocol）サーバーを公開した。1 つの MCP 接続だけでエージェントがカタログ検索・カート構築・Shop Pay チェックアウトまでを完結できる。Claude・ChatGPT などの AI エージェントから Shopify のコマース機能を直接呼び出せるため、エージェントコマースの実装が大幅に簡素化される。ウェブフック未対応のためチェックアウト状態の確認にはポーリングが必要。

Google Cloud C4N マシンタイプが Titanium SSD 対応で GA — ストレージ集約型ワークロード向けに最適化

cloud
🔗 FinOps Weekly

Google Cloud の C4N マシンタイプが Titanium SSD サポートを含めて一般提供（GA）となった。Titanium SSD は Google 独自のカスタムストレージスタックを採用し、従来の Persistent Disk に比べて高い IOPS と低遅延を実現する。データベースや分析ワークロードなどストレージ I/O が重要なユースケースで効果が大きく、Compute Engine にも global リソースのリージョン別読み取りビューが追加されている。

dev
🔗 Linuxiac
