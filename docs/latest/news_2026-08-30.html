Shopify Additional Scripts（checkout.liquid）を8月26日に完全廃止 — 非Plusストア向けチェックアウト移行が必須に

shopify
🔗 Makseong Blog

2026年8月26日をもって、Shopifyは非Plusストアに対して checkout.liquid・Additional Scripts フィールド・注文ステータスページのスクリプトタグを廃止した。これにより、Third-Partyトラッキングピクセルやカスタムチェックアウトスクリプトを同フィールドで管理していたストアは即時影響を受ける。移行先はWeb Pixels API（Customer Events）またはネイティブのGoogle・Meta・TikTokチャネルアプリが推奨される。未対応の場合はコンバージョン計測の欠損が発生するため、早急な対応が求められる。

Shopify ストアフロントの Script Tags 廃止決定 — 2027年3月1日に注入停止、移行はApp Embed Blocksへ

shopify
🔗 Shopify Developer Changelog

Shopifyは8月24日、ストアフロント向けの Script Tags（ScriptTag API）を段階的に廃止するタイムラインを発表した。2026年10月1日から scriptTagCreate・scriptTagUpdate ミューテーションがユーザーエラーを返すようになり、2027年3月1日にはスクリプトの注入が完全に停止される。開発者はApp Embed Blocks（テーマ拡張）またはWeb Pixels APIへの移行が必要。既存の ScriptTag を持つアプリは今すぐ移行計画を立てることが推奨される。
