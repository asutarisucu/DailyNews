shopify
🔗 Shopify Developer Changelog

レガシーカスタマーアカウントが廃止 — テンプレートファイルの要件も撤廃、新アカウント体験への移行を

shopify
🔗 Shopify Developer Changelog

Shopifyがレガシーカスタマーアカウントを正式に廃止した。テーマにレガシーカスタマーアカウントのテンプレートファイルを含めることが不要となり、shopify-account コンポーネントを使用した新しいアカウント体験への移行が促進される。既存のカスタムテーマを保守している開発者は、テンプレートの要件変更を確認した上で新しいシステムへの対応更新を推奨する。

Oxygen が Dev Store で利用可能に — 有料プランなしで Hydrogen ストアフロントのデプロイ・テストが可能

shopify
🔗 Shopify Developer Changelog

ShopifyのHydrogen向けホスティングサービス「Oxygen」が開発ストア（Dev Store）でも利用できるようになった。これまではOxygenの利用に有料プランが必要だったが、今後は開発中のHeadlessストアフロントを無料でデプロイ・テスト可能。ただし開発ストアにはパブリック環境が含まれないため、デプロイURLへのアクセスには常にストアログインが必要となる点に注意。

Cart アクションにカート属性更新を追加 — 新 shopify:cart:attributes-update イベントでアプリの即時検知・ロールバック対応

shopify
🔗 Shopify Developer Changelog

Shopify が standard Cart action にカート属性更新（cart attribute updates）を追加し、新しい shopify:cart:attributes-update イベントを導入した。アプリはカートの属性変更をリアルタイムで検知できるようになり、更新が拒否された場合のロールバックサポートも提供される。カートの状態変化への即応性を高めたいアプリ開発者は、このイベントの活用を検討したい。

🔗 The Hacker News

CISAがN-able N-centralの認証バイパス脆弱性CVE-2026-18577（CVSS 8.2）をKnown Exploited Vulnerabilities（KEV）カタログに追加した。CVE-2026-18556の不完全なパッチに起因し、リモート攻撃者が認証なしにN-centralサーバーの管理者権限を奪取・Take Control機能を悪用して管理対象エンドポイントへ侵入可能。実際の野良悪用が確認されており、N-able N-central 利用組織は即刻パッチ適用が必要。

DeadLock ランサムウェア — Rust 製、Windows Defender・バックアップを無効化し Polygon スマートコントラクトで C2 解体を防止

security
🔗 The Hacker News

DeadLockランサムウェアはRustで実装されており、暗号化前にWindows Defender・Volume Shadow Copy・バックアップサービス・イベントログを無効化する。C2設定をPolygonブロックチェーンのスマートコントラクトに格納することでサーバー差し押さえによるインフラ削除を無効化し、二重恐喝（データ窃取＋暗号化）を採用している。2026年7月時点で80社以上が被害を受けており、被害の半数以上がヨーロッパ企業。
