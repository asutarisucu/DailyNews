Shopify Scripts が6/30に完全廃止完了 — 移行未完ストアでチェックアウトロジックが消滅、Shopify Functions移行の事後対応を急ぐ

shopify
🔗 Shopify Developer Changelog

2026年6月30日をもってShopify Scriptsが完全廃止され、すべてのスクリプトが実行停止となった。移行が間に合わなかったストアでは、カスタム割引・配送ルール・B2B決済フィルタリングのロジックがShopifyのデフォルト動作に戻り、チェックアウト体験に影響が出ている。現時点でスクリプトの修正・再公開は不可のため、Shopify FunctionsまたはパブリックAppへの移行を最優先で完了させる必要がある。

SimpleHelp OIDC認証バイパス脆弱性 — 未署名JWTを検証せず受け入れ、リモートで完全認証迂回が可能 (CRITICAL / 7月1日 KEV追加)

security
🔗 CISA — Known Exploited Vulnerabilities Catalog

SimpleHelp（リモートサポートツール）にOIDC認証フローの重大な脆弱性が発見され、7月1日にCISA KEVへ追加された（CRITICAL評価）。ログイン時に提出されたIDトークンの暗号署名を検証せずに受け入れるため、未認証のリモート攻撃者が偽造トークンを送信するだけで完全に認証されたテクニシャンセッションを取得できる。SimpleHelp環境を運用している組織は即時パッチ対応が必要。
