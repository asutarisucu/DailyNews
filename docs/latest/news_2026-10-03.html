SubscriptionContractCalculation が SubscriptionDraft を置き換え — calculate → poll → commit のステートレスな新フローへ移行

shopify
🔗 Shopify Developer Changelog 2026-10

GraphQL Admin API 2026-10 に SubscriptionContractCalculation が追加され、複数ステップの Draft ワークフローに代わる後継として位置づけられた。新フローは「計算（calculate）→ ポーリング（poll）→ コミット（commit）」の3段階で構成され、サーバーに中間状態を保存しないステートレスな設計となっている。SubscriptionDraft は依然使用可能だが将来的な廃止が予告されているため、新規実装では SubscriptionContractCalculation を採用することが推奨される。

shopify
🔗 Shopify Developer Changelog 2026-10
