🔗 The Tech Buzz

【要対応】OpenRouter が推論プロバイダー3社を排除 — Dragos の「カナリア」調査でプロンプトや秘密情報の流出が判明

security
🔗 BleepingComputer

OpenRouter は11月22日、推論プロバイダー3社をプラットフォームから外し、125のエンドポイントを Zero Data Retention（ZDR）対象から除外したと発表した。Dragos が固有の偽リンクや偽認証情報を埋め込んだ約200万件のテストプロンプトを送ったところ、3社経由でデータが第三者に流出していたことが判明し、最も古い侵害は7月中旬にさかのぼる。BleepingComputer は対象を Together AI、Phala、Novita と報じている。影響を受けた可能性のある利用者は、リクエストに含めた API キーなどの秘密情報をローテーションすべきだ。

【要対応】Azure API Management の Classic 階層の欠陥が悪用され API 認証情報が窃取 — ノルウェーのエネルギー企業が標的

security
🔗 BleepingComputer

Microsoft は、Azure API Management（APIM）の Classic 階層（Developer / Basic / Standard / Premium）の欠陥が悪用され、インスタンスに保存されたアクセストークンやシークレット、名前付き値が盗まれたと警告した。v2 階層は影響を受けない。ノルウェー当局は Equinor と Skagerak Energi が標的になったとしている。Microsoft は11月19日に侵入経路を塞いだが、修正前に漏れた可能性のある認証情報は自動で無効化されないため、利用者自身によるローテーションと Key Vault 参照への移行が推奨される。

【要更新】ScreenConnect クライアントの CVE-2026-84869（CVSS 9.9）が MSP 技術者の PC 乗っ取りに悪用

security
🔗 Huntress

Huntress は、ConnectWise ScreenConnect の技術者側クライアントの脆弱性 CVE-2026-84869 が実際に悪用されたことを確認した。悪意あるゲスト側が技術者の PC にファイルを送り込み、警告なしに実行させることができ、11月12日には技術者端末1台の完全な侵害を観測、42の MSP サーバーで少なくとも68.8万件の不正なファイル要求が確認された。修正は9月公開の 26.6.5 で、全技術者のホストクライアントを 26.6.5 以降に更新し、Temp フォルダからのスクリプト起動を調査するよう呼びかけている。

security
🔗 BleepingComputer

iQSTEL 傘下の B2B デジタルギフトカード事業者 GlobeTopper は、10月22日に検知した侵入でプラットフォームを停止し、再構築を経て11月1日から段階的に業務を再開したと開示した。停止期間中の逸失売上は最大約250万ドルと見積もられ、額面約7万ドル分のギフトカードが不正に換金された。攻撃者は一部法人顧客の API 認証情報と連携キーも取得しており、これらは失効・再発行済みという。

Dataform・BigQuery Studio・Colab Enterprise にテナント横断のパストラバーサル CVE-2026-126054 — Google 側で修正済み

security
🔗 Google Cloud セキュリティ速報

Google Cloud はセキュリティ速報 GCP-2026-084 で、Dataform、BigQuery Studio、Colab Enterprise のワークスペースディレクトリ処理と Git 連携にパストラバーサルの脆弱性（CVE-2026-126054、Critical）があったと公表した。認証済みの攻撃者が他テナントのリポジトリの非公開ファイルを読み取ったり、任意のファイルを作成したりできる恐れがあった。修正は10月10日に適用済みで、利用者側の対応は不要とされている。

Amazon RDS for Oracle に「Primary Endpoint」— レプリカへの切り替え後も接続文字列を変えずにプライマリへ接続

cloud
🔗 AWS What's New

Amazon RDS for Oracle で、レプリケーション構成の現在のプライマリインスタンスを常に指す DNS 名「Primary Endpoint」が使えるようになった。Oracle レプリカへのスイッチオーバー時にエンドポイントが新しいプライマリへ自動的に向き直るため、アプリ側の接続設定を変更する必要がない。Enterprise Edition の全インスタンスに追加料金なしで自動付与され、既存のインスタンスエンドポイントと併存する。RDS for Oracle が提供される全商用リージョンで利用可能。

cloud
🔗 Google Cloud ドキュメント

Google Cloud は、非推奨となっていた Vertex AI Extensions を11月26日以降に停止する。移行ガイドでは、Code Interpreter 拡張は Agent Platform の Code Execution Sandbox（または Gemini API のコード実行ツール）、Google 検索拡張は Grounding with Google Search、OpenAPI 仕様で定義したカスタム拡張は Function Calling への移行が案内されている。まだ利用中の場合はサービス中断を避けるため早急な対応が必要だ。
