Hydrogen Developer Preview 更新（9月2日）— バリアントリンク・カートリフレッシュ・ローカル HTTPS 証明書自動生成を追加

shopify
🔗 Shopify Developer Changelog

Hydrogen の 2026年9月2日デベロッパープレビューでは3つの改善が追加された。バリアントリンク対応により Google Shopping フィードなどの特定バリアントへのリンクが商品デフォルト表示ではなく該当バリアントを直接開くようになった。カートリフレッシュは、サーバー側で作成したカートなど Hydrogen 外でのカート変更を useCartActions() または CartStore.refresh() で再同期できる機能。ローカル HTTPS 証明書は Customer Account テスト用に自動生成され、ローカル開発環境のセットアップが大幅に簡略化された。

Shopify CLI 4.8 リリース — ターミナルや AI コーディングエージェントから dev ストアの作成・一覧・削除が可能に

shopify
🔗 Shopify Developer Changelog

Shopify CLI 4.8 で shopify store サブコマンドが追加され、ターミナルや AI コーディングエージェントから dev ストアをプログラム的に管理できるようになった。shopify store create dev でテスト用 dev ストアを作成、shopify store list で組織内のストア一覧を取得、shopify store info で詳細情報を確認、shopify store delete で削除が可能。Shopify AI Toolkit との連携により、コーディングエージェントが直接 dev ストアの CRUD 操作を行えるため、テスト自動化ワークフローが強化される。組織あたりの dev ストア上限は 250 件。

ai

security
🔗 CISA

CISA が9月10日、MikroTik RouterOS の 2 件の脆弱性を既知悪用脆弱性（KEV）カタログに追加した。CVE-2026-67277 は重要な機能への認証欠如（Missing Authentication for Critical Function）、CVE-2026-86060 はコマンド引数デリミタの不適切な無効化によるコマンドインジェクションで、両脆弱性とも実際の攻撃への悪用が確認されている。MikroTik ルーターは中小企業から ISP まで広く利用されており、ファームウェアの最新化が急務。連邦機関は特定期限までのパッチ適用が義務付けられている。

cloud
🔗 Azure Charts

Azure の9月アップデートとして複数の機能強化が展開された。AKS（Azure Kubernetes Service）の改善のほか、VM Image Builder のより広範な提供開始、ディスク単位のレジリエンシー設定、ASR（Azure Site Recovery）での Linux NVMe レプリケーションサポートが追加された。Azure Database for MySQL にはリードスケーリング用のリーダーエンドポイントが追加され、読み取り負荷の分散が可能に。Defender for Cloud のクラウドセキュアスコアは、日中の平均値ではなく日末のスナップショット値を使う算出方式へ変更され、より正確なポスチャ評価が可能になった。

Azure Virtual Desktop がハイブリッド参加に VPN 不要になった — Azure Arc + Entra ID でオンプレミス・エッジ環境から直接 Azure 認証

cloud
🔗 Microsoft Learn

Azure Virtual Desktop がハイブリッド参加環境において VPN を必要とせずにセッションホストを構成できる新機能を提供した。Azure Arc と Entra ID を活用することで、オンプレミスやエッジ環境のセッションホストが Azure に直接認証できるようになる。従来はサイト間 VPN や ExpressRoute が必要だったハイブリッド AVD 構成が大幅に簡略化され、リモートワークやブランチオフィスへの仮想デスクトップ展開コストの削減に繋がる。エッジコンピューティング環境での AVD 活用が現実的な選択肢となった。

dev

Vercel は AI SDK および関連プロダクトの複数のアップデートを今週公開した。9月10日には @ai-sdk/harness-github-copilot パッケージ経由で GitHub Copilot をハーネス層として使用可能に、9月14日にはハーネスがネイティブのサブスクリプション認証に対応しクレデンシャルをホスト境界に置いたまま認証できるようになった。9月11日には Vercel Sandbox の標準ストレージが 32GB から 64GB に倍増。AI 開発ツールのエコシステムを強化する連続したアップデートで、特に GitHub Copilot 連携はエンタープライズ環境での AI SDK 採用を促進するとみられる。

npm の bypass-2FA 粒度アクセストークンがアカウント管理操作を制限 — 639 件の悪意あるパッケージ公開攻撃を受けたセキュリティ強化

dev
🔗 GitHub Changelog

7月31日より、npm の 2FA バイパス設定の粒度アクセストークン（GAT）ではトークン作成・削除、パッケージアクセス変更、メンテナー管理、組織/チームのメンバーシップ管理などの重要操作が不可になり、インタラクティブな 2FA 検証が必須となった。これは単一の盗まれたトークンで 22 分間に 323 パッケージ・639 バージョンの悪意あるコードが配布された「Mini Shai-Hulud 攻撃」を受けた対応。2027年1月からは直接 publish も OIDC トラステッドパブリッシング方式に移行し、standing token が不要になる予定。
