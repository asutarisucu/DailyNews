shopify
🔗 Shopify Changelog

Shopify Developer Dashboard にカスタムアプリのパフォーマンス可視化機能が追加された（9月25日）。API リクエスト量・エラー率・Webhook 配信の健全性・Embedded Admin ページのロード速度を個別アプリごとに確認でき、単一の絞り込み可能なログストリームで全リクエスト・Webhook 配信・アプリイベントを横断検索できる。問題発生時の根本原因特定が大幅に効率化され、エージェンシーや外部開発者も同じデータを参照可能。

shopify

security
🔗 CISA
