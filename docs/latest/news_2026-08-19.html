🛒 Shopify 開発者情報

Hydrogen 開発者プレビュー更新（8月18日）: カートセッション帰属・カート属性・ページビューイベント改善・Shop Pay 直接レンダリング

shopify
🔗 Shopify Developer Changelog

Hydrogen 開発者プレビューに4つの機能改善が追加された。カートセッション帰属（Cart session attribution）により、サインイン済みの顧客がカートから Customer Account セッションへシームレスに移行できるようになりゲストフローを回避できる。カート属性（Cart attributes）でギフトメッセージなど注文全体データをカートに、彫刻テキストなど明細ごとのデータを各ラインに付与可能に。ページビューイベントが初回ロードだけでなく全ナビゲーションを報告するよう改善され、Shop Pay ボタンは shop-js なしでも即座にスタイル付きで表示されるようになった。

Shopify Oxygen が開発ストアで利用可能に — 有料プランなしで Hydrogen ストアフロントをデプロイ・テスト可能に

shopify
🔗 Shopify Developer Changelog

Shopify の Hydrogen ホスティングサービス「Oxygen」が開発ストアからもデプロイ可能になった。これまで Oxygen のデプロイには有料プランが必要だったが、今回の更新で開発ストアからも利用できるようになり、本番環境に近い条件でのテストが無料で行える。ただし開発ストアにはパブリック環境が含まれないため、デプロイ URL にはストアへのログインが必要。新規アプリ開発や Hydrogen ストアフロントの PoC を行う開発者にとって大きな利便性向上となる。

Shopify API: SubscriptionBillingAttempt の非推奨フィールド errorCode・errorMessage を削除 — 2026-10 移行前に対応が必要

shopify
🔗 Shopify Developer Changelog

Shopify Admin GraphQL API において、SubscriptionBillingAttempt オブジェクトの非推奨フィールド errorCode および errorMessage が API バージョン 2026-10 で正式に削除される。これらのフィールドを使用しているサブスクリプション課金アプリは、代替の errorDetails フィールドへの移行が必要。errorDetails は構造化されたエラー情報を提供しており、より詳細なエラーハンドリングが可能になる。2026-10 バージョンへの移行前に必ず対応を完了させること。

ai

security
🔗 Oracle Security Alerts
