shopify

Shopify Admin API: SubscriptionBillingAttempt の非推奨フィールド errorCode・errorMessage を削除 — 2026-10 以降の全 API バージョンに適用

shopify
🔗 Shopify Developer Changelog

Shopify Admin GraphQL API において、SubscriptionBillingAttempt オブジェクトの非推奨フィールド errorCode および errorMessage が API バージョン 2026-10 以降で削除される。代替として billingAttemptError フィールドへの移行が必要となる。定期課金処理（サブスクリプション）を実装しているアプリは早急に影響範囲を確認し、移行対応を進めることが推奨されている。

security
