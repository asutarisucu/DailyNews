Hydrogen 2026-10 が正式リリース — フレームワーク非依存ライブラリに刷新、React Router/Next.js スターター同梱

shopify
🔗 Shopify Developer Blog

Shopify の Hydrogen が 2026-10 バージョンで正式リリースされ、フレームワーク非依存のライブラリとして全面刷新された。React Router および Next.js 向けのスターターテンプレートが同梱され、20 以上のコーディングエージェントスキルも提供される。既存の Hydrogen プロジェクトはマイグレーションガイドに従ってアップグレードできる。

shopify
🔗 Shopify Developer Changelog

Checkout MCP および Cart MCP のレスポンスに購買者の同意情報を含む buyer.consent オブジェクトが追加された（10 月 16 日）。これにより AI エージェントがストア固有の同意オプションをユーザーに提示できるようになり、ヘッドレスコマースやエージェント型ショッピング体験の構築が容易になる。既存の MCP インテグレーションは新フィールドを取り込むよう実装を更新することが推奨される。

Segment クエリ言語の関数構文が変更 — = true / = false から MATCHES / NOT MATCHES へ移行が必要

shopify
🔗 Shopify Developer Changelog 2026-10

API バージョン 2026-10 から、Segment クエリ言語の関数構文が変更された。これまで = true / = false で記述していた部分を MATCHES / NOT MATCHES に移行する必要があり、関数パラメータ自身も独自のオペレータを取るようになった。カスタムセグメントを使用しているアプリは 2026-10 への移行前にクエリを更新すること。

shopify
🔗 Shopify Developer Changelog 2026-10

Global Catalog REST API が 2026 年 11 月 2 日にトラフィックの受け付けを停止する。移行先は GraphQL Admin API のカタログ関連ミューテーションおよびクエリで、REST 経由でカタログを操作している実装は期限前に移行を完了する必要がある。移行ガイドと代替エンドポイントは developer changelog で提供されている。

CISA 緊急勧告：PHP に深刻な RCE 脆弱性 CVE-2026-109618/109619「php2shell」— 8.5.12/8.4.27/8.3.36 以降へ即時更新を

security
🔗 CISA

CISA が 10 月 21 日、PHP の重大な脆弱性 CVE-2026-109618 と CVE-2026-109619（「php2shell」）に関する緊急勧告を発出した。認証不要のリモートコード実行（RCE）が可能で、Web の広大な範囲に影響する。修正版は PHP 8.5.12、8.4.27、8.3.36、8.2.35 であり、各組織は速やかにアップグレードすることが強く推奨される。

🔗 CISA

CISA が BeyondTrust Remote Support の認証バイパス脆弱性 CVE-2026-102764（CVSS 9.3）を KEV カタログに追加した。中国系の APT グループが初期侵入と横方向移動（ラテラルムーブメント）に積極的に悪用しているとされる。セルフホスト型アプライアンスは BT26-05 パッチを適用し、24.3.1 未満のバージョンは先にアップグレードが必要。
