Google が130万台規模の Android ボットネット「XCPE」を無力化 — TV ボックス製造元 Videostrong が意図的にバックドアと断定

security
🔗 Help Net Security

Google は、主に Android TV セットトップボックスからなる130万台超のボットネット「XCPE」をテイクダウンした。Google の脅威インテリジェンスグループは、製造元の Videostrong がバックドアを意図的に作成・運用し、犯罪者にアクセスを販売していたと高い確度で評価し、同社との関係をすべて断った。制御用ドメインやサーバーへの法的措置により、他のマルウェア経由で侵害された少なくとも1,000万台へのアクセスも遮断したとしている。ただしバックドア自体は端末に残り、所有者が自力で除去することはできない。

Linux カーネル TCP の RCE 脆弱性 CVE-2026-98432 — Red Hat が修正を公開し深刻度を9.8に引き上げ、Ubuntu はテスト段階

security
🔗 The Hacker News

IPv4 TCP のハンドシェイク処理に存在する use-after-free 脆弱性 CVE-2026-98432 について、Red Hat が修正を公開し、当初の評価を引き上げて CVSS 9.8（Critical）とした。Ubuntu の修正はまだオプトインのテストチャネルにとどまる。Anthropic の Frontier Red Team は、Multipath TCP（MPTCP）で待ち受けるサーバーで認証なしに root 権限を奪える攻撃チェーンを報告している。広範な悪用は確認されていないが、各ディストリビューションの修正済みカーネルへの更新が推奨される。

Polymarket で約270万ドルの被害 — 改ざんされた DebugBear の性能監視スクリプト経由のサプライチェーン攻撃

security
🔗 SecurityWeek

予測市場 Polymarket で、サイトに組み込まれていた英 DebugBear のパフォーマンス監視スクリプトがウォレットドレイナーに差し替えられ、約1時間にわたりログイン中のセッションが乗っ取られた。分析企業の推計では700超のウォレットから約270万ドルが盗まれた。Polymarket は国際取引を一時停止してスクリプトを削除し、盗難分と取引停止に伴う損失を含め計390万ドルを返金するとしている。サードパーティ製スクリプトの読み込みが持つリスクを改めて示す事例だ。

Azure Confidential VM への移行で大容量 OS ディスクの暗号化が GA — イメージの縮小・再構築が不要に

cloud
🔗 PUPUWEB（Azure Updates AZ578850）

Microsoft は Azure Updates で、Confidential VM への移行シナリオ向けに大容量 OS ディスク暗号化（LOSDE）を一般提供したと発表した。これまでディスクサイズが障壁となっていた本番規模のワークロードでも、システムイメージを縮小・再構築・再暗号化することなく、OS ディスクを機密ディスク暗号化で保護したまま移行できる。機密 OS ディスク暗号化はキーを VM の vTPM に結び付け、その VM インスタンスだけが復号できる仕組み。

AWS Lambda Web Functions が登場 — 通常の HTTP Web アプリを書き換えずに Lambda で実行、CPU 時間課金

cloud
🔗 SecurityBrief

AWS は、標準的な HTTP Web アプリケーションをイベントハンドラーに書き換えることなく Lambda で動かせる「Lambda Web Functions」を提供開始した。1つの実行環境で最大128の同時リクエストを処理でき、I/O 待ちは課金されず実際に消費した CPU 時間ベースで課金される。現時点では Node.js 24（Arm64）で5リージョンに対応し、CloudFront のオリジンとしてオリジンアクセスコントロール付きで利用できる。ただし I/O の多い API では従来型より高くつく試算もあり、移行前の見積もりが必要だ。

OpenAI が独自 Git バックエンド「Pando」を公開 — Codex によるコミット急増に対応、プッシュ遅延を約80%削減

dev
🔗 MarkTechPost

OpenAI は、AI コーディングエージェントによるコミット急増に対応するため、約10週間で構築した独自の Git バックエンド「Pando」を明らかにした。リポジトリ全体ではなくブランチ単位の因果的一貫性を採用することで無関係なブランチへの書き込みを並行処理でき、中央値のプッシュ遅延を従来比で約80%（約5倍）短縮した。1日に約1PB の Git データを配信し、1時間で57TB 超のパックファイルを送出した実績もあるという。エージェント時代のモノレポ運用の参考になる事例だ。

Node.js 27 の最初のアルファ版が公開 — 既定のヒープ上限を物理メモリから自動算出、Buffer も上限に計上

dev
🔗 Node.js

Node.js 27.0.0-alpha.0 が公開された。--max-old-space-size を指定しない場合、既定のヒープ上限は物理メモリの半分（256MB〜4GB の範囲）に変わり、Buffer や ArrayBuffer が保持するメモリもこの上限に含まれるようになる。従来の既定値に依存していた大規模サービスは挙動が変わる可能性があるため、--max-old-space-size を明示的に設定するよう推奨されている。アルファ版のため、安定版までに仕様が変わる可能性もある。
