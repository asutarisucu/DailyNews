Shopify Flow: Action runtime URL が自動更新 — アプリ再デプロイ後もワークフローの手動更新が不要に

shopify
🔗 Shopify Developer Changelog

Shopify Flow が Action のランタイム URL を毎回の実行時に解決するようになり、アプリを再デプロイして URL が変更されても既存のワークフローが次回実行時に自動的に新しい URL を使用するようになった。これまではアプリ側の URL 変更ごとにマーチャントがワークフローを手動で更新する必要があったが、この手間が解消される。さらにアクションのフィールドに破壊的変更があった場合もバリデーション失敗なく実行を継続し、サーバー側でスキーマ差異を柔軟に処理できるようになった。

【即時対応】Microsoft SharePoint Server RCE CVE-2026-45659 が CISA KEV に追加 — 認証済みユーザーが特権なしで RCE 可能、連邦機関は3日以内にパッチ必須

security
🔗 The Hacker News

Microsoft SharePoint Server の信頼されていないデータのデシリアライズに起因するリモートコード実行脆弱性 CVE-2026-45659（CVSS 8.8）が CISA の既知悪用脆弱性カタログ（KEV）に追加された。サイトメンバー権限以上を持つ認証済みユーザーが管理者権限なしにサーバー上で任意コードを実行できる。Microsoft は 5 月のパッチリリース時に「悪用の可能性は低い」と評価していたが、ランサムウェアグループなどによる実際の攻撃が確認され KEV 追加に至った。SharePoint Server Subscription Edition・2019・Enterprise 2016 を対象に即時パッチ適用が必要。

Windows 11 Patch Tuesday 2026-07（KB5101650）: Point-in-time Restore 搭載・571 件のパッチ・更新を最大 35 日一時停止可能に

dev
🔗 Windows Central

Microsoft が Windows 11 の 2026 年 7 月 Patch Tuesday アップデート（KB5101650）をリリースした。目玉機能は Point-in-time Restore で、72 時間以内の自動作成済み復元ポイントへの全システムロールバックが可能になる（Home・Pro エディションでデフォルト有効、200GB 以上のストレージが必要）。Windows Update にカレンダー UI が追加され、更新を最大 35 日間任意の日まで一時停止できるようになった。あわせて 571 件の脆弱性パッチ、大規模な Bluetooth 修正、File Explorer の高速化、Secure Boot 証明書ロールアウトを含む。
