Hydrogen 開発者プレビュー更新（8月18日）: カートセッション紐付け・カート属性・全ページビューイベント・高速 Shop Pay ボタンを追加

shopify
🔗 Shopify Developer Changelog

Hydrogen の開発者プレビューが8月18日に更新され、カートと Customer Account セッションを同期させる「カートセッション属性」が追加。サインイン済みユーザーがゲストフローを経由せず直接チェックアウトに進めるようになった。ギフトメッセージなど注文全体に付与するカート属性と、彫刻テキストなどライン単位で付与する属性が利用可能に。また、Hydrogen ストアフロントは従来初回ページロードのみページビューを発火させていたが、すべてのナビゲーションでイベントを発火するよう改善され Liquid テーマと同等の計測が可能になった。Shop Pay ボタンはホスト側スクリプト読み込みを待たずに即座にスタイル済み状態でレンダリングされるように変更。Customer Account のローカル HTTPS テスト対応やプラガブルロギング対応も含まれる。

Shopify POS UI Extensions 2026-07: 新 Printing API でハードウェアレシートプリンターへの直接印刷が可能に — getPrinters() / print() を提供

shopify
🔗 Shopify Developer Changelog

API バージョン 2026-07 を使用する POS UI Extensions が新しい Printing API（shopify.printing）を通じて、ペアリング済みのハードウェアレシートプリンターを直接検出・印刷できるようになった。getPrinters() でプリンターを列挙し print() で HTML またはイメージドキュメントを送信することで、システムの印刷ダイアログを開かずにシームレスな印刷ワークフローが実現する。これまでの shopify.print は非推奨となり、POS バージョン 11.11.0 以上で直接印刷がサポートされる。注文ピックアップや独自レシート・バックオフィス印刷など店頭業務の高速化が期待される。

Shopify 次世代イベント（Next Generation Events）が開発者プレビューに — フィールドレベルトリガー・カスタム GraphQL ペイロード・クエリベースのデリバリーフィルターを Webhook に追加

shopify
🔗 Shopify Developer Changelog

Shopify が「次世代イベント（Next Generation Events）」を開発者プレビューとして公開。従来の Webhook を大幅に拡張し、特定フィールドの変更のみをトリガーとするフィールドレベルトリガー制御、受信したいデータをカスタマイズできるカスタム GraphQL ペイロード、条件クエリベースのデリバリーフィルターが追加される。不要なイベント処理を削減してリソース効率を高め、サードパーティアプリとの統合をより精密に制御できるようになる。既存 Webhook との互換性を維持しながら段階的移行が可能で、今後の安定版リリースに向けてフィードバックを受け付けている。

OpenAI、フロンティアモデル向け「ゼロデータ保持（ZDR）」を発表 — Private Safety Processing でプライバシーと不正利用検知を両立

ai
🔗 Truescho / OpenAI Security Blog

OpenAI が8月19日、対象 API 顧客向けにフロンティアモデルのゼロデータ保持（ZDR）機能を提供すると発表した。「Private Safety Processing」と呼ばれる新機能により、OpenAI スタッフがデフォルトでコンテンツにアクセスしない状態を維持しながら、複数の関連インタラクションをまたいだ不正利用パターンを自動的に検出できる。従来のゼロ保持ポリシーでは不正利用検知ができなかった課題を解決するアーキテクチャ上の改善で、エンタープライズ顧客のコンプライアンス要件充足とセキュリティ強化を両立する。

security

CISA が8月18日、既知の悪用済み脆弱性カタログ（KEV）に4件を追加し連邦機関に8月21日までの対応を指示した。最も深刻な CVE-2026-59310（CVSS 9.8）は Broadcom VMware vCenter のパストラバーサルで、ネットワークアクセスさえあれば認証不要で任意コードを実行可能。CVE-2026-55040（Microsoft SharePoint、CVSS 9.1）は4つの認証検証不備を連鎖させた認証トークン偽造。加えて macOS と Windows IKE の脆弱性も同時追加された。Broadcom は7月29日に vCenter の修正パッチを公開済み。vCenter 環境を運用中の組織は直ちに適用されたい。

中国系ハッカーが5日間で361ネットワークを侵害 — CISA が企業向け重大脆弱性に3日間パッチウィンドウを新設

security
🔗 TechTimes

中国国家支援とみられる脅威アクターが5日間で361のネットワークを侵害したとの報告が8月20日に公表された。CISA はこれを受け、エンタープライズ向け重大脆弱性に対して連邦機関が従来の BOD 26-04 期限よりも短い3日間でパッチ適用を完了すべきとする緊急パッチウィンドウを新設した。急速な横断的移動（ラテラルムーブメント）に対応するため、既知の脆弱性を持つシステムのインターネット露出を最小化すること、多要素認証の徹底、ネットワーク分離の見直しを全組織に強く推奨している。
