Shopify Admin API: 未フルフィルメント注文の配送先変更時に税金を自動再計算 — 8月31日より GraphQL Update mutation で対応

shopify
🔗 Shopify Developer Changelog

2026年8月31日以降、未フルフィルメント注文（unfulfilled order）に対して GraphQL Admin API の orderUpdate mutation で配送先住所を変更すると、税額が新しい配送先に基づいて自動的に再計算される。これまでは住所変更後の税額更新を手動で行う必要があったが、今後はミューテーション実行時に自動で反映される。OMS や注文管理 App を構築するパートナーは挙動変更に注意が必要。

CISA KEV: N-able N-central 認証バイパス CVE-2026-18577 が悪用中 — 対応期限8月6日、管理下エンドポイントへの侵害リスク

security
🔗 The Hacker News

CISA は CVE-2026-18577（CVSS 8.2）を Known Exploited Vulnerabilities カタログに追加した。N-able N-central の認証バイパス脆弱性で、CVE-2026-18556 の不完全なパッチ適用による残留問題。攻撃者は N-central サーバーに管理者権限でリモートアクセスしたのち、内蔵の「Take Control」機能を悪用して管理下エンドポイントに横展開し持続的なマルウェアを設置できる。FCEB 機関は8月6日までのパッチ適用が義務付けられた。

npm: 2FA バイパス・グラニュラーアクセストークンの権限を制限 — アカウント管理・org管理が7月31日より2FA必須に

security
🔗 GitHub Changelog

7月31日より、2FA バイパス設定の npm グラニュラーアクセストークン（GAT）でトークン作成・メンテナー変更・org メンバー管理などの特権操作が行えなくなった。これらの操作は今後、インタラクティブな 2FA チャレンジを必要とする。サプライチェーン攻撃の典型的な侵入経路となっていた「スケルトンキー」的なトークン悪用パターンをアーキテクチャレベルで封じる大きな変更となる。直接 publish については 2027年1月に追加制限が予定されている。
