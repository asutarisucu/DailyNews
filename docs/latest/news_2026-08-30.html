shopify
🔗 Shopify Developer Changelog

Shopify Storefront Script Tag 非推奨化を正式アナウンス — 2026年10月に create/update mutations がエラー返却、2027年3月に注入終了

shopify
🔗 Shopify Developer Changelog

Shopify がストアフロント Script Tag の非推奨化スケジュールを正式発表した。2026年10月以降、Script Tag の create および update mutations はエラーを返すようになり、2027年3月にはスクリプトの注入自体が完全に停止される。Script Tag を利用しているすべてのアプリとテーマカスタマイズは、app embed blocks または web pixels への移行が必要。追加スクリプトフィールド（additional scripts）に依存するストアは特に影響を受けるため、早急な対応計画の策定を推奨する。

🔗 AI Agent Store

🔒 セキュリティ

【緊急】CVE-2026-8452: Citrix NetScaler ADC/Gateway の未認証RCEが野生で悪用中 — CISA KEVカタログ登録・連邦機関の修正期限は8月29日

security
🔗 Help Net Security

Citrix NetScaler ADC・NetScaler Gateway に存在する CVE-2026-8452（CVSS v4.0: 8.8）がすでに野生で悪用されていることが確認された。同脆弱性は AAA サービスの SAML SSO パースコードにおける事前認証ヒープメモリオーバーフローで、WatchTowr Labs の研究者が未認証リモートコード実行（RCE）として実証。Citrix は6月30日に DoS 脆弱性として開示していたが、重大性を上方修正した。CISA は8月26日に KEV カタログへ追加し連邦機関に8月29日までの修正を義務付け。修正済みビルド（14.1-73.32以降 または 13.1-63.21以降）への早急なアップデートを推奨する。

CISA が8月26日に既知悪用済み脆弱性6件を KEV カタログへ追加 — Cisco Secure Firewall・Microsoft Windows・Metabase 等が対象

security
🔗 CISA

CISA が8月26日に Known Exploited Vulnerabilities（KEV）カタログへ6件の脆弱性を一括追加した。今回の追加には CVE-2026-20349（Cisco Secure Firewall）・CVE-2026-68820（Microsoft Windows WinSock）・CVE-2026-72898（Metabase SQL インジェクション）・CVE-2026-8452（Citrix NetScaler ADC/Gateway）等が含まれる。BOD 26-04 の要件に基づき、連邦政府機関はすべての公開資産における KEV 掲載脆弱性の優先的な修正が義務付けられている。民間企業においても、早期のパッチ適用計画見直しを強く推奨する。
