🔗 Shopify Developer Changelog

7月9日のHydrogen Developer Previewアップデートで、カタログデータ（商品・コレクション・ページ）をエッジでキャッシュするStorefront API Cachingが追加。WebMCPツールによりAIエージェントがストアフロントのカタログ検索やカート操作をブラウザ内で行えるようになった。ログイン済みユーザー向けのCustomer Account APIサポート（注文履歴・プロフィール）と、型付きルート・リダイレクトも同時投入。

POS UI Extensions 2026-07: 固定額割引が「単価ベース」に変更 — 2026-04以前のアプリは割引計算結果が変わる可能性

shopify
🔗 Shopify Developer Changelog

API バージョン 2026-07 より、POS UI Extensionsの固定額ラインアイテム割引は「数量合計」ではなく「単価」として扱われる仕様に変更された。旧バージョン（2026-04以前）では自動変換が行われていたが、2026-07以降はその変換が廃止される。POSで割引ロジックを実装しているアプリは金額計算の確認と対応が必要。

Shopify Flow: Action実行時URLがアプリ再デプロイ時に自動更新 — ワークフローの手動再保存が不要に

shopify
🔗 Shopify Developer Changelog

Shopify FlowのActionでランタイムURLが変更されアプリが再デプロイされると、既存のワークフローが自動的に新しいURLに切り替わるようになった。これまではマーチャントがワークフローを手動で編集・再保存しなければ更新URLが反映されなかったが、その手間が完全に解消される。Flow連携アプリを開発・運用しているチームには嬉しい改善。

POS Extensions: バックグラウンド拡張ターゲット（pos.app.ready.data）追加 — UIを表示せずセッション全体でPOSイベントを監視可能に

shopify
🔗 Shopify Developer Changelog

POS Extensionsに新しいバックグラウンド拡張ターゲット「pos.app.ready.data」が追加された。このターゲットはPOSセッション全体を通じて起動し続け、UIを一切レンダリングすることなくPOSイベントのオブザーブやバックグラウンドロジックの実行が可能になる。在庫チェック・ポイント計算・分析イベント送信などをUIレスで実装できるユースケースが広がった。
